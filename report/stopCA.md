# stopCA · Stop Child Abuse

> ℹ️ 这是一个反滥用执法的透明度通报频道。本报告只分析其运营机制与数据形态，不涉及任何被处置的内容。
>
> **频道 · 15,447 订阅 · 1.00 帖/天 · 成熟中位阅读 10,543 · ERR 68.25% · 存活率 100.0%**
> 数据来源：`scripts/tg_recon.py dump stopCA --limit 300` → [data/recon/stopCA.jsonl](../data/recon/stopCA.jsonl)
> 抓取时间 2026-09-20 · 样本 300 条（2025-11-25 → 2026-09-20，跨度 299 天）

**一句话结论：这是本语料形式上最极端的频道——300 条消息，全部是纯文本，正文长度在 172 到 181 个字符之间，零域名、零图片、零文件、零标签、零反应、零评论。id 跨度恰好 300，存活率 100.0%；发帖频率恰好 1.00 条/天，299 天一天不差。每条的内容是同一个句式：当天被封禁的相关群组与频道数量，加上本月累计。而这样一个没有任何修饰的数字流，ERR 是 68.25%——高于本语料除工具类与不可替代信源之外的所有样本。它证明了一件事：当数据是第一手且无处可得时，呈现形式可以压缩到零。**

## 二、核心发现一：本语料形式上的极小值

**逐项列出这个频道"没有"的东西：**

| 项 | 本语料典型值 | 本样本 |
|---|---|--:|
| 域名 | 3–400 | **0** |
| 图片 / 文件 | 0–245 | **0** |
| 标签 | 0–268 | **0** |
| 反应 | 0–300 帖 | **0** |
| 评论 | 0–1,999 条 | **0** |
| 正文长度极差 | 数十到数千字符 | **9 个字符** |

**本语料此前的"最简"样本是 [tgx_perfection](tgx_perfection.md)（站外域名绝对为零，但有 608 个 `t.me`、219 张图片、8 个标签）与 [zhihuribao_rss](zhihuribao_rss.md)（结构 100% 一致，但每条带三个链接）。**

**这个样本比两者都更彻底：它连一个链接都没有。**

**正文长度 172–181 字符这个区间值得单独记。**

**极差只有 9 个字符，而每条内容都不同（日期在变，数字在变）。**

**这说明句式是固定的，只有几个数值在变化——**一个典型的填空模板：

```
<数字> groups and channels related to <类别> banned on <月份> <日>.
Total this month: <数字>
```

**本语料在 [wublock](wublock.md) 第四节确立过固定话术的三档判据：**

| 档 | 判据 | 样本 |
|---|---|---|
| **机器模板** | **覆盖率 100% + 完全一致** | **stopCA、[cool_scripts](cool_scripts.md)** |
| 编辑规范 | 覆盖率不足 100% + 完全一致 | [wublock](wublock.md) |
| 个人习惯 | 覆盖率不定 + 细微变体 | [iingtw](iingtw.md) |

**这个样本是第一档最纯粹的实例：** 覆盖率 300/300、长度极差 9 个字符、频率恰好 1.00/天、存活率 100.0%。

**四项指标同时达到理论极值，这在本语料是唯一一例。**

## 三、核心发现二：68.25% 的 ERR 与零形式

**一个没有图片、没有链接、没有标签、不开放互动的纯数字流，拿到了 68.25% 的 ERR。**

**把它放进本语料的 ERR 分类框架**（[iingtw](iingtw.md) 第二节确立，[steamsteam](steamsteam.md) 第二节验证）：

| 类别 | ERR 量级 | 样本 |
|---|---|---|
| 工具/查阅型 | 60–170% | [ACL4SSR](ACL4SSR.md)、[QuanX_API](QuanX_API.md) |
| 不可替代的信源本人 | 130%+ | [iingtw](iingtw.md) |
| **第一手且无处可得的数据** | **68%** | **stopCA** |
| 限免推送 | 38–42% | [SteamNy](SteamNy.md)、[steamsteam](steamsteam.md) |
| 人格化评论 | 20–60% | [misakatech](misakatech.md)、[lover_links](lover_links.md) |
| 编辑型转载 | 10–20% | [zrj96](zrj96.md)、[kejiqu](kejiqu.md) |
| 机器聚合 | 3–10% | [zhihuribao_rss](zhihuribao_rss.md)、[wublock](wublock.md) |

**它落在中上位置，而它的形式投入是全表最低的。**

**与 [zhihuribao_rss](zhihuribao_rss.md)（3.40%）的对照最能说明问题：**

| | [zhihuribao_rss](zhihuribao_rss.md) | **stopCA** |
|---|--:|--:|
| 频率 | 4.11 帖/天 | **1.00** |
| 结构一致性 | 100% | **100%** |
| 自动化 | 完全 | **完全** |
| 形式投入 | 全文镜像 + 三链页脚 | **零** |
| **ERR** | **3.40%** | **68.25%** |
| **倍差** | | **20.1×** |

**两个都是机器生成、结构完全一致的自动流，ERR 差 20 倍。**

**唯一的实质差别是数据的来源性质：**

> **[zhihuribao_rss](zhihuribao_rss.md) 搬运的是别处已有的内容**——**读者随时可以去原站看。**
> **这个频道发布的是只有发布方掌握的处置统计**——**除了这里，无处可得。**

**本语料由此把"机器聚合 = 低 ERR"这条经验判断彻底纠正：**

> **决定 ERR 的不是内容由谁生成（人还是机器），而是内容是否可替代。**
> **一个机器生成的独家数据流，可以比一个人工编辑的转载号高一个数量级。**

**这条修正同时回收了本语料此前两条各自成立但看似矛盾的观察：**

- [iingtw](iingtw.md) 第二节：**"发得越少读得越多"是相关性而非因果，真正的驱动是内容的不可替代性。**
- [zhihuribao_rss](zhihuribao_rss.md) 第二节：**那条规律对机器抓取的内容不成立。**

**合起来的完整表述是：**

> **ERR ≈ f(内容的不可替代性)，频率与生成方式都只是次要修正项。**

## 四、核心发现三：零互动是一个合规选择

**反应与评论均未开放。**

**本语料此前的零互动样本是 [zhihuribao_rss](zhihuribao_rss.md)（机器号，无人看管）与 [wublock](wublock.md)（机构媒体，纯分发管道）。**

**这个样本的动机与那两个都不同，而且可以直接从主题推出来：**

> **这是一个关于儿童保护执法的通报频道。**
> **一旦开放评论，运营方就需要对评论区的内容承担审核责任**——**而这个主题下的评论区是风险极高的场所。**

**关闭互动在这里不是省事，是必要的。**

**本语料由此在"是否开放互动"这个运营决策上补上第四种动机：**

| 动机 | 样本 |
|---|---|
| 留存与社群沉淀（开放） | [SteamNy](SteamNy.md)、[lychee_wood](lychee_wood.md)、[zrj96](zrj96.md) |
| 无人看管（关闭） | [zhihuribao_rss](zhihuribao_rss.md) |
| 频道只是分发管道（关闭） | [wublock](wublock.md) |
| **主题风险（关闭）** | **stopCA** |

**转发均值 5.2、中位 5、max 16——分布极窄，与 [wublock](wublock.md)（均值 2.1、max 7）同型。**

**本语料在 [wublock](wublock.md) 第三节确立过转发的第六种边界"密度边界"（同类内容高密度供给使单条失去稀缺性）。**

**这个样本的转发低不是密度问题（1.00 帖/天不算高频），而是另一种原因：**

> **这类内容没有分享动机。** **转发一条"今天封了 1,752 个群"对接收方没有可操作的价值，也不带社交信号。**

**这与 [cool_scripts](cool_scripts.md) 第二节的"适用性边界"接近但不同：那个是"转了对方看不懂"，这个是"转了对方看得懂但没有用"。**

**本语料由此补上转发的第七种边界：**

> **效用边界。** **内容完全可理解、完全可信，但接收方无法基于它做任何事。**

## 五、实现技术思路

| 层 | 做法 |
|---|---|
| 数据来源 | **发布方自有的处置统计** |
| 生成 | **模板填空**，两个变量（日期、数量） |
| 发布 | **恰好 1.00 条/天** |
| 形式 | **纯文本，零一切** |
| 互动 | **全部关闭** |
| 基础设施 | **零域名、零文件、零 bot 可见** |

**"恰好 1.00 条/天、299 天 299 条"这个规律性本身是一个可读的信号：**

**它说明发布由一个定时任务驱动，而不是由事件驱动**（若由事件驱动，会出现一天多条或某天没有的情况）。

**本语料的 cron 指纹分析**（[sspai](sspai.md) 分钟 `:20` 100%、[hacker_news_feed](hacker_news_feed.md) 分钟模 10 = 0、[programmerjokes](programmerjokes.md) `:30` 98%）**通常需要看分钟与秒的分布才能判定自动化。**

**这个样本不需要：日频率的绝对整齐已经足够。**

**本语料由此得到一条更省力的自动化判据：**

> **当 `帖数 / 天数` 恰好等于一个整数且长期不变时，无需看时间指纹即可判定为定时任务。**

**这条判据的适用条件是样本跨度足够长（本样本 299 天）。**

**id 跨度恰好等于可见条数（300 = 300）说明这个频道从未删除或编辑过任何一条**——**对一个统计通报频道而言，这是正确的做法：历史数据不应被改动。**

**本语料的"从不删"样本**（[jin10light](jin10light.md) 0.0%、[zhihuribao_rss](zhihuribao_rss.md) 100.0%、[lover_links](lover_links.md) 98.0%、[lychee_wood](lychee_wood.md) 94.3%）**中，这个样本与 [zhihuribao_rss](zhihuribao_rss.md) 并列满分，但理由不同：那个是"没有人在那里做删除这个动作"，这个是"删除会破坏数据的完整性"。**

## 六、成本

**经常性（月）：¥0–50。**

| 项目 | 金额 | 依据 |
|---|--:|---|
| 发布脚本 | ¥0–50 | 一个定时任务，读一个数字，填一个模板 |
| 域名 / 存储 / bot | **¥0** | 零 |
| 人力 | **≈¥0** | 完全自动 |

**这是本语料运营成本最低的频道，没有之一。**

**但它的成本结构需要说清楚：**

> **发布这件事几乎免费；产生被发布的那个数字，成本极高。**

**"今天封禁了多少个群组和频道"这个数字背后是一整套检测、审核与处置系统。**

**本语料在 [cool_scripts](cool_scripts.md) 第七节、[projectXray](projectXray.md) 第七节记录过同一结构：频道本身几乎零成本，但它是一个有真实成本的体系的附属品。**

**这个样本是该结构最极端的一例：**

| 样本 | 频道成本 | 背后体系 |
|---|---|---|
| [cool_scripts](cool_scripts.md) | ≈0 | 一个开源项目的开发时间 |
| [projectXray](projectXray.md) | ≈0 | 同上 |
| [wublock](wublock.md) | ≈0 | 3–4 人的编辑部 |
| **stopCA** | **≈0** | **一套内容审核与执法体系** |

## 七、收益

**¥0，且结构上不应有。**

**300 条里零广告、零收款账号、零联盟参数、零推广码、零商品、零外链。** **粗筛命中 0/300。**

**这是本语料第二个"零外链 + 零商业痕迹"的绝对干净样本**（另一个是 [tgx_perfection](tgx_perfection.md)，但那个有 608 个 `t.me`）。

**收益估算：不适用。**

**理由与 [iingtw](iingtw.md) 第八节同型但更强：**

> **[iingtw](iingtw.md)：变现会摧毁价值本身（第十一种类型"变现即毁灭"）。**
> **本样本：这个频道的存在目的就是透明度，而透明度不能被出售。**

**本语料的"不变现十二种类型"在这里出现第十三种：**

> **合规性透明度发布。** **它不是一个商业账号，是一个问责机制的输出端。**

**它与"第一方渠道"（[sspai](sspai.md)、[nicegramchat](nicegramchat.md)、[wublock](wublock.md)）的区别是：那些第一方渠道最终服务于某个商业目标（卖内容、卖产品、导流到自有站），这一个没有下游目标。**

**未变现的承载力：¥0。** **不是"低"，是"零"**——**一个 1.54 万订阅、ERR 68.25% 的账号在商业上很有价值，但它的每一项资产（可信度、覆盖面、主题权威）都会在第一条广告出现时归零。**

## 八、增长策略

| 机制 | 证据 | 判读 |
|---|---|---|
| **独家数据** | ERR 68.25% | **唯一且压倒性** |
| 日更规律 | 恰好 1.00 帖/天 | 形成查阅习惯 |
| 主题权威 | 频道名即主题 | 关键词可达 |
| 转发 | 均值 5.2 | 弱且稳定 |
| 互动 / 标签 / 互推 / 矩阵 | **全部为零** | |
| 买粉 | **不可能** | ERR 68.25% |

**这个频道没有任何可拆解为"动作"的增长机制。**

**本语料在 [iingtw](iingtw.md) 第十节把"频道外的既有身份"列为最后一种增长来源，并指出它"不可被复制，也不可被运营"。**

**这个样本属于同一类，但来源不同：**

| 来源 | 样本 | 本质 |
|---|---|---|
| **人的身份** | [iingtw](iingtw.md) | 只有这个人能说这些话 |
| **数据的垄断** | **stopCA** | **只有这个来源有这个数字** |

**两者的共同点是不可替代性，区别是前者绑定在一个人身上，后者绑定在一个系统上。**

**后者更稳固：** **人会离开（[wangvpn_user_chat](wangvpn_user_chat.md) 的运营者），系统不会。**

**本语料由此把"不可替代性"这个 ERR 的核心驱动因素拆成两支，并给出一条实用判断：**

> **绑定在人身上的不可替代性有单点风险；绑定在系统上的不可替代性没有。**

## 九、法律风险

**风险等级：低。** 这是本语料风险最低的样本之一。

- **内容性质：处置统计的透明度发布。** 300 条全部是聚合数字（当日封禁数量、当月累计），**不包含任何被处置内容的描述、链接、标识或样本。** **这是一个通报机制，不是一个内容分发账号。**
- **主题的敏感性不等于风险。** 频道主题涉及儿童保护执法。**内容本身是执法成果的统计披露，其法律定位与风险结构和本语料的其他样本完全不同：它是治理的一方，不是被治理的一方。**
- **零数据处理。** 无 bot、无评论区、无表单、无收款——**运营方不通过这个频道收集任何读者信息。** **关闭互动同时消除了《网络安全法》第 47 条与《互联网群组信息服务管理规定》语境下的内容审核负担：没有用户生成内容，就没有需要处置的违法信息。**
- **零商业行为。** 零广告、零收款、零联盟参数、零外链——**切断所有需要营利要件的路径，同时避免了任何"利用敏感议题牟利"的质疑。**
- **统计数据的准确性。** 数字由发布方自行提供，**外部无法验证。** **这是透明度报告普遍存在的结构性问题，不构成法律风险，但需在引用这些数字时说明。**
- **境内连接点：无。** 内容为英语、发布方与受众均无中国大陆指向。**中国法无直接管辖意义。**
- **不适用**：不涉及开设赌场罪（0 条博彩内容、0 个域名）；**不涉及传播淫秽物品罪**（300 条纯文本聚合统计，0 个文件、0 张图片、0 个链接——**这是本语料中该项"不适用"证据最充分的样本**）；不涉及帮助信息网络犯罪活动罪（0 个收款账号、0 个支付通道、0 条商业导流）；不涉及侵犯著作权罪（无内容分发）；不涉及侵犯公民个人信息罪（无 bot、无数据收集、无互动）；不涉及非法经营罪（零收入）；不涉及提供翻墙服务（零域名）。

**责任主体**：发布该统计的机构或团队。**暴露面：零域名、零收款、零外链、零互动**——**这个频道在技术上只是一个每天写一行字的输出端，它的全部实质都在它背后那套不可见的系统里。**
