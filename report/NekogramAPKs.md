## 二、核心发布机制：一次五个架构

**63 个发布日里，58 天恰好发 5 条**（4 天发 1 条、1 天发 6 条）。

**文件名把原因说清楚了：**

```
Nekogram-9.6.3-3344-arm64-v8a.apk
Nekogram-9.6.3-3344-armeabi-v7a.apk
Nekogram-9.6.3-3344-universal.apk
Nekogram-9.6.3-3344-x86_64.apk
Nekogram-9.6.3-3344-x86.apk
```

**同一个版本号（9.6.3）、同一个构建号（3344）、五个 CPU 架构（ARM64 / ARM32 / 通用 / x86_64 / x86）。**

**这解释了「间隔中位 0 秒、`<10 秒` 占 79%」** ——**不是刷屏，是一次发版把五个产物一起传上来，全部在同一秒内完成。**

**这也是一个可复用的判读方法**：看到"间隔中位 0 秒 + 每批固定条数 + 文件名只差一个后缀"，就应该先判断是不是多产物发布，而不是判断为刷屏。（对照本轮的 awesomeRSSHub 一次倒 200 条与 AwesomeChatGPT 回填 175 条，那两个才是真刷屏。）

**发布节奏**：0.25 条/天 ≈ 每 19 天一个发布日，**符合一个活跃开源项目的发版周期。**

**这条公告拿到 135 次转发，是所有文字帖里最高的**，说明社区反应强烈。

**3.2 2026 年 2 月：整批 APK 被判违规**

**这些消息的阅读与转发都是 `None`** ——**内容被屏蔽后，连统计数据都不再返回。**

## 九、法律风险

> **level: low。**
>
