## 三、核心发现二：抽奖机制的量化设计

**开奖方式只有两种，比例悬殊：**

```
按人数自动开奖：218 次（75%）
按时间自动开奖：74 次（25%）
```

**「按人数开奖」的设定人数：中位 188，最大 888。**

**这个选择是有意图的。** 按时间开奖，参与人数不确定；**按人数开奖，主办方等于给自己设了一个明确的获客目标——「凑够 188 个人我就开奖」。**

**样本内可见 499、888、200、150、99 等设定值** ——**888 与 99 这类数字明显是营销取整，不是随机设置。**

**中位 188 人换一份机场套餐**：若套餐月费按 ¥10–30 计，**单个新增用户的获客成本约 ¥0.05–0.16。** 这个数字极低——**这正是这套玩法能持续的原因。**

**参与流程被刻意留在群外：**

> 具体参与方式请在群内发送『怎么抽奖』进行查询。

**这一句是每条公告的固定结尾。** 它保证了**用户必须进入主办方的群才能参加** ——**导航频道只负责让人知道有这场抽奖，转化在群里完成。**

## 四、核心发现三：一次延期与一套可验证开奖算法

**样本内有两条与抽奖内容无关的公告，它们是这个号唯一的"自我叙述"：**

**4.1 延期道歉（2025-05，13,303 阅读，8 转发）**

> 【通知📢】用户您好，项目组正在对机器人进行升级重构，预计用时两周。
>
> 【补充公告 📢｜关于项目延期的致歉】…原定于 5 月 2 日起进行的机器人升级重构项目，原计划预计两周内完成。但由于过程中遇到了一些技术挑战及细节优化上的延误。项目组目前正全力推进剩余工作…

**"项目组"这个自称说明背后不是单人。** 一次公开的延期道歉，**在本轮所有样本里只出现过两次**（另一次是 agentONE_R 的故障赔付公告）。

**4.2 V2 上线与 SHA-256 开奖算法**

> 目前 v2 已正式上线！
> 1. 新版三个月内不部署在 `@cnLottery_bot`，请使用 `@NewCnLotteryBot`
> 2. **新版采用密码学安全的随机抽奖算法。开奖时系统生成 256 位随机种子，将种子与每位参与者的用户 ID 通过 SHA-256 哈希计算出随机权重，按权重排序选出中奖者。种子在开奖瞬间才产[生]…**

**这一段是整份样本里技术含量最高的内容，也是最值得单独拆解的：**

| 设计 | 作用 |
|---|---|
| 256 位随机种子 | 保证不可预测 |
| 种子 ⊕ 用户 ID → SHA-256 → 权重 | **每个人的中奖权重可以被任何人独立复算** |
| 按权重排序选中奖者 | 结果确定性，不依赖运行时随机数 |
| **种子在开奖瞬间才生成** | **防止主办方提前算出结果后再挑人** |

**这是 provably fair（可验证公平）的标准实现。** 它解决的是这个生态最核心的信任问题：**抽奖的主办方（机场服务商）和开奖的系统（bot）如果串通，用户永远无法验证自己是不是"陪跑"。**

**一个专门为"抽奖导航"做可验证公平算法的团队，说明它意识到了自己的信任是最脆弱的资产。** 这与本轮 AppsSweepstakesNews 的反羊毛党规则（"无用户名用户中奖无效""活动期间禁止加群"）是同一类思考——**都是被现实教训之后加上去的。**

**同时它也暴露了运营风险**："新版三个月内不部署在 `@cnLottery_bot`，请使用 `@NewCnLotteryBot`" ——**要求全部用户迁移到新 bot，这在实践中会流失相当一部分主办方。**

> **月度广告承载力约 ¥7,000–21,000。**

## 十、法律风险

> **level: high。**
>
> **1｜为"机场"提供有偿或无偿的推广渠道（核心）。** 292 个可解析奖品中 **124 个（42%）是代理服务套餐**，前十大主办方中至少五个是代理服务商的用户群（群名直接标注价格与卖点）。「机场」关键词命中 95 次。中国大陆《计算机信息网络国际联网管理暂行规定》第六条禁止自行建立或使用其他信道进行国际联网；对经营者的判例多以**非法经营罪**处理。
>
> **本频道的角色是提供集中曝光与用户导入的渠道**，且形式上是"抽奖导航"而非直接广告。**若存在挂单收费，则"明知 + 获利"两要件齐备，可能构成共犯或依《刑法》第二百八十七条之二帮助信息网络犯罪活动罪；若完全免费，则"获利"要件缺失，责任显著减轻。样本内无任何价格信息，无法确认——这是把等级定在 high 而非更高的原因，也是本报告最大的不确定项。**
>
> **2｜奖品中的账号类物品。** 91 个奖品（31%）是 Google Voice、Gmail、TextNow 等**批量注册的境外通讯与邮箱账号**，样本内明确出现"GV 源头供应"这样的主办方群名与"Google voice 稳定老号"这样的奖品描述。
>
> **这类账号的来源与用途都有问题**：批量注册违反服务商条款；**"老号"意味着经过养号，而养号账号的典型用途是绕过平台风控。** 中国大陆《刑法》第二百五十三条之一**侵犯公民个人信息罪**（若账号涉及他人实名信息）与第二百八十七条之二**帮信罪**（若明知用于电诈等）均有适用空间。**本频道作为发布渠道，责任层级低于账号提供方，但它是这类交易的公开橱窗。**
>
> **3｜抽奖活动合规。** 《反不正当竞争法》第十条规定有奖销售最高奖金额不超过五万元；《规范促销行为暂行规定》要求公示奖项设置与开奖方式。**本频道的公示做得相当规范**——奖品名称、数量、开奖方式、开奖人数/时间、状态五项俱全，**V2 的 SHA-256 可验证算法甚至超出了监管要求。单份奖品价值多在数十元量级，远低于上限。这一项风险很轻，且是它做得最好的地方。**
>
> **4｜若存在收费则涉及经营资质。** 《电子商务法》第十条要求市场主体登记。同样受限于样本无法确认。
>
> **不适用的三条**：不涉及开设赌场罪（**免费参与、无投注、无对价——这是抽奖与赌博的法律分界线，本频道全部场次均为免费参与**）；不涉及传播淫秽物品罪（0 条成人内容）；不涉及侵犯著作权罪（0 个资源链接、0 个网盘、纯文本无任何文件）。
