## 二、核心发现一：两套调度并存，用"秒"完全分离

把 300 条按是否带 `#一觉醒来发生了什么` 标签切成两组：

| | **日报组（142 条）** | **内容组（158 条）** |
|---|--:|--:|
| 分钟 ∈ {0,15,30,45} | **142 / 142（100%）** | **11 / 158（7%）** |
| 秒 ∈ `:05–:09` | **142 / 142（100%）** | 散（`:04` 10、`:25` 10、`:34` 7…） |
| 秒的众数 | **`:06` 77 条、`:07` 41 条** | 最高仅 10 条 |
| UTC 小时 | 0 点 94 条，其余散在各刻钟 | 散 |

**日报组的秒数分布是 `:06`(77) → `:07`(41) → `:05`(15) → `:08`(6) → `:09`(3)，一个漂亮的单峰。** 峰在 `:06`，向两侧衰减——**这是"整刻钟触发 + 抓取和渲染耗时 5–9 秒"的典型形状**：任务在 `HH:MM:00` 被唤醒，拉数据、拼版、调 API 发送，稳定耗时 6 秒左右，网络抖动造成 ±2 秒的尾巴。

**本语料的 cron 签名排行至此更新为：**

| 频道 | 最强单字段聚集 | 覆盖率 |
|---|---|--:|
| [sspai](sspai.md) | 分钟 `:20` | **100%** |
| **jike_collection（日报组）** | **分钟整刻钟 + 秒 `:05–:09`** | **100% / 100%** |
| [programmerjokes](programmerjokes.md) | 分钟 `:30` | 98% |
| [solidot](solidot.md) | 分钟 mod 5 = 0 | 92% |
| [theblockbeats](theblockbeats.md) | 秒 `:02` | 86% |
| [xhqcankao](xhqcankao.md) | 分钟 mod 30 < 5 | 60% |

**但 jike_collection 是第一个"同一频道内两套调度"的样本，也是第一个"秒的分布本身就是分组依据"的样本。** 此前本语料用秒来判断是否自动化，这里第一次用秒来**分离同一频道里的不同生产线**。

**方法论结论：混合型频道不能整体算 cron 指纹。** 如果把 300 条合起来看，分钟整刻钟只有 51%、秒 `:05–:09` 只有 50%——两个数字都落在"看起来像但不确定"的灰区，会得出"半自动"这种没有信息量的判断。**先按内容标签分组，再各自算指纹，才能看清它其实是 100% 自动 + 100% 手工两条线。**

## 三、核心发现二：日报是一个纯搬运的新闻聚合，内容帖是即刻的原生长文

**日报组（142 条，占 47%）** 的结构完全固定：

```
<日期>
🌍资讯快读
1、<标题>
<链接>
2、<标题>
<链接>
…
```

链接全部指向两家中文新闻站（`jiemian.com` 449 次、`thepaper.cn` 141 次）。**每条日报约 4–8 个条目**，142 条日报对应约 590 个新闻链接——与统计数字吻合。

**内容组（158 条）** 是另一回事。`m.okjike.com/originalPosts/<id>` 出现 **584 次**——即刻（一个中文社交 App）的原帖链接。正文是即刻用户的原创长文，中位 697 字、最长 4,033 字。

按即刻的"圈子"标签分类：

| 标签（即刻圈子名） | 条数 |
|---|--:|
| `#一觉醒来发生了什么` | **142**（日报） |
| `#无用但有趣的冷知识` | 31 |
| `#大产品小细节` | 28 |
| `#科技圈大小事` | 27 |
| `#AI探索站` | 24 |
| `#你不知道的行业内幕` | 20 |

**标签直接沿用即刻的圈子名，说明搬运是按圈子订阅的，不是按用户订阅的。** 这是一个重要的形态判断：它抓的是"话题流"而非"作者流"，所以内容质量取决于圈子的平均水平，而不是某几个作者。

**内容质量确实高。** 样本里的长文包括：干细胞研究访谈的科普整理（4,033 字，讲大象的 TP53 基因拷贝数与人类的差异）、某 AI 公司创始人的万字长文摘译（2,811 字）、某对冲基金创始人访谈的结构化笔记（2,385 字）、以及一份 Codex 日常使用场景清单（转发 106，全样本最高）。**这些不是资讯，是二次加工过的观点内容**——这解释了为什么 ERR 有 11% 而转发只有 6。

## 四、核心发现三：31 条"疑似广告"和 8 类黑话命中，全部是中文新闻造成的误报

**这是本语料迄今最集中的一次误报爆发，也是最有说服力的一次。**

**广告粗筛命中 31 条**，命中词分布：商务 8、合作 8、广告 6、推广 6、投放 4、代理 3、联系 2。逐条核对后的真实语境：

| 命中词 | 实际语境 |
|---|---|
| **商务** | 「**商务**部新闻发言人就中美经贸磋商初步成果答记者问」「集齐几乎所有互联网大厂的**商务**」 |
| **广告** | 「互联网公开募捐服务平台管理新规：不得插入商业**广告**」「严打互联网**广告**违法行为，市场监管总局推出系统性治理方案」 |
| **投放** | 「因未按规定**投放**车辆等行为，某共享单车被罚款」「个人未按规定要求分类**投放**生活垃圾最高罚千元」 |
| **代理** | 「双方的**代理**律师也完全符合各自的风格」「他**代理**的是一家瓷砖品牌」 |
| **推广** | 「帮我提出建议以及进行各种**推广**的朋友们」「他也没有这个钱去**推广**」 |

**黑话粗筛命中 8 类**，全部误报，其中三条值得单独记：

| 黑话词 | 赌博/灰产语义 | 本样本的实际语义 |
|---|---|---|
| **跑分** | **代收洗钱（找人用个人账户过流水）** | **「跑分不用全看，挑几个和日常使用关系比较大的就够了」——大模型基准测试成绩** |
| **出黑** | 从黑网站追回资金 | 「男子被指虐猫……牵**出黑**产社群」——「牵出」+「黑产」的分词错位 |
| **引流** | 给赌博/色情站导流 | 「北京警方打掉一涉短视频**引流**洗钱犯罪团伙」——**报道引流洗钱的新闻** |
| 流水 | 赌博投注额 | 「和开发商合作只能做**流水**」——家装行业的营收 |
| USDT | 结算币 | 某加密货币人物的持仓报道 |
| 加拿大 | 加拿大 PC28 彩种 | 「外交部回应**加拿大**军舰派至台湾海峡」 |
| 实名 | 免实名绕过 | 「**实名**购药、严禁 AI 替代审方」 |
| 一手 | 一手资源 | 「中国芯片产业本质上是美国**一手**帮助建立起来的」 |

**「跑分」是本语料最锋利的一个反例。** 同样两个字，在赌博灰产里指"找人用个人银行账户帮赌资过账"（帮信罪的典型手法，见 [fufeikc](fufeikc.md)、[inside1024](inside1024.md)），在中文科技圈里指"跑分数"即 benchmark。**两个语义都高频、都是行业内的标准说法、且都出现在技术相关的上下文里**——不看整句无法区分。

**「出黑」那一条则是分词错位**：「牵出」的「出」和「黑产」的「黑」在字符串上相邻。这与本语料此前记录的 `#Open`+`#AI`（子词切分）、`#Sensor`+`#Tower`（空白切分）同属一类，但成因是第三种：**中文没有词边界，纯字符串匹配会跨词组命中。**

**「引流」那一条是最讽刺的**：一条**报道引流洗钱案件被打掉**的新闻，命中了"引流"这个用来找引流洗钱的关键词。这与 [times001](times001.md) 的「广告害死人」、[tginfo](tginfo.md) 报道 Telegram 广告业务属于同一形态——**报道犯罪的内容必然命中犯罪关键词。**

**至此本语料的关键词误报谱系是 14 类，可以归纳成三个成因：**

1. **同形异义**（`机场`=airport / `跑分`=benchmark / `代理`=proxy / `合作`=商业协作）
2. **报道即命中**（报道广告业、报道引流洗钱、报道博彩案件）
3. **分词错位**（`#Open`+`#AI` 子词、`#Sensor`+`#Tower` 空白、`牵出`+`黑产` 中文无边界）

**实务结论：粗筛只能用来定位候选，任何一条命中都必须回原文看整句。** 本语料跑到 14 类之后，可以说没有任何单个关键词是可以自动采信的。

## 五、实现技术思路

**两条独立生产线：**

**线 A —— 日报（全自动）**
```
每刻钟 cron → 抓两家新闻站的稿件列表 → 挑 4–8 条 → 拼成编号列表 → 发布
                                                      ↑ 耗时稳定 6 秒
```
**线 B —— 内容帖（人工）**
```
即刻圈子 → 人工挑帖 → 复制正文 + 原帖链接 → 发布（时间完全随机）
```

**线 A 的自动化程度是满的**（秒 `:05–:09` 100%），但**选题是否自动不能确定**——每条日报只有 4–8 条，而两家新闻站每天的稿件量远超此数，**存在一个筛选环节**，可能是关键词规则，也可能是人工勾选后由脚本发布。**秒分布无法区分这两者**，因为筛选发生在 cron 触发之前。

**线 B 完全没有自动化痕迹**：分钟随机、秒随机、间隔中位 37,031 秒（10.3 小时）、`<60 秒` 仅 11%。

**内容全部是搬运，且保留链接。** 584 个即刻原帖链接意味着**每一条内容帖都能溯源到原作者的原帖**。但**署名不完整**——`by @<作者>` 格式只出现 30 次（24 个不同作者），远少于 158 条内容帖。**其余的内容帖只给链接不给署名。**

对照本语料的署名谱系：

| 频道 | 署名方式 | 覆盖率 |
|---|---|--:|
| [sspai](sspai.md) | `[by 作者]` | 完整 |
| [designers](designers.md) | `Suggested by @<用户名>` | 完整（175/175） |
| [douban_read](douban_read.md) | 截图带原帖用户名 + 原帖链接 | 完整 |
| **jike_collection** | **原帖链接 100%，`by @` 仅 30 次** | **部分** |
| [programmerjokes](programmerjokes.md) | 无 | 0 |

**"给链接但不给名字"是一个中间态**：技术上可溯源，阅读时不可见。这个差别在第九节的著作权分析里是关键。

**互动配置**：反应开着但反应量极低（中位 5，对 3,952 阅读即 ER 0.16%），评论关闭。**CV 中位 0.887 说明这些反应是真实的**，只是没人点——长文内容的阅读者更倾向于读完就走。

| 项目 | 金额 | 依据 |
|---|--:|---|

| LLM | **¥0** | **没有改写痕迹**——日报是标题原文，内容帖是即刻原文照搬 |

**经常性合计 ¥920–3,880/月。**

**运营时间投入集中在线 B。** 158 条内容帖 / 148 天 ≈ **每天 1.07 条**。每条需要"刷即刻 → 判断是否值得搬 → 复制长文（中位 697 字）→ 附链接 → 发布"，单条 10–25 分钟，**合 5–20 小时/月**。

**这里有一个与 [douban_read](douban_read.md) 的直接对照，两者形态几乎相同（都是搬运中文社交平台长文），但成本结构不同：**

| | douban_read | jike_collection |
|---|---|---|
| 内容帖频率 | 0.68 条/天 | **1.07 条/天** |
| 是否截图 | **是（239 张）** | 否 |
| 是否有自动化部分 | 无 | **有（47% 是 cron 日报）** |
| 月人力 | ¥600–3,000 | ¥900–3,600 |

**jike_collection 用一条自动化日报占掉了 47% 的发帖量**，让人工部分只需要维持一天一条。**这是"自动化补位"的典型做法：不是把人的活自动化掉，而是用机器产能填满频道的更新预期，把人的精力集中在真正需要判断的内容上。** 代价见第七节——日报的互动表现远不如内容帖。

**LLM 成本为零**是一个值得注意的点。对照 [kejiqu](kejiqu.md)（同为中文科技资讯，但每条都过一遍 LLM 改写，月成本 ¥5–60）——**jike_collection 选择了不改写，成本更低，但也因此完全没有独创性（见第九节）。**

## 七、收益

**直接收入：¥0。** 300 条、148 天、**0 条广告、0 个联盟参数、0 个优惠码、0 个 bot 深链、0 个收款入口**。第四节已逐条排除全部 31 条粗筛命中。

**广告承载力（未变现的潜力）：**

判断依据：

1. **月曝光** = 2.03 条/天 × 30 × 3,952 ≈ **24 万次**。
2. **受众画像**：中文科技/互联网从业者。**这是中文 TG 广告市场里定价最高的一档人群**（对照 [thinkpositivewords](thinkpositivewords.md) 的南亚英语受众，同样 3.6 万订阅，单价差 3–5 倍）。
3. **本语料同类锚**：[kejiqu](kejiqu.md) 同为中文科技资讯、订阅量相近（3.64 万 vs 3.58 万）、曝光量相近（34 万 vs 24 万），其承载力估为 ¥600–4,800/月。

按每月 4–8 条计：**¥600–4,000/月。**

**区间为什么宽，三条，且与 kejiqu 的三条不完全相同：**

1. **转发中位只有 6，ER 只有 0.16%**——两个互动指标都比 kejiqu 更差（kejiqu ER 0.44%）。**长文内容的读者黏性高但互动率低**，这在议价时是硬伤。
2. **47% 的版面被日报占着。** 广告主买的是"一条帖子"，而这个号有将近一半的帖子是格式固定的新闻列表——**软广插在日报流里会非常突兀，插在长文里又与内容调性冲突。** 可售版面实际上只有内容组那 158 条的一部分。
3. **内容全部是搬运的。** 与 kejiqu 相同的问题：读者认的是原作者，不是这个号，广告转化低于有人格的号。

**倾向性判断：偏下沿，且低于 kejiqu。** 理由是第 2 条——kejiqu 的 300 条形态统一、条条可售，jike_collection 的可售版面只有一半。

**趋势：平稳偏弱。** 月度中位阅读 2026-04 = 3,877、05 = 4,060、06 = 3,998、07 = 3,691、08 = 3,569、09 = 2,679（未成熟）。**五个月内从 4,060 缓慢下滑到 3,569，跌幅 12%**，而同期帖数在 51–68 之间波动、无明显趋势。**这个下滑不能用"发得多"解释**（帖数没涨），是真实的注意力流失。

月度转发总和 310 / 620 / 636 / 494 / 482 / 214，同样在 2026-06 见顶后下行。**转发的拐点（06）早于阅读的拐点（05→07 才明显）**，再次印证转发是领先指标。

## 八、增长策略

| 机制 | 证据 | 判读 |
|---|---|---|
| 日报的更新预期 | 142 条、整刻钟 cron、47% 版面 | **维持存在感的主力** |
| 内容帖的质量 | 正文中位 697 字，最长 4,033 字 | 决定订阅意愿 |
| 圈子标签 | 6 个即刻圈子名 | 定位清晰 |
| 保留原帖链接 | 584 个即刻链接 | 可溯源，提升可信度 |
| 从不删帖 | **id 缺口 0.0%** | 档案完整性 |
| 互推 | **0** | 零第三方 @、零第三方 `t.me` 引用 |

**"用自动化日报维持更新频率、用人工长文维持订阅价值"是这个号的全部策略，而且它是有效的。** 2.03 条/天让频道每天在订阅者的列表里出现两次，这个曝光频次由日报保证（成本接近零）；而真正让人不取关的是那些 700–4,000 字的长文。

**但它的代价在数据上很清楚。** 把两组分开看，日报组是高频低价值，内容组是低频高价值——**混在一起的结果是整体 ER 被拉到 0.16%，在本语料的中文资讯号里属于最低的一档**（[kejiqu](kejiqu.md) 0.44%、[douban_read](douban_read.md) 0.46%、[thinkpositivewords](thinkpositivewords.md) 0.86%）。

## 九、法律风险

**风险等级：中。** 无刑事风险，核心问题是著作权，且它的处境比 [kejiqu](kejiqu.md) 更不利。

- **著作权：完整搬运、零改写、署名不完整（主要风险）。** 158 条内容帖是即刻用户原创长文的**全文照搬**，中位 697 字、最长 4,033 字，内容是有完整论述结构的原创作品，毫无疑问受《著作权法》保护。本号既未获授权，也未做任何改写或评论——**它比 [kejiqu](kejiqu.md) 的处境更差**：kejiqu 至少经过 LLM 改写可以主张演绎（虽然演绎本身也侵权），而本号是**逐字复制**，直接落在第 10 条第（五）项复制权与第（十二）项信息网络传播权上，没有任何抗辩空间。**唯一的减轻情节是保留了原帖链接（584 个）**，但**署名只在 30 条上出现**——《著作权法》第 12 条的署名权是独立的人身权利，**给链接不等于署名**，读者在不点击的情况下看不到作者是谁。责任主体为频道运营者。
- **日报的新闻标题与链接：风险显著低于内容帖。** 142 条日报只提供标题加链接，不含正文。标题通常因过短而缺乏独创性，且《著作权法》第 5 条第（二）项将单纯事实消息排除在保护之外。**这部分基本安全**，但**持续、系统性地聚合特定两家媒体的稿件，可能触及反不正当竞争法意义上的"搭便车"**（《反不正当竞争法》第 2 条原则条款），在中国已有若干新闻聚合类判例支持这一路径。
- **《互联网新闻信息服务管理规定》的资质问题。** 与 [kejiqu](kejiqu.md) 同理：持续转载时政、经济类新闻信息并面向公众提供，属于需许可的转载服务，且转载源须在稿源单位名单内。日报里出现的题材包括外交表态、行政处罚、监管新规——**明确属于时政类**，资质要求比纯科技资讯更严。**运营主体与服务器位置不可观测，这是本报告最大的未验证变量。**
