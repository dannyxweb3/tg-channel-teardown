## 二、核心发现：24 MB 装不下 90 分钟

**正文自己提供了判断所需的两个数字：片长（样本中可见 90 分钟、103 分钟一类的标注）与文件体积。**

| 项 | 值 |
|---|---|
| 电影类文件中位体积 | **24.4 MB**（n=120） |
| 电视剧类文件中位体积 | **26.2 MB**（n=131） |
| 正文标注的片长 | **90–103 分钟量级** |
| **推算码率** | **约 32 kbps** |

> **32 kbps 的视频在任何分辨率下都不可观看。**
> **一部 90 分钟的影片，即使压到 480p 也需要 300 MB 以上。**

**体积分布进一步排除了"低码率全片"的可能：**

> **296 个文件里有 269 个（91%）在 50 MB 以下，其中 19 个在 5 MB 以下。**
> **只有 9 个超过 150 MB。**

**本语料由此确定这个频道的实际形态：**

> **它发布的不是影片，是预览片段。**
> **正片在页脚的入口后面。**

**这一点改变了它在本语料里的归类。** 既有的影视类样本是**片源分发**：

| 样本 | 分发什么 | 订阅 | 存活率 |
|---|---|--:|--:|
| [shareAliyun](shareAliyun.md) | 网盘链接（4K / 蓝光原盘） | 202,079 | **1.0%** |
| [Aliyun_4K_Movies](Aliyun_4K_Movies.md) | 网盘链接 | 215,867 | 99.0% |
| [yeqingjie_GJG666](yeqingjie_GJG666.md) | 动画片源（REMUX / BD 原盘） | 22,270 | 94.6% |
| [dianying4K](dianying4K.md) | 片源 | — | 71.9% |
| **youxiu_movie** | **元数据索引 + 预览片段** | **49,948** | **46.2%** |

**本语料由此得到一条可计算的判据：**

> **判断一个影视类账号发的是正片还是片段，不需要下载任何文件：**
> **用正文标注的片长与文件体积算码率。**
>
> **低于约 300 kbps → 必然是片段、预告或极短的剪辑；**
> **1–5 Mbps → 可观看的压制版；**
> **10 Mbps 以上 → 原盘级。**
>
> **这个判据只用两个已有字段，而它决定了法律定性的轻重（第六节）。**

## 三、核心发现二：导航的 ERR 只有「省时」的三分之一

**ERR 2.23% 是其频率档（3–10 帖/天，中位 6.48%）的 0.34 倍。**

**本批 [LinsBookA](LinsBookA.md) 第二节把 ERR 公式里的"不可替代性"分成三档（专属 / 稀缺 / 省时），并指出 ERR 的倍数按这个顺序排。这个样本需要第四档。**

**两个样本可以直接对照，因为它们的其他条件相近：**

| | [LinsBookA](LinsBookA.md) | **youxiu_movie** |
|---|--:|--:|
| 帖/天 | 1.66 | **9.38** |
| 适用面 | 宽（中文视频内容） | **宽（影视）** |
| 变现 | 零 | **零（版面）** |
| 产物 | **一支视频的 196 字摘要** | **一部影片的元数据 + 片段** |
| **ERR / 所在档中位** | **1.13 倍** | **0.34 倍** |

**差 3.3 倍。而两者的区别可以一句话说清：**

> [LinsBookA](LinsBookA.md) **替读者把东西看完了**——**那份摘要是一次不可替代的劳动，只有写它的人有。**
> **这个样本告诉读者东西在哪**——**而它给出的元数据（又名、地区、首映、主演、类型、简介、IMDb 编号）全部来自公开数据库，任何人都能照搬。**

**本语料由此把不可替代性补成四档：**

| 档 | 价值来自 | 可替代性 | 样本 | ERR / 档中位 |
|---|---|---|---|--:|
| **专属** | 这个人 | 不可替代 | [rvalue_daily](rvalue_daily.md) | **4.7** |
| **稀缺** | 这东西别处没有 | 被搬运后失效 | [LetITFlyW](LetITFlyW.md)（受适用面压制） | 0.8 |
| **省时** | 我替你把东西看完了 | 任何人都能做，但要花时间 | [LinsBookA](LinsBookA.md) | **1.13** |
| **导航** | **我告诉你东西在哪** | **任何人都能做，而且不花时间** | **youxiu_movie** | **0.34** |

> **"省时"与"导航"的区别在于有没有投入不可回收的劳动。**
> **写一份摘要要先看完 20 分钟的视频；贴一份 IMDb 元数据是一次抓取。**
>
> **判据：产物中有多少成分是账号自己生产的。**
> **本样本的自产成分只有那句"一句话卖点"**——**其余 400 多字是搬来的字段。**

**而第二节已经说明，连那个 24 MB 的文件也不是它的产物（是片段），真正的产物在页脚后面。**

> **所以它的 0.34 倍不是运营失败，是定位的必然结果：**
> **一个导航站的价值在于被用一次，而不是被反复打开。**

**页脚印证这个定位。** 每条帖子末尾是固定的三件套：一个索引标识、一个"站内搜索工具"标识、一个自有 bot。

**本语料在 [WenAnGuan_botjihuo](WenAnGuan_botjihuo.md) 第五节区分过页脚的两种用途（身份标记 / 转化入口），并在 [xinjiyuan9](xinjiyuan9.md) 第四节按规模排过三类（单链接自指 = 回流、多链接同族 = 矩阵导航、多链接异构 = 转化漏斗）。**

> **这个页脚是转化入口，而且只有一个出口（那个 bot）。**
> **它既不是回流（不指向本频道），也不是矩阵导航（只有一个目标）。**
>
> **本语料由此补第四类：单链接外指 = 单一漏斗。**
> **判据：页脚只有一个链接，且指向本账号之外的一个功能入口。**
> **它意味着整个频道的全部流量被收到一个点上**——**这是转化设计最集中的形态。**

## 四、核心发现三：存活率在盗版号里跨 99 倍，而原因不一定是版权

**650 个 id 只剩 300 条，缺了 350。缺口零大块、中位 1——每发一条留下的，就删掉约一条。**

**本语料的影视类样本存活率分布：**

| 样本 | 存活率 |
|---|--:|
| [Aliyun_4K_Movies](Aliyun_4K_Movies.md) | **99.0%** |
| [vip115hot](vip115hot.md) | 97.1% |
| [yeqingjie_GJG666](yeqingjie_GJG666.md) | 94.6% |
| [soutv](soutv.md) | 78.3% |
| [VodStore](VodStore.md) | 77.7% |
| [dianying4K](dianying4K.md) | 71.9% |
| **youxiu_movie** | **46.2%** |
| [shareAliyun](shareAliyun.md) | **1.0%** |

> **跨 99 倍。**

**直觉的解释是"版权下架压力"，但那解释不了这个分布：几个规模最大、内容最敏感（4K 原盘）的样本反而存活率最高。**

**对本样本，正文提供了另一个解释，而且有依据：**

> **268/300 条正文以"上新"开头。**
> **"上新"是一个时效性栏目词**——**一条三周前的"上新"帖已经不是新的了。**
>
> **而第二节确定了那些文件是预览片段。**
> **一个过期的预览片段对运营者没有价值，占着版面还会让频道看起来旧。**

**本语料由此得到：**

> **盗版分发号的低存活率不一定来自外部压力，也可能来自内容的时效性定位。**
>
> **区分判据：正文有没有时效性栏目词（"上新"、"今日"、"本周"）。**
> **有 → 删除更可能是主动的内容轮换；**
> **没有 → 删除更可能是失效或下架响应。**

**本报告倾向于"内容轮换"，依据是那 268 个"上新"。** **但它不能排除版权响应同时存在**——**两者会产生相同的缺口形状，而样本里没有任何可以区分它们的痕迹（比如下架通告）。** **这一点本报告不作认定。**

**对照 [shareAliyun](shareAliyun.md) 的 1.0%：那个样本分发的是网盘链接，而网盘链接会被平台封禁失效**——**链接失效后保留帖子只会招来抱怨，所以删除是被动的。** **这与本样本的"主动轮换"是两种不同的机制，而存活率这一个数字分不出来。**

## 五、其余维度

**标签密度 4.84 个/帖（1,452 个 / 300 条），550 个不重复——本语料最高。**

**标签的构成是分面式的：片名、品类（电视剧 131 / 电影 119）、地区、类型（惊悚 62、犯罪 46、喜剧 36、悬疑 33、动作 33）、以及演员名。**

**本批 [yunspeedtest](yunspeedtest.md) 第三节确立了标签的第 19 种用途"结构化字段"（八个标签以 22–23 次的固定组合共现，方差几乎为零）。这个样本要求把它分成两型：**

| 型 | 共现模式 | 标签次数的分布 | 样本 |
|---|---|---|---|
| **固定字段组** | 每条记录带同一组标签 | **方差 ≈ 0** | [yunspeedtest](yunspeedtest.md)（8 个各 22–23 次） |
| **可变分面** | 每条记录展开各自的属性值 | **长尾** | **youxiu_movie**（550 个，从 1 到 131 次） |

> **判据就是标签次数的方差。**
> **固定字段组描述的是同一种测量；可变分面描述的是各不相同的对象。**

**演员名被做成标签，而不是留在正文里，这是一个判断。**

**本批 [LinsBookA](LinsBookA.md) 第四节记录过相反的选择：那个样本把视频作者名放在正文的方括号前缀里，而不是做成标签——因为它判断读者不会按作者检索。**

> **两个样本做了相反的选择，而两个选择都是对的：**
> **影视观众确实会按演员找片；而视频摘要的读者不会按作者找摘要。**
>
> **这正好验证了 [LinsBookA](LinsBookA.md) 第四节那条判据的有效性：把哪个维度做成标签，反映的是运营者对读者检索行为的判断。**

**广告粗筛 59/300，逐条核对为影视简介的误命中**（"广告代理公司"、"追凶"一类词组）。

**本语料的粗筛失效语境至此三种：**

| 语境 | 失效方式 | 样本 |
|---|---|---|
| 政经新闻 | 高误报（"商务部"、"中外合作"） | [XiaoZhangDuBao](XiaoZhangDuBao.md)（168/300 全为误判） |
| 黑产文案 | 高漏报（黑产用另一套词汇） | [sepiansousuo](sepiansousuo.md)（实际 113 条，粗筛只中 40） |
| **影视简介** | **高误报（剧情描述含商业词汇）** | **youxiu_movie（59/300 全为误判）** |

> **三种语境的共同结论：粗筛只在消费与工具类内容上可用，而它恰好是从那里长出来的。**

**ERR 低而反应覆盖率 83%。** **按本批 [XiaoZhangDuBao](XiaoZhangDuBao.md) 第三节的区分（ERR 低有"没人想看"与"想看的人要先下决心"两种成因，用反应覆盖率区分）——这个样本的覆盖率很高（83%），属后者。** **但这里的"门槛"不是正文长度，是第三节的定位：打开它的人少，因为它只是一个索引。**

**三条转化路径，覆盖率各不相同：**

| 路径 | 覆盖 | 性质 |
|---|--:|---|
| 固定页脚的自有 bot | **接近 100%** | 主入口 |
| 一个私有邀请链接 | **51/300（17%）** | 不可命名的边（见下） |
| 一个裸 IP 加端口 + 内容 id | 19/300（6%） | 自建站 |

**那个私有邀请链接被引用 86 次，指向同一个目标。** **按本批 [Newbie_Chat](Newbie_Chat.md) 第二节的分类，`t.me/+<hash>` 是一条"已知存在但不可命名"的边：它确实指向一个账号，但从链接本身读不出身份。**

**裸 IP 加端口的自建站值得单记：**

> **它没有域名。**
> **而域名是境内监管最容易切断的一环（备案、解析、封禁都作用在域名上）。**
> **直接用 IP 加端口暴露服务，是在规避这一层**——**代价是用户必须记住一串数字，而且 IP 一旦被封就要全部换掉。**

**该站带内容 id 参数，说明它是一个有内容库的站点，而不是单页。**

**样本还有 11 次指向一个搜索 bot，带启动参数。** **那个 bot 属于本批 [mugou66666666](mugou66666666.md) 第四节扫描出的家族**——**九个样本、四个用户名变体、横跨八个领域，其中七个被本语料评为 criminal 或 critical。**

**成本（月）：¥300–2,000。** **自建站需要一台有公网 IP 的服务器（裸 IP 说明没有域名成本）；元数据抓取与 bot 托管；10.8 GB 由平台承载。**
**上传速率下界（按本批 [mugou66666666](mugou66666666.md) 第三节的指标）：10,846 MB / 32 天 = 0.004 MB/s**——**可忽略，不需要特殊基础设施。**

**收益：¥0（版面可观测）。** **59 条粗筛命中全部为误判；零收款账号、零联盟参数、零推广码、零第三方广告帖、零商务联系方式。**

**属"变现在别处"一类**（与 [readhub_cn](readhub_cn.md)、[xinjiyuan9](xinjiyuan9.md)、[mugou66666666](mugou66666666.md) 同组）：**变现发生在那个 bot、那个私有频道或那个自建站里，三处都在样本之外。**

**未变现的承载力：¥2,000–10,000/月。** 49,948 订阅 + 影视受众（广告主池大）；**上锚受两点压制：ERR 2.23% 意味着单条触达只有 1,116 人，以及页脚已经被自有转化入口占满——加第三方广告会与自己的漏斗竞争。**

**增长：搜索 bot 引流 + 分面标签 + 高频上新。** 转发中位 1（几乎零外溢）；零互推清单、零买量、零抽奖。**频道名是一个自造词 + "影视"的组合，属属性检索占位。**

## 六、法律风险

**风险等级：criminal。**

- **侵犯著作权罪（构成要件齐备）。** 296 个视频文件来自第三方影视作品，附带完整元数据与 IMDb 编号，并通过固定页脚、一个私有频道与一个自建站提供获取路径。**《刑法》第 217 条第（一）项（未经许可复制发行他人作品）与"通过信息网络向公众传播"均被触及；《著作权法》第 10 条第（五）（十二）项、第 52、53 条的民事责任成立。**
- **第二节的码率推算在定性上是减轻情节，但不是出罪理由。** **本频道直接发布的是片段（24 MB / 90 分钟，约 32 kbps），而不是可观看的完整作品。** **单就这些文件而言，使用量有限，接近《著作权法》第 24 条第（二）项"适当引用"的边界。**
- **但"提供获取路径"使减轻情节被抵消。** **每条帖子的固定页脚都指向一个获取入口，另有 51 条带私有频道邀请链接、19 条带自建站链接。** **依《关于办理侵犯知识产权刑事案件具体应用法律若干问题的解释》，通过信息网络向公众提供作品（包括提供下载链接）即构成"发行"。** **片段是诱饵，而真正的传播行为发生在那三个入口里。** **本报告只能观测到入口，不能观测到入口后的内容**——**这是本案事实认定上最大的空白。**
- **"以营利为目的"。** **版面零收入（零广告、零收款、零联盟参数）。** **但本语料在 [shareAliyun](shareAliyun.md) 第一节论证过：依上述解释，"以营利为目的"不能以"零广告"排除，通过提供侵权作品获取其他利益（包括为自有站点导流、积累用户）同样满足。** **本样本有一个自建站、一个私有频道与一个自有 bot，三者都是可变现的资产。**
- **自建站使用裸 IP 加端口（第五节）。** **这在法律上是一个不利情节：《互联网信息服务管理办法》第 4 条要求经营性互联网信息服务取得许可、非经营性服务履行备案；刻意不使用域名以规避备案与封禁，在主观状态的认定上不利。**
- **私有邀请链接（86 次引用，51 条帖子）。** **《民法典》第 1195–1197 条的通知—删除机制作用于可被通知的对象；一个私有频道使权利人无法发出通知。** **这同样是不利情节。**
- **内容含成人向影片。** 样本的元数据中可见分级标记一类的描述。**这些是经正规渠道发行的商业影片，不属于《刑法》第 364 条意义上的淫秽物品**——**与本批 [mugou66666666](mugou66666666.md) 的性质完全不同。** **本报告不以此加重定性。**
- **搜索 bot 深链（11 次）。** **指向一个本语料已识别的、引用者以 criminal 与 critical 为主的 bot 家族。** **若该 bot 侧存在收费或分成，则另涉《刑法》第 287 条之二帮助信息网络犯罪活动罪。**
