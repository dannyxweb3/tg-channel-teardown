## 四、核心发现三：一次关键词误报的教科书案例

**`@` 提及统计的前四名是：**

```
@login_manager  6 次
@login_required 6 次
@auth_bp        4 次
@pythonofftopic 5 次
```

**前三个根本不是 Telegram 账号，是 Python 装饰器语法。**

```python
@login_required
def profile():
    ...
```

**`@login_required`、`@auth_bp.route(...)`、`@login_manager.user_loader` 是 Flask 的标准装饰器。** 抓取脚本按 `@\w+` 提取"提及"，**把代码片段当成了账号。**

**这个误报值得单独记下来，因为它有一般性**：

| 场景 | 误报来源 |
|---|---|
| 编程类群 | `@decorator` 语法被当成 @提及 |
| 邮箱 | `xxx@gmail.com` 的 `@gmail` |
| 财经号 | `#美国`+`安机构` 被分词器切错（本轮 FinanceNewsDaily） |
| 代理工具号 | 「节点/代理/机场/订阅」是产品术语（本轮 Loon0x00、NobyDa、NewlearnerChannel） |

**在本轮 106 份深度报告里，"关键词命中 ≠ 灰产"这条已经出现过五次以上。Python 群是其中最干净、最容易验证的一例。**

**真正的 Telegram 账号只有四个，而且构成很有意思：**

```
@pythonofftopic 5   同群体系的闲聊分流群
@PythonRes 2        资源频道（视频课程、pdf 书籍）
@arabipython 2      阿拉伯语 Python 群
@azepug 2           阿塞拜疆 Python 用户组
@pythonzh 2         中文 Python 群
```

**它是一个按语言/地区分支的国际 Python 社区网络的主群** ——**阿拉伯语、阿塞拜疆语、中文各有分群，主群保持英文。**

**`@pythonofftopic` 的存在说明它有话题纪律**：闲聊被分流到另一个群，**这是 85.4% 删除率的另一部分来源——不只是删广告，还删跑题。**


## 九、法律风险

> **level: low。**
>
> 国际 Python 开发者的技术问答社区，全英文，内容为编程问题、框架用法与学习资源讨论。零广告、零收款、零导流变现，外链不到 25 个且全部指向官方文档、GitHub 与代码粘贴站，零文件托管。
>
> **1｜内容审核表现良好。** 85.4% 的删除率下，样本内 **0 条博彩、0 条色情、0 个代收款账号、0 条机场广告、变现关键词仅 `aff` 1 次命中**。一个 9.6 万成员的国际群能保持这种清洁度，说明反垃圾机制有效。**这一点上它与 blacktechsharing 并列为本轮群类样本的最佳。**
>
> **2｜关于 `@` 提及的说明（非风险，防误判）。** 自动化扫描会把 Python 装饰器语法（`@login_required`、`@login_manager`、`@auth_bp`）识别为 Telegram 账号提及。**这些是代码，不是账号。任何基于 @提及数量的风险评分都会在这个样本上给出错误结论。**
>
> **3｜学习资源的著作权（很轻）。** 样本内有一条提到某机器学习教材的书名与简介，另有 `pythonbooks.org` 链接与 `@PythonRes`（"视频课程、pdf 书籍"）频道的推荐。**样本内没有出现任何具体的盗版下载链接或网盘地址**；`@PythonRes` 的实际内容不在本次抓取范围内，**这是唯一的不确定项，但量级很轻。**
>
> **不适用的四条**：不涉及帮助信息网络犯罪活动罪（0 个收款账号、0 条灰产导流）；不涉及非法经营罪（零收入、无经营行为）；不涉及传播淫秽物品罪（0 条成人内容）；不涉及规避技术措施（0 个破解包、0 个激活工具、0 个绕过工具）。
