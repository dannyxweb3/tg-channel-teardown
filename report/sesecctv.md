## 二、技术实现:搜索 bot 与搜索服务器怎么工作

**重要口径**:本群自身**不拥有搜索引擎**。下面是支撑它运转的 SOSO 平台搜索服务的架构推断,依据是交互行为 + 同生态 jisou771 的可观测证据(带 slot id 的广告链接、爬取式结果块)。这一层的成本由平台方承担,不落在群主头上。

一套 TG 资源搜索服务由四段组成:

**1. 爬取(采集层)——最脏最累的一环。**
用一批 **MTProto user 账号(账号池)** 批量加入并驻留大量公开群/频道,持续增量拉取历史消息和新消息。抓的主要是文本 + 内嵌 t.me 链接 + 文件名,所以带宽压力其实很小。难点在**账号是易耗品**:大量加群、频繁读取会触发 Telegram 的封号/限流,必须几十到几百个账号轮换,每个挂不同代理 IP,并处理 FloodWait 退避。

**2. 抽取与去重(处理层)。**
从每条消息抽出正文、t.me 链接、文件名,关键词正规化,按内容 hash 去重,落地成倒排结构:`关键词 → 命中的一批 t.me 消息链接`。

**3. 索引(存储层)——搜索服务器的钱主要花在这。**
一个**倒排全文索引**,工程上通常是 Elasticsearch / Manticore / Meilisearch / Sphinx / PostgreSQL FTS 之一。规模一旦到**亿级消息**,索引体积可达数百 GB,对内存和磁盘 IOPS 要求很高——这才是"搭建搜索服务器"真正的成本来源,不是 bot、不是带宽。

**4. 查询与投放(服务层)——就是用户看到的那个 bot。**
```
用户在群里发关键词
   → 搜索 bot（群管理员，通过 bot API 收群消息）
   → 查倒排索引
   → 按 时效 + 匹配度 排序
   → 回一个结果块：
        [顶部若干行付费广告]   ← 带 slot id，可按关键词竞价投放
        [中间约 18-19 条 t.me 结果链接]
        [底部一行 热搜关键词]
```
广告注入是**独立叠在结果顶部的一层**,和搜索结果解耦。关键词广告位按用户搜的词竞价——用户搜什么,就注入对应广告主(这一点在同生态 jisou771 观测到 `ad=kw######` / `ad=link####` 参数,可作旁证)。

整套系统**不存任何资源**,只存"词 → 链接"的索引,结果全是外链指路。瓶颈始终在索引服务器的内存与 IOPS。

## 三、成本(重算:含搭建搜索服务器)

成本分两层,**口径务必分清**:

### A. 搜索服务层(平台方承担 · 群主不付)

支撑这个搜索 bot 的整套服务,经常性成本约 **¥3,000–20,000/月**:

| 项 | 月成本 | 说明 |
|---|---|---|
| **全文索引服务器**(大内存独服/VPS,64–256GB RAM,NVMe) | **¥1,500–8,000** | **主成本**,钱花在内存和磁盘 IOPS |
| 爬取账号池(数十–数百 MTProto 账号,易耗轮换) | ¥300–2,000 | 账号被封是常态,要持续补 |
| 代理 / 住宅或移动 IP(爬取账号防封) | ¥200–2,000 | |
| 采集/入库 worker(2–4 台中等 VPS) | ¥200–800 | 持续增量抓取 + 写索引 |
| bot 托管(搜索 bot + 管理 bot 多个) | ¥100–500 | |
| 运维人力(兼职:养号 + 索引维护 + 反封对抗) | ¥1,000–5,000 | |
| LLM | ¥0 | 纯关键词匹配,不需要 |

**一次性**:账号铺底采购 ¥500–5,000 + 初始全量爬取与建索引(算力+时间)¥1,500–10,000。

### B. 展位节点层(群主实际承担)

这个群自己几乎不花钱——不自建索引、不存资源、全自动 bot 管理,经常性支出仅 **¥0–300/月**。它买的是"接入 SOSO 现成搜索服务"的便利,代价是只是个展位、没有议价权。

单一来源:**SOSO 付费轮播广告的分成**,估**月 ¥500–3,000**,且只是"本群作为单个展位的可归因部分"。

> ⚠️ **不要拿第三节的成本减这里的收入**:成本是"整套搜索服务"(平台口径,¥3,000–20,000/月),收入是"单个展位"(节点口径,¥500–3,000/月),两者口径不同。
>

1. **侵犯公民个人信息罪 / 非法获取计算机信息系统数据罪(刑事)** —— 置顶 SOSO 广告投放"社工库/开盒"类目服务。

3. **疑似涉未成年人性交易 / 性剥削** —— 群内用户消息出现明显指向未成年人的招揽话术。**这已超出竞品分析范畴,属应向执法机关举报的对象**,本报告未收录、未进一步抓取。
4. **爬取层的 ToS 灰区** —— 用账号池大规模抓取公开群/频道消息本身处于 Telegram 服务条款灰区;用于索引违法内容则叠加前述刑责。
5. **帮信罪敞口** —— 作为 SOSO 引流/广告网络一环,为上述违法服务导流。
