## 三、核心发现二：191 处 `aff`

**101 个 `aff` 参数 + 98 个 `pid` 参数** ——**这是 WHMCS（主机行业最常用的计费系统）的标准联盟与产品参数。**

**样本内的典型带货帖：**

> **搬瓦工上新 BIGGERBOX-20-1024**　作为 MINIBOX 的升级版，BIGGERBOX 在内存、存储配置和流量上都有所提升。该机器配置为：1vCPU，1024MB 内存，1000GB 流量，20GB 存储，1Gigabit 带宽。**售价为 $37/y，优惠后 $34.5。购买需要邀请码（不是优惠码）**。该机型同样位于 DC99，默认走优化线路，通过电信 CN2 回程，**但在网络级别相对较低，有可能在某些时…**

**这条值得单独看，因为它的写法与典型带货文案相反：**

| 典型带货 | **本条** |
|---|---|
| 只讲优点 | **明确写出「网络级别相对较低，有可能在某些时…」** |
| 模糊规格 | **1vCPU / 1024MB / 1000GB / 20GB / 1Gigabit 全部列明** |
| 隐瞒门槛 | **「购买需要邀请码（不是优惠码）」——主动区分两个容易混淆的概念** |
| 不提机房 | **「位于 DC99（不是 DC9）」——纠正一个常见误认** |

**另一条同类帖也写着「默认走优化线路，但是『尽力而为，不能保证』」、「出站流量只可能走 CN2GIA，不会通过移动 CMIN2 和中国联…」。**

**这种"把缺点写在正文里"的带货方式，在本轮是第一次见到。**

**对照本轮的另外两个联盟推广样本：**

| | [jichangtj](jichangtj.md) | [merlinclashcat](merlinclashcat.md) | **vps_xhq** |
|---|---|---|---|
| 联盟参数 | `aff` / `a_aid` / `a_bid` | `code=` | **`aff` 101 + `pid` 98** |
| 广告标识 | **无** | **有**（「【推】…推广」） | **无独立标识** |
| 内容态度 | 排序免责「顺序随便排的」 | 无 | **正文内直接写明限制与缺点** |

**三者都没有规范的广告标识，但披露方式不同：一个免责排序，一个标注"这是推广"，一个把负面信息写进产品描述。**

**`xhqcankao` 是本轮的另一个样本，其显示名为「风向旗参考快讯」，16.3 万订阅。**

**但它的用户名前缀是 `xhq` —— 信号旗的拼音首字母，与本频道的 `vps_xhq` 同源。**

**这说明两件事：**

1. **两者同属一个账号体系**（`vps_xhq` + `vpsxinhaoqi` + `xhqcankao`）
2. **`xhqcankao` 把显示名从「信号旗」改成了「风向旗」，但用户名改不了，留下了痕迹**

**用户名是 Telegram 里唯一改不掉历史的字段**（改用户名会丢掉所有旧链接），**所以它是判断账号血缘最可靠的依据。** 本轮此前靠页脚密度做过四次矩阵识别，**这一次是靠用户名的拼音残留。**

**矩阵的分工也清楚**：`vps_xhq` 做主机优惠（4.96 万订阅、0.33 条/天），`xhqcankao` 做综合快讯（16.3 万订阅）——**一个垂直带货，一个泛资讯引流。**
