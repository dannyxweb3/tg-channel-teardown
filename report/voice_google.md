## 二、核心发现一：99.1% 的删除率，而幸存的是招牌

**6,164 个 id 只剩 56 条。** 本语料的频道类删除率谱系：

| 频道 | 删除率 | 成因 |
|---|--:|---|
| **voice_google** | **99.1%** | **见下** |
| [google_drive](google_drive.md) | 99.4% | 资源失效 |
| [shareAliyun](shareAliyun.md) | 99.0% | 单一网盘被删 |
| [Hao12News](Hao12News.md) | 93.6% | 文档维护 |
| [XPlus_Channel](XPlus_Channel.md) | 83.5% | 清理旧公告 |

**但成因与上面任何一个都不同。** 判据是**幸存内容的构成**：

| 幸存的 56 条里 | 数量 |
|---|--:|
| 经营宣言、号码列表入口、购买方式 | 多数 |
| 4 次投票 | 4 |
| 零星的「便宜 GV，随机发货」这类短促销 | 若干 |

**没有一条是"某某号码已售出"或"今日上新第 N 批"。**

**一个卖号八年的店铺，它的消息流里绝大部分应该是逐批的上架信息**——**而这些正是消失的那 99.1%。**

**最合理的解释：这是一个持续清理库存信息的商铺号。** 号码卖掉了、批次过期了、价格调整了，**旧帖就删掉**，**只留下不会过期的招牌（经营宣言、入口、联系方式）。**

**这与本语料的其他高删除率样本有本质区别：**

| 类型 | 删掉的是什么 | 样本 |
|---|---|---|
| 资源失效 | 死链 | [shareAliyun](shareAliyun.md)、[google_drive](google_drive.md) |
| 文档维护 | 过时教程 | [Hao12News](Hao12News.md) |
| **库存清理** | **已售批次** | **voice_google** |

**"库存清理"是本语料新增的第六种删除动因**（前五种见 [zuanke8](zuanke8.md) 第四节）。**它的特征是：删除率极高，但幸存内容高度同质且全是"常青"信息。**

**本号与 [sizukon](sizukon.md) 属同一类：靠时间。** 56 条帖的中位帖龄以年计，**阅读在八年里一点点累积。**

**但它多了一个 [sizukon](sizukon.md) 没有的因素：极高的转发峰值。** 那条经营宣言被转发 **1,080 次**——**对 2.26 万订阅即 4.8%**，**是本语料转发比最高的单帖之一。**

**为什么一条商铺自述会被转两万分之一千次？** 因为它是**可以转给别人的"店铺名片"**：需要买号的人把这条转给同样需要的人，**比转一个链接更完整（有介绍、有入口、有信誉背书）。**

**这再次落在本语料的"转发由'对方需要'驱动"规律上，而且是它在商业场景里的形态：广告可以被转发，只要它同时是一份使用说明。** 对照 [speedcentre](speedcentre.md)（广告帖转发中位 0–2，因为那是"某机场在打折"，不是"哪里能买到"）。

**4 次投票在一个只有 56 条可见消息的频道里占 7%。** 本语料使用投票的样本至此七个（[surfboardnews](surfboardnews.md) 14、[tginfo](tginfo.md) 10、[tginfoen](tginfoen.md) 7、**voice_google 4**、[LptTech](LptTech.md)、[QuanX_API](QuanX_API.md)、[zaproshare](zaproshare.md) 各 1），**而这是唯一一个商铺号。** **投票在这里最可能的用途是问客户想要什么货。**

## 四、核心发现三：卖的到底是什么

**幸存内容里的商品线索（本报告只做归类）：**

| 商品 | 出处 |
|---|---|
| **某通讯服务的号码**（含"靓号"分级） | 经营宣言、号码列表入口 |
| **"七位纯数字"的某平台邮箱账号** | 一条独立公告 |
| "更多邀请码/账号/VIP" | 一条促销 |

**三类商品的共同点：它们都是可以被批量注册、然后转售的平台身份。**

**"七位纯数字"这个说法值得解释。** 某平台的邮箱地址在早期允许纯数字用户名，**且位数越短越稀缺**（六位、七位在十几年前就已注册完）。**这类账号今天只能从老用户手里获得或通过其他途径取得**——**它们不是新注册的，是存量账号的二级市场。**

**销售渠道有三条，互为备份：**

| 渠道 | 形态 |
|---|---|
| 自有店铺站 | 11 条链接，有商品列表页与分页 |
| **自助购买 bot** | 一条公告里给出，发指令即可下单 |
| 人工客服 | 一个 Telegram 账号 + 一个微信号 |

**"自助 bot + 人工客服 + 独立站"三件套是成熟电商的配置。** 对照本语料的其他售卖型样本：

| 频道 | 渠道 |
|---|---|
| [fufeikc](fufeikc.md) | bot 深链 |
| [zaproshare](zaproshare.md) | 自有站 + 联盟 |
| **voice_google** | **站 + bot + 双客服（TG + 微信）** |

**微信号的出现是一个重要细节**：它意味着**交易可以落到境内的支付与社交体系里**，**这与纯 Telegram 内交易的风险结构完全不同**（见第九节）。

**标签里还有 `#避雷`、以及三个机场品牌名**——**说明它顺带做机场点评**，这是本语料常见的"账号商兼做代理服务测评"形态。

## 五、实现技术思路

**这是一个开了八年的线上商铺，Telegram 频道是它的门面而不是货架。**

**判据：**
1. **0.02 条/天**——货架上的商品变动不在频道里体现，在站上。
2. **99.1% 删除率**——频道只留常青信息。
3. **自有站 11 条链接，含商品列表页与具体商品页的分页编号**——**真正的货架在站上。**
4. **自助 bot**——下单不经过人。

**基础设施：一个自有域名的站 + 一个 bot + 两个客服身份（一个 Telegram、一个境内社交）。**

**自动化程度：下单自动化（bot），内容完全人工（56 条 / 8 年）。**

**56 条里有 20 条无正文**（纯图片），**多为商品截图或列表截图。**

## 六、成本

**一次性**

| 项目 | 金额 | 依据 |
|---|--:|---|
| 建站 | ¥2,000–10,000 | 商品列表 + 分页 |
| 自助 bot 开发 | ¥3,000–15,000 | 需要接库存与发货逻辑 |

**经常性（月）**

| 项目 | 金额 | 依据 |
|---|--:|---|
| **货源采购** | **不可观测** | 见下 |
| 站点 + bot 服务器 | ¥50–300 | |
| 域名 | ¥10 | |
| 客服人力 | ¥1,000–5,000 | 两个客服渠道需要有人值守 |

**货源采购是这门生意的主要成本，而它完全不可观测。**

**可以说清楚的是它的结构**：这类商品不是自己生产的，**是从上游批量获取的**。上游的形态在本语料有旁证——[gouwu](gouwu.md) 的幸存内容里就有"全球社媒账号批号、住宅 IP、某平台邮箱、某几个社交平台账号"的供货广告。**那类供货商就是这类商铺的上游。**

**本报告不估算货源成本，因为：**
1. **单价随号码"靓"的程度差几十倍**（普通号与七位纯数字不是一个量级）。
2. **获取方式不可知**——批量注册、收购老账号、或从更上游的渠道进货，成本结构完全不同。
3. **本样本没有任何价格信息**（幸存的 56 条里没有报价，报价在站上）。

## 七、收益

**这是本语料少有的"确定在赚钱但完全不可估算"的样本。**

**确定在赚钱的证据：**
1. **八年持续运营**（2018-04 → 2026-08）。一门不赚钱的生意不会做八年。
2. **自建站 + 自助 bot + 双客服**——这些是有成本的投入。
3. **自述「诚信经营六年有余」**（该帖发布时点算起）。

**不可估算的原因：**
1. **交易全部在频道外**（站上、bot 里、微信里）。
2. **56 条幸存消息里没有任何价格、销量、库存数字。**
3. **本语料没有可比样本**——其他售卖型号要么卖虚拟服务（[jichangtj](jichangtj.md) 的机场订阅有公开价目），要么卖内容访问（[sizukon](sizukon.md) 的付费线），**都没有这种"实物化的平台身份"品类。**

**能给出的只有一个边界性的观察：** 2.26 万订阅、成熟中位阅读 48,295、经营八年——**单是那条 147,276 阅读、541 转发的招牌帖，累计带来的到站量就足以支撑一门小生意。** **但把它折算成金额需要客单价与转化率，这两个数都不在样本里。**

**趋势：可能在收缩。** 依据是发帖密度——**8 年 56 条可见消息，而最后一条在 2026-08-16。** 但 99.1% 的删除率使这个判断很弱：**看不到的那 6,108 条里，近期的密度无从得知。**

## 八、增长策略

| 机制 | 证据 | 判读 |
|---|---|---|
| **时间** | 八年、ERR 213.84% | **主要资产** |
| 招牌帖的可转发性 | 1,080 转发（转发比 4.8%） | **最强的单点获客** |
| 信誉叙事 | 「诚信经营六年有余」 | 二级市场的核心竞争 |
| 三渠道并行 | 站 + bot + 双客服 | 降低转化摩擦 |
| 投票 | 4 次 | 问客户要什么货 |
| 兼做机场点评 | `#避雷` + 三个品牌标签 | 蹭相邻流量 |
| 互推 | 极少（3 条 `t.me`） | |
| 买粉 / 刷互动 | **可排除** | 反应覆盖 88%、中位 43，与阅读量匹配 |

**"诚信经营六年有余"这句话是这门生意的核心资产。** 账号二级市场的最大问题是**买家无法验证卖家**——付了钱可能收不到货、收到的号可能被找回。**一个开了八年、有独立站、有自助 bot、有两个客服渠道的店铺，它卖的其实是"跑不掉"这个信号。**

**本语料此前在 [fufeikc](fufeikc.md) 记录过非法市场的信用机制（「上押 X 万 U」——带担保方的保证金），在 [gouwu](gouwu.md) 记录过另一种（反诈改名监控 bot）。**这是第三种：用时间和基础设施做抵押。**

**三者的共同点：非法或灰色市场必须自己制造信用，而制造信用的成本就是它的进入壁垒。**

## 九、法律风险

**风险等级：刑事。**

- **侵犯公民个人信息罪（《刑法》第 253 条之一）——最可能适用的一条。** 出售平台账号（邮箱、通讯号码）**是否构成"公民个人信息"取决于账号是否关联到可识别的自然人**。
  - **若这些账号是用他人身份注册后转卖**（本语料 [gouwu](gouwu.md) 的幸存内容显示存在"证件料"收购市场），**则账号本身承载了他人的身份信息，出售行为直接落入本罪。**
  - **若是自行批量注册的"空号"**，则不含他人个人信息，**本罪不成立**，需转向下面几条。
  - **本报告无法确认货源性质**，这是定性上最大的分叉点。
- **帮助信息网络犯罪活动罪（第 287 条之二）。** 通讯号码与邮箱账号在灰产链条里的主要用途是**接收验证码、注册其他平台、规避实名与风控**——本语料在 [gouwu](gouwu.md) 已记录过同一类供货信息与"免实名"卖点。**批量出售这类账号，若明知或应知买家用于违法活动，构成本罪。** 一个公开挂牌、持续八年、明确标注"大量"的店铺，**"应知"的认定门槛很低。**
- **非法经营罪（第 225 条）。** 出售境外平台的通讯号码，**涉及未经许可经营电信业务的争点**。这类号码本质上是境外服务商提供的通讯服务，**转售它在中国法下缺乏合法资质路径。**
- **违反实名制要求。** 《网络安全法》第 24 条确立网络实名制。**账号买卖的全部商业价值恰恰建立在"绕开实名"之上**——这一点与本语料 [fufeikc](fufeikc.md) 解码过的「免实名 免绑卡」、[gouwu](gouwu.md) 的「海外服务器代开户，免实名」是同一个卖点。
- **微信客服是境内连接点，也是最重的一项。** 一个境内社交账号意味着：**运营者或其客服很可能在中国境内**，**交易资金可能走境内支付通道**，**该账号本身是实名的。** 对照本语料的其他灰色样本——[projectXtls](projectXtls.md) 零收款地址、[moeisland](moeisland.md) 零暴露面、[zaproshare](zaproshare.md) 有域名与联盟账号——**这个号是唯一一个把境内实名社交账号挂在门面上的。**
- **自有站与 bot 加重了"经营"的认定。** 独立站有商品列表与分页、bot 能自助下单，**这些是"以营利为目的、持续性经营"的直接证据**，远强于零散的私下交易。
- **99.1% 的删除率在法律上是双刃的。** 一方面它销毁了绝大部分交易记录；**另一方面，系统性删除本身可能被评价为掩盖行为。** 而**幸存的 56 条已经足够证明经营事实**——**招牌帖白纸黑字写着卖什么、卖了多久。**
- **不适用**：不涉及开设赌场罪（0 条博彩内容、0 个博彩域名、0 个客服号指向博彩）；不涉及传播淫秽物品罪（0 条成人内容）；不涉及侵犯著作权罪（无内容分发）。

**责任主体**：店铺运营者。**暴露面是本语料最完整的之一**——**一个自有域名（可查注册信息）、一个 Telegram bot（绑定账号）、一个 Telegram 客服账号、一个境内社交账号（实名）、以及八年的公开经营记录。** **对照 [moeisland](moeisland.md)（零暴露面）：同样在灰色地带，一个什么都不落地，一个把招牌挂了八年。** 而这正是它的商业模式所要求的——**第八节已论证，它卖的就是"跑不掉"。**
