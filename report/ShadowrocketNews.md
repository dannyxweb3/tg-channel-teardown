## 三、核心发现二：changelog 的写法暴露了工程规范

**样本原文（测试版）：**

> **Shadowrocket 测试版更新　版本 2.2.91 (3390)**
> 测试内容：
> · **`feat(reality)`**: add client versi…

> **版本 2.2.81 (3096)**
> · **`feat(mitm)`**: add http2 mitm suppo…

> **版本 2.2.91 (3394)**
> · **`fix(script)`**: prevent malformed …

> **版本 2.2.91 (3396)**
> · **`feat(shadowsocks)`**: add extra ae…

**`feat(scope):` 与 `fix(scope):` 是 Conventional Commits 规范的标准前缀。**

**这说明版本公告是直接从 git 提交记录生成的，而不是人工撰写的营销文案。**

**正式版公告则改用中文，但保留了同样的结构：**

> **Shadowrocket 正式版更新　版本 2.2.92**
> \* **特性(protocol)**: 新增 **Sudoku** 代理协议支持，并深度优化其数据转发路径以减少内存分配与拷贝
> \* **特性(dns)**: 增加直连域名专属 DNS 路由支持并允许 **DNS over TCP**，新增 **DNSCrypt** 上游支持，并在 CNAME 与 Host 规则中支持配置多服务器
> \* **特性(tailscale)**: 引入全局 **Tailscale** 隧道模块，支持本地 **MagicDNS** 解析，并新增对端设备详情、延迟（RTT）与配置管理等 UI 交互
> \* **优化(tailscale)**: 全面优化 Tailscale 运行能耗与稳定性，支持按需调度 **WireGuard** 唤醒、自动适配网络接口变动与 UDP 套…

**「测试版用英文 commit 前缀、正式版用中文『特性/优化』」是一个刻意的分层**：**测试版给开发者与尝鲜者看，正式版给普通用户看。**

## 十、法律风险

> **level: medium。**
>
> **1｜代理客户端的定性（与本轮 [Loon0x00](Loon0x00.md)、[QuanXNews](QuanXNews.md)、[QuanXApp](QuanXApp.md) 同一判断）。** Shadowrocket 是在 App Store 正常上架的付费应用，属**规则分流客户端**——它不提供网络出口，只做本机的规则匹配与流量转发。中国大陆《计算机信息网络国际联网管理暂行规定》第六条禁止的是"自行建立或使用其他信道进行国际联网"，**指向提供信道的一方（机场），而非客户端工具。**
>
> **本频道不销售节点、不提供订阅、不推荐任何机场服务商**：6 个外链（3 个 GitHub、2 个模块商店、1 个公共 DNS），**零落地页、零优惠码、零 aff 参数、零收款入口、零机场客服账号。** 「代理 16」次命中全部是 changelog 里的技术词。
>
> **残余风险在于内容本身的性质**：changelog 里明确列出了 REALITY、Mieru、Sudoku 等抗封锁协议的支持，**这些协议的设计目的就是规避网络审查。** 发布对这类协议的支持说明，**在监管口径上处于灰色地带——但它是产品的技术文档，不是服务销售。**
>
> **2｜MITM 能力的公告。** 样本内有 `feat(mitm): add http2 mitm suppo…`。**中间人解密是这类客户端的核心功能之一，用于本机流量的规则改写。** 它作用于用户自己的设备与自己的证书，**不侵入他人系统，不构成《刑法》第二百八十五条项下的问题。** 但同一能力也是本轮 [NobyDa](NobyDa.md) 那些"去广告/解锁会员"脚本的技术前提——**工具方与脚本方的责任在法律上是分离的。**
>
> **3｜为第三方模块索引平台背书。** 「模块中心」（139 转发）是一个第三方的模块资源索引站，原文强调"模块资源均来源于开源仓…"。**若其索引的模块中包含绕过付费墙、去广告等内容，则触及《著作权法》第五十条；但本频道只是介绍它，不托管任何模块。** 责任层级很低。
>
> **不适用的四条**：不涉及帮助信息网络犯罪活动罪（0 个收款账号、0 条博彩/诈骗导流、不为任何机场提供推广）；不涉及非法经营罪（207 天零收入、无经营行为）；不涉及传播淫秽物品罪（0 条成人内容）；不涉及侵犯著作权罪（0 个破解包、0 个盗版资源、零文件托管，App 本身在 App Store 正常销售）。
>
> **与本轮 feiyu123、blacktechsharing、Lottery_home 的关键区别**：那三个**为机场提供有偿推广渠道（带优惠码、落地页、CPS 分成）**，本频道**只发自家产品的版本更新日志**。它是本轮四个代理生态样本里内容最"干净"的一个——**连教程和配置讨论都没有。**
