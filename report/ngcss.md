> ⚠️ 本报告不复现机场域名、订阅地址、节点 IP 与邀请链接。
>
> **群 · 24,301 成员 · 可见 300 条 · 发言人 82 · bot 消息 0% · 12.5 条/天 · 存活率 15.6%**

**一句话结论：群名里写着「公益机场」和「咨詢问题仅限官网右下角」——一个 2.43 万人的机场用户群，明确把客服入口放在群外，而群里 0 个 bot、0 条管理消息。它的 id 每天前进 80 个而只有 12.5 条活下来，存活率 15.6%；82 个发言人里最活跃的一个占 33%（98/300）。样本里出现了一条裸 IP 地址和一条缓存域名，以及「有没有共享账号，下载小火箭」这类请求——这是本语料第一个能看到机场用户群内部日常对话的样本，而它显示的是：用户在群里聊的不是机场，是怎么把客户端装上。**

## 二、核心发现一：「咨詢问题仅限官网右下角」

**群名的括号里写着这句话。** 它把一个 2.43 万人的用户群的核心功能——客服——**明确排除在群外。**

**这是本语料第三种"把支持成本挡在门外"的做法：**

| 做法 | 样本 | 形态 |
|---|---|---|
| 关键词 bot 自动回答 | [v2rayN](v2rayN.md) | 「下载」「文挡」自动应答 |
| 迁到认证私有群 | [nexitallyusers](nexitallyusers.md) | bot 验证后才能进 |
| **群名声明客服在别处** | **ngcss** | **零技术，改个群名** |

**第三种成本最低，而且它与 [giantcutie6688](giantcutie6688.md) 把反诈声明写进群名是同一手法**——**群名是 Telegram 里曝光最充分的位置（搜索结果、会话列表、转发标头都显示它）。**

**本语料由此可以总结一条：群名不只是名字，它是运营者唯一一个"每个人都一定会看到"的版面。** 已记录的用途有四种：

| 用途 | 样本 |
|---|---|
| 关键词占位 | [beijingz](beijingz.md)、[hao123f](hao123f.md) 等九种形态 |
| 排他宣示 | [giantcutie6688](giantcutie6688.md)「唯一群！」 |
| 反诈声明 | [giantcutie6688](giantcutie6688.md)「不會主動DM」 |
| **支持渠道重定向** | **ngcss「咨詢问题仅限官网右下角」** |

**而它确实生效了：bot 0 个、管理消息 0 条、群里没有任何答疑机制**——**运营者不在群里出现。**

## 三、核心发现二：用户在群里聊的不是机场

**样本中可见的发言形态：**

| 内容 | 性质 |
|---|---|
| 「有没有共享账号，下载小火箭」 | **求 App Store 外区账号** |
| 「屡试不爽，每时每刻都有大…」 | 使用体验 |
| 「@某人 给个链接」 | 互相要东西 |
| 一条裸 IP 地址 | **直接贴节点地址** |

**一个机场用户群里最高频的请求不是"节点怎么样"，而是"怎么下载客户端"。**

**这与本语料的 [ClashR_for_Windows_Channel](ClashR_for_Windows_Channel.md) 第三节形成呼应**——**那个号占据的正是"用户第一次下载客户端"的位置，并因此成为代理生态六层里变现最重的一环（176 个推广码）。**

**这个群的对话从需求侧验证了那个判断：下载客户端确实是用户的第一道坎，而且它比选机场更早、更普遍。**

**「共享账号」这个请求指向的是 App Store 外区账号**——**因为某些代理客户端只在特定区的商店上架。** **这条需求链恰好连到本语料的两个样本：[voice_google](voice_google.md)（卖各类平台账号）与 [Licensesss](Licensesss.md)（订阅拼车）。** **三个互不相关的样本，指向同一个由"地区限制"制造出来的市场。**

**一条裸 IP 地址的出现说明群里存在直接的节点分享**——**绕过订阅链接，直接给地址。** **这是机场运营者最不希望看到的行为（节点被滥用会加速被封），也解释了为什么它把客服挡在群外：群里发生的事它管不了，也不想管。**

## 四、核心发现三：0 个 bot、15.6% 的存活率

**本批十一个群里，只有三个的 bot 占比为 0：[PublicTestGroup](PublicTestGroup.md)（英文社交）、[BotTalk](BotTalk.md)（英文技术）、**和这个群。**

**前两个的存活率是 85.71% 与 40.21%，这个是 15.6%。**

**三个零 bot 的群，存活率差五倍多。** 本语料在 [BotTalk](BotTalk.md) 第四节确立的四种存活率成因里：

- [PublicTestGroup](PublicTestGroup.md) 靠**对话速度**（消息几秒被刷走，投广告不划算）
- [BotTalk](BotTalk.md) 靠**话题门槛**（英文技术问答）
- **ngcss 两样都不占**：12.5 条/天不算快，而"怎么下载客户端"的门槛极低。

**所以它的 15.6% 就是"没有治理"的自然结果**——**80 条/天进来，靠平台封号与用户自删消化掉 84%。**

**幸存内容里有 9 条粗筛命中**，本报告未逐条核验，**但结合群的形态（零治理 + 低门槛 + 机场用户群），这里出现机场互推或第三方广告的可能性不低。**

**82 个发言人里最活跃的一个发了 98 条（33%）**——**在一个零 bot、零管理的群里，一个人贡献三分之一的消息，这个人要么是热心用户，要么是运营者的马甲。本报告无法区分。**

## 五、实现技术思路

**这个群没有任何技术实现：零 bot、零置顶规则（可见范围内）、零标签、零文件托管（1 个贴纸）、零自有域名。**

**唯一的设计动作是群名里的那句话。**

**它与本语料的 [nexitallyusers](nexitallyusers.md)（机场用户群，已迁往认证私有群）是同一品类的两种选择：**

| | [nexitallyusers](nexitallyusers.md) | **ngcss** |
|---|---|---|
| 公开群的状态 | **空壳**（0.1 条/天） | **仍在用**（12.5 条/天） |
| 客服在哪 | 认证私有群 | **官网** |
| 治理 | 无（群已空） | **无（群没空）** |
| 结果 | 存活率 0.68% | 存活率 15.6% |

**两个机场都把核心服务移出了公开群，区别在于一个连群都放弃了，一个还留着当门面。**

## 七、收益

**群侧可观测：¥0。**

**300 条里没有可辨识的联盟参数、收款账号或推广码**（9 条粗筛命中未逐条核验）。

**机场本体的收益不属于本群，且「公益」这一自述使其更难估算。** 本报告不给数字，理由有三：

1. **"公益机场"在中文代理圈是一个有特定含义的说法**——通常指不盈利、靠运营者自费或小额捐赠维持、限量邀请。**但这个群有 2.43 万成员，这个规模很难用"自用小圈"解释。**
2. **本报告看不到官网**（客服在那里），**收费与否、价目、邀请机制全部不可观测。**
3. **本语料没有"公益机场"的可比样本。**

**唯一能说的：一个宣称公益的服务有 2.43 万人的用户群，这两件事之间存在张力，而本报告无法解释它。**

## 九、法律风险

**风险等级：高。**

- **提供翻墙服务（主要风险）。** 这是一个机场（代理服务）的用户群，**机场本体在中国法下落在《计算机信息网络国际联网管理暂行规定》第 6 条与《计算机信息网络国际联网安全保护管理办法》第 6 条上**；**若有经营行为且情节严重，触及《刑法》第 225 条非法经营罪。**
- **「公益」不是免责事由。** 本语料在 [zaproshare](zaproshare.md) 第九节论证过"免费不等于非经营"（那个号用免费节点换广告点击）。**这里更直接：即使真的分文不取，提供翻墙服务这一行为本身的行政违法性不因此消除**——**营利与否影响的是非法经营罪能否成立，不影响行政责任。**
- **群内的节点分享。** 样本中出现一条裸 IP 地址。**直接分享节点地址比分享订阅链接更进一步**，**且它绕过了机场自己的用量控制。** **发布者与放任其存在的群主都可能被评价。**
- **群主的管理义务：履行状况最差的一档。** 零 bot、零管理消息、零置顶规则、15.6% 的存活率——**与 [gouwu](gouwu.md)、[beijingz](beijingz.md) 同属"什么都不做"。** **而群名里那句「咨詢问题仅限官网右下角」在法律上是不利的：它证明运营者知道这个群存在但主动选择不在其中提供服务与管理。**
- **境内连接点明确。** 简体中文、服务对象是中国大陆用户、讨论的是绕过境内网络管控。
- **不适用**：不涉及开设赌场罪（可见内容 0 条博彩内容、0 个博彩域名）；不涉及传播淫秽物品罪（0 条成人内容）；不涉及侵犯著作权罪（无内容分发）；不涉及侵犯公民个人信息罪（无数据收集）。**"共享账号"的请求若成交，则涉及 [Licensesss](Licensesss.md) 第九节讨论的平台条款问题，但本群只见请求未见交易。**

**责任主体**：机场运营方（群名即服务名）与群主。**暴露面**：机场本体有官网（群名直接指出"官网右下角"有客服）——**那个官网是整条链路上最完整的身份锚点，而这个群反而几乎不留痕。**
