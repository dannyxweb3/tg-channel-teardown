> ⚠️ 本报告不复现主机商域名、优惠码、联盟参数值、自有短链与任何客服账号。
>
> **频道 · 11,819 订阅 · 0.48 帖/天 · 成熟中位阅读 5,964 · ERR 50.46% · 存活率 96.5%**
> 数据来源：`scripts/tg_recon.py dump vpscang --limit 300` → [data/recon/vpscang.jsonl](../data/recon/vpscang.jsonl)
> 抓取时间 2026-09-21 · 样本 300 条（2024-12-17 → 2026-09-03，跨度 625 天）

**一句话结论：这个频道把"默认带 aff"四个字写进了自己的名字里。样本中 `aff` 参数出现 144 次、`pid` 108 次，合计 252 个带归属标识的链接——比本语料此前的纪录保持者 [liyuans](liyuans.md)（119 个）多一倍。而那个样本零披露，这个样本的披露写在每一个人订阅之前就会看到的位置。本语料此前把广告披露排成八档，最好的一档是俄罗斯法律强制的广告标识；这个样本提出了一个不依赖法律强制、成本为零、却比 `#ad` 更彻底的做法：把它放进频道名。**

## 二、核心发现一：把披露写进频道名

**频道名里带着一个括号，括号里写着"默认带 aff"。**

**本语料的"广告披露八档"**（[creativemotion](creativemotion.md) 第五节确立）：

| 档 | 做法 | 样本 |
|---|---|---|
| 最低 | **零标注** | [askahh](askahh.md)、[liyuans](liyuans.md)、[Pojieapp](Pojieapp.md) |
| 1 | 免责声明 | [jichangtj](jichangtj.md)、[vps_xhq](vps_xhq.md) |
| 2 | 行内标签 | [merlinclashcat](merlinclashcat.md)、[weekly_books](weekly_books.md) |
| 3 | `#ad` | [tginfoen](tginfoen.md) |
| 4 | **转发自名为「付费广告」的频道** | [speedcentre](speedcentre.md)、[sharecentre](sharecentre.md) |
| 5 | 为平台自身的广告免责 | [ACL4SSR](ACL4SSR.md) |
| 6 | **法定广告标识** | [creativemotion](creativemotion.md) |

**这个样本提出第七档，而它的位置在谱系之外：**

> **不是标注单条内容，是标注整个账号。**

**三者的差别可以直接比较：**

| 做法 | 读者什么时候知道 | 能不能漏掉 |
|---|---|---|
| `#ad` 标签 | **看到那条内容时** | **能**（没标的那条就不知道） |
| 转发自「付费广告」 | 看到那条内容时 | 能 |
| **写进频道名** | **订阅之前** | **不能** |

**本语料在 [speedcentre](speedcentre.md) 第五节测过第四档的代价（转发式广告的阅读只有该频道常态的 32%），并在 [sharecentre](sharecentre.md) 第二节复现过（57%）。**

**这个样本的做法没有那个代价：**

> **它不需要给单条内容贴标签，因此单条内容的表现不受影响。**
> **代价被一次性前置到了"要不要订阅"这个决定上。**

**而 ERR 50.46% 说明这个代价并不大。**

**本语料由此得到一条：**

> **广告披露的成本取决于它被支付的时点。**
> **逐条披露的成本按条累加，账号级披露的成本只付一次。**
> **后者对高广告密度的账号（本样本 27.3%）明显更划算，而它同时更彻底。**

**这条判断有一个前提：账号级披露只有在广告密度本来就高的时候才成立。** **一个偶尔接广告的账号把"带 aff"写进名字，反而是自我伤害。**

**它也解释了为什么本语料此前没有见过这一档：** **本语料的高广告密度样本（[askahh](askahh.md) ≈100%、[Pojieapp](Pojieapp.md) 100%、[liyuans](liyuans.md) 20%）全部选择了零披露。**

**而这个样本与 [liyuans](liyuans.md) 的对照尤其干净：**

| | [liyuans](liyuans.md) | **vpscang** |
|---|--:|--:|
| 品类 | **VPS / 主机推广** | **VPS / 主机推广** |
| 联盟参数 | 119 | **252** |
| 披露 | **零** | **写进频道名** |
| 订阅 | 14,311 | **11,819** |
| **ERR** | **19.77%** | **50.46%** |
| 评论/帖 | 2.1 | **8.9** |

**同一个品类、更高的广告密度、更彻底的披露，而参与度高出 2.5 到 4 倍。**

**本报告不主张披露导致了高参与度**——**两个账号在内容深度、更新节奏、自有工具上都有差异（第三节）。**

**但至少可以排除一个直觉：披露没有损害这个账号。**

## 三、核心发现二：一个有自有工具的推广号

**域名构成里有四个属于运营者自己：一个主站、一个短链域、一个测速工具、一个另一个工具子域，合计 112 次。**

**加上 `t.me` 130 次（指向 6 个自有或关联账号，最高 28 次），这个账号的自有资产引用超过外部主机商的总和。**

**本语料的 VPS 推广样本对照：**

| | [liyuans](liyuans.md) | **vpscang** |
|---|---|---|
| 自有域名 | **归属存疑**（初稿误判，已更正） | **四个，合计 112 次** |
| 自有工具 | 无 | **测速 + 另一个工具** |
| 自有短链 | 无 | **有（17 次）** |
| 内容 | 促销转贴（正文中位 213 字） | **自撰评测（正文中位 242 字、max 3,235）** |

**"自有测速工具"这一项值得单独记。**

**本语料在 [askahh](askahh.md) 第八节确立过一条：**

> **这类"测评号"的准入门槛不是流量，是测试环境。**

**那个样本的测试环境是六个省份的千兆线路（用于测机场）。**

**这个样本的测试环境是一个自建的网络测速页面（用于测主机）。**

**两者的共同点是：测评的可信度需要一个可复现的工具作为支撑，而那个工具本身就是护城河。**

**自有短链（17 次）的用途在第四节。**

**本语料在 [wublock](wublock.md) 第二节把"自有域名"分成短域名（收口与计数）与完整域名（品牌露出）两支。**

**这个样本同时用了两支：完整域名做品牌（主站 27 次），短链域做收口（17 次）。**

**这是本语料第一个同时使用两支的样本。**

## 四、核心发现三：252 个归属标识的结构

**参数分布：`aff` 144、`pid` 108、`target` 41、`gid` 30、`vps_provider` 13、`region` 9。**

**本语料的联盟参数密度排名：**

| 样本 | 归属参数 | 密度 |
|---|--:|--:|
| **vpscang** | **252** | **0.84/帖** |
| [liyuans](liyuans.md) | 119 | 0.40/帖 |
| [sharecentre](sharecentre.md) | 40 | 0.13/帖 |
| [xuehuashe](xuehuashe.md) | 1 | 0.003/帖 |

**0.84/帖意味着几乎每一条内容都带着一个分成标识。**

**而 `target`、`vps_provider`、`region` 这三个参数不是联盟网络的标准字段**——**它们看起来是自有短链服务的内部参数。**

**这说明链路是两段的：**

> **读者点自有短链 →（带上 `target` / `vps_provider` / `region` 等内部标记）→ 跳转到主机商，并在那一跳带上 `aff` 与 `pid`。**

**本语料在 [hacker_news_feed](hacker_news_feed.md) 第二节确立过"链接处理六档"的第六档（自有短域名收口），并在 [wublock](wublock.md) 第二节把它分成两支。**

**这个样本给第六档补上一个此前没有的用途：**

> **短链不只是收口与计数，它还是一个可以随时改指向的中间层。**
> **主机商换了联盟计划、换了域名、或者跑路了，运营者只需要改短链的目标，而历史帖子里的链接不用动。**

**对一个跨度 625 天、存活率 96.5%（几乎不删历史帖）的账号而言，这一层是必要的：**

**没有它，两年前的那些推广链接今天大概率已经失效。**

**本语料由此得到一条：**

> **长期不删历史内容的推广号，必须有一个自己可控的跳转层。**
> **否则它的历史内容会随着上游变动而逐条失效，而它又不删帖。**

**这条判断反过来解释了 [liyuans](liyuans.md) 的做法：** **那个账号用的是原始域名 + 联盟参数，没有跳转层，而它的存活率是 96.2%——同样不删帖。** **两个账号在同一个问题上做了相反的选择，而本报告无法判断哪一个的历史链接失效率更高。**

## 五、其余维度

**实现技术思路：自撰评测 + 自有工具 + 自有跳转层 + 多账号矩阵。**

| 层 | 做法 |
|---|---|
| 内容 | **自撰促销与评测**（正文中位 242 字、max 3,235） |
| 工具 | **自建测速页与另一个工具子域**（68 次） |
| 跳转 | **自有短链**（17 次，带内部参数） |
| 矩阵 | **`t.me` 130 次指向 6 个账号**（最高 28 次，含一个补货提醒专用号） |
| 标签 | **`#补货` 13 + 主机商名 13** ——**补货提醒专题** |
| 互动 | 反应 + 评论全开（1,511 条） |

**标签体系值得一提：`#补货` 与某主机商名各 13 次，且两个编号标签也各 13 次**——**四个标签同时出现 13 次，说明它们是一组固定搭配，用于标记同一类内容（某个热门主机商的库存补货提醒）。**

**本语料的"标签十五用"**（[tdlibchat](tdlibchat.md) 第四节确立第十五种）**中，这属于"分类"这一基础用途，但它的应用场景很具体：库存提醒是有时效的，标签让读者能回查"上一次补货是什么时候"。**

**`t.me` 中最高频的一个账号（28 次）超过了自指（27 次）**——**这在本语料是罕见的：一个账号引用另一个账号的次数超过引用自己。**

**结合转自字段（4 个频道各 1 次，其中一个是本语料已收录的 [zrj96](zrj96.md)），可以确认这个账号处在一个主机圈的引用网络里。**

**本语料在 [liyuans](liyuans.md) 第四节第一次观察到两个已分析样本之间的内容流动（[zrj96](zrj96.md) 与 [liyuans](liyuans.md) 共享主机评测信源）。**

**这是第三个节点：** **[zrj96](zrj96.md) → [liyuans](liyuans.md)、[zrj96](zrj96.md) → vpscang。**

**本语料由此第一次在中文主机评测这个细分领域里画出一个三节点的可见网络，而其中两个节点带联盟参数（119 与 252），一个不带（[zrj96](zrj96.md) 的 450 条链接零自有标识）。**

> **同一批内容流过三个账号，而它们对"要不要在链接上留下自己的标记"做了不同的选择。**

**成本（月）：¥100–800。** 自有主站 + 短链域 + 两个工具子域需要域名与托管；测速工具需要服务器。**内容成本：0.48 帖/天 × 242 字中位，含核价、整理规格、写评测。**

**收益：¥8,000–50,000/月。** **这是本语料最高的估算区间，四条依据：**

1. **252 个归属标识 / 625 天，密度 0.84/帖**——**是 [liyuans](liyuans.md)（0.40/帖）的两倍。**
2. **ERR 50.46% + 单帖 5,964 阅读**——**触达质量是 [liyuans](liyuans.md)（19.77% / 2,829）的两倍以上。**
3. **评论 8.9 条/帖（1,511 条）说明读者在认真比较**——**而在主机采购这个品类里，认真比较的读者就是高意向客户。**
4. **上锚受 0.48 帖/天压制**，**且主机联盟的结算方式（首单一次性 vs 按月分成）不可观测，这是区间宽的主因。**

**本语料在 [liyuans](liyuans.md) 第八节估过 ¥5,000–35,000/月。** **按参数密度与触达质量的双重倍数关系，这个样本的合理区间应当更高，而下锚 ¥8,000 正是那个推算的结果。**

**增长：1.18 万订阅来自内容 + 那个三节点引用网络。** 转发均值 13.5、max 203；零买量迹象（ERR 50.46% + 1,511 条真实评论）。

**频道名是"靠谱 VPS 推荐"+ 品牌名 + 披露声明的组合**——**本语料"关键词占位十八种形态"中的"品类词 + 形容词"，而它多带了一个此前没有的元素：把商业性质写进名字。**

## 六、法律风险

**风险等级：中。** 与 [liyuans](liyuans.md) 第十节同档，但披露状况显著更好。

- **推广的商品本身合法。** VPS、独立服务器、云主机是完全合法的商业服务。**这是它与本语料 [askahh](askahh.md)（机场推广）、[sharecentre](sharecentre.md)（机场 + API 转售）的根本区别。**
- **广告可识别性：本语料表现最好的一个。** **《广告法》第 14 条要求广告应当具有可识别性。** **把"默认带 aff"写进频道名，使每一个潜在读者在订阅之前就知道这个账号的商业性质**——**这在形式上满足甚至超过了该条的要求。** **本语料的"广告披露八档"中，除了俄罗斯法律强制的标识（[creativemotion](creativemotion.md)），这是披露最彻底的一个，而它是自愿的。**
- **但需要指出一个限制：账号级披露不能替代对具体内容的真实性要求。** **《广告法》第 28 条规制虚假宣传**——**帖文中包含具体的规格、价格、线路与促销条件，若与实际不符仍可能被评价。** **1,511 条评论构成一个事实上的纠错机制。**
- **自有短链的跳转层。** 它使运营者能够随时改变链接目标。**这在技术上是正当的运营手段；但若被用于把读者从一个声称的目标导向另一个目标，则可能构成《广告法》第 28 条意义上的引人误解。** **本报告没有发现此类迹象，仅记录这一能力的存在。**
- **未见"机场主"类定位。** 本语料在 [liyuans](liyuans.md) 第十节识别过一个实质风险点（该账号的标签明示目标客户包含代理服务运营者，构成帮信罪"明知"的直接证据）。**这个样本的标签体系里没有同类表述**——**这是它与那个样本在法律风险上的关键差别。**
- **自建测速工具。** 它会收集访问者的网络测量数据。**若涉及 IP 地址等可识别信息的留存，落在《个人信息保护法》第 13、17 条下。** **本报告看不到其隐私政策。**
- **境内连接点明确。** 简体中文、受众为中国大陆技术用户、推广的多为面向大陆优化的线路、自有测速工具服务于大陆网络环境。
- **不适用**：不涉及开设赌场罪（0 条博彩内容、0 个博彩域名、0 个客服号）；不涉及传播淫秽物品罪（0 条成人内容，51 张图片为测速图与规格表）；不涉及侵犯著作权罪（内容为自撰评测，转载有来源）；不涉及侵犯公民个人信息罪的频道侧（无 bot、无表单）；**不涉及直接提供翻墙服务**（0 个机场域名、0 个订阅链接、0 个节点——**它卖的是空服务器**）。

**责任主体**：频道运营者（拥有主站、短链域与两个工具子域，**本报告不复现**）。**暴露面：四个自有域名的注册信息、多家主机商的联盟结算记录、以及一个把商业性质写在名字里的公开账号。** **本语料在 [daily5kong](daily5kong.md)、[newmobilelife](newmobilelife.md)、[EZwalls](EZwalls.md) 三次观察过"实名不是合规成本，是产品本身"，这是第四个实例，而且是最主动的一个：它公开的不只是身份，还有利益关系。**
