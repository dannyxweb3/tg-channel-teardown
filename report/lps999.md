## 二、技术实现

### 2.1 架构

```
汉化源（F95zone 等英文站 → 汉化组/资源站）
   → 打包成 Android APK（Ren'Py / RPGM 安卓构建）
   → 每款游戏 = 5 条消息：4 张截图(album) + 1 个 APK(document)
   → 定时批量投放（每月 4 批，每批 17-21 款）
   → 约 3 周后整批删除
   → footer 常驻引流到自有私有群 + 两个常驻联盟广告位
```

### 2.2 Telegram 当免费无限 CDN

**这是全部经济性的基础。** 当前窗口 82 个文件、**102.76 GB**，全部以 document 直传 Telegram：

```
暮色之境 1.7.apk           2694.4 MB
巨人守护者 0.4.10.apk       2742.3 MB
魔咒林渊-粉丝扩展包 0.8.9.1  2251.8 MB
异世界乐园 v0.9.apk         2174.0 MB
```

中位单包约 1.2 GB。100 GB 存储加每月数百 GB 出站，托在任何网盘或对象存储上都是一笔硬成本，在 Telegram 上是 **0 元**。没有这一条，这门生意不成立。

### 2.3 滚动删除：97% 的历史被主动抹掉

消息 ID 已到 **12,990**，现存只有 **390 条**。中间 `id 1547 → 12642` 一刀切掉 **11,095 条**，覆盖 2024-11 到 2026-08 整整 21 个月。

这一招同时干三件事：

1. **降低被举报面** —— 存量越少，被扫到的表面积越小
2. **制造稀缺** —— 错过这批就没了，逼用户留在频道蹲下一批
3. **把人挤进私域** —— 要补档只能去他自己的群

### 2.4 双消息结构：文案与引流分开承载

| 消息 | 内容 |

footer 里三个私有邀请链接在 42 条帖子里**逐字重复**——模板化注入。
