## 二、核心发现一：一份逐分钟的安全事故复盘

**2025-07-06 的公告（96,676 阅读，106 条评论）是本轮所有样本里技术披露最完整的一份文档。**

> 這次嗶咔受到的攻擊性質惡劣，**涉及敏感政治內容**，給大家帶來了極壞的影響。作為一向**不談政事，只談風月**的平台，我們有不可推卸的責任。

**事件时间线（原文照录）：**

```
7月1日
  0:30 - 廣告系統遭到惡意攻擊，內容被非法篡改
  7:30 - 管理人員發現異常          ← 距被攻破 7 小时
  7:33 - 聯繫 CDN 服務商請求技術支援
  7:46 - CDN 服務商配合暫停域名解析
  8:25 - 伺服器緊急下線，問題得到控制
 10:00 - 發現客戶端快取問題，相關模組全面下線
7月2日–7月5日  僅保持核心功能運行 / 對廣告系統進行完整重構 / 全面審查系統日誌和安全漏洞
7月5日  新系統完成部署
```

**根因披露：**

> 此次攻擊的根本原因是嗶咔的**廣告系統存在安全漏洞**。攻擊者透過持續的 **API 密鑰爆破攻擊**，最終獲得了系統存取權限，並惡意替換了廣告內容。

**这份文档有三处值得单独拆解：**

**2.1 「7 小时」是这份复盘里最刺眼的数字**

**0:30 被攻破，7:30 才被发现。** 一个月活以十万计的平台，**在凌晨没有任何自动告警。** 后续的应急响应很快（发现后 3 分钟联系 CDN、16 分钟暂停解析、55 分钟服务器下线），**说明团队有能力，缺的是监控。**

**改进措施里"盡可能保證 24 小時安全檢查"这句话反过来证实了这一点** ——之前没有。

**2.2 它专门澄清了两个技术误解，说明社区在质疑它的立场**

> **1）關於 URL 參數疑問**：URL 中「?」後面的 GET 參數是可以任意添加的技術特性…這些參數可以被任何人隨意編寫，與網站營運方的立場無關。攻擊者在篡改廣告內容時，同樣可以在連結中添加任何內容。**這確實不能作為判斷我們立場的依據。**
>
> **2）關於 DNS 傳言**：實際情況…是我們**主動請求 CDN 服務商暫停域名解析，這是標準的應急止損措施，而非 DNS 被劫持。**

**第一条尤其关键。** 被注入的政治内容里，**URL 参数被用户当成了平台立场的证据。** 平台不得不出来解释"GET 参数谁都能写"——**这说明事件已经从技术故障演变成了信任危机。**

**2.3 「不談政事，只談風月」是它的核心生存策略，而攻击正好打在这一点上**

**对一个面向中文用户的境外成人平台来说，色情内容带来的是常规风险，政治内容带来的是灭顶风险。** 攻击者选择注入政治素材而非色情素材或恶意软件，**这个选择本身说明攻击是针对性的，而不是随机的牟利行为。**

**这也解释了它为什么要发这么长一份复盘**：**它需要在用户面前把"我们被攻击了"和"我们改立场了"彻底切割开。**

## 三、核心发现二：一份公开的财务纠纷

**2024-10-10 的公告（192,336 阅读，287 条评论）披露了一起内部治理事件，信息量同样很大：**

> 因之前遊戲區使用百度網盤連結經常出現問題，**自 2019 年起，嗶咔漫畫直接授權維咔營運遊戲區**，由維咔方提供所有下載連結並負責其開支。
>
> 作為連接二者的其中一位管理…嗶咔方一向對厄夜給予高度信任，**亦有每月向厄夜提供一定金額的援助。**
>
> ① 厄夜單方面以自己嗶咔代表的身份…向維咔進行各種不合理的施壓和索取，並從中獲利，比如**要求所有廣告位的對接由他負責，並要求在其中有所分成。**
> ② 厄夜以伺服器營運不順為由，向嗶咔團長索取每月一定金額的援助，事後嗶咔和維咔對賬時，雙方發現**厄夜這筆收入從未告知維咔，表明這筆資金從未投入至伺服器開支，而是由他本人收下。**
> ③ 在上述事件發生後，厄夜透過其 QQ 空間、Telegram 頻道等發表所謂的「公告」，**造謠遊戲區內容充斥著病毒木馬**…進一步改成「廣告、遊戲包都有病毒，必須透過 **9008 刷機**才可清除」。

**这份公告意外地暴露了整个平台的商业结构：**

| 披露 | 含义 |
|---|---|
| 2019 年起把游戏区**授权**给另一方运营 | **它是分层外包的，不是单一团队** |
| 对方"提供所有下载链接并**负责其开支**" | **成本由合作方承担，换取运营权** |
| **每月向中间人提供"一定金额的援助"** | **存在持续的现金支出** |
| 中间人索要**广告位对接与分成** | **广告位是有价值、可分成的资产** |
| 双方"**对账**"发现资金去向不明 | **有账可对，说明有正式的财务往来** |

**关于广告的部分更直接：**

> 目前遊戲區的廣告問題是客觀存在的…**經常會出現的彈窗廣告，是因為維咔方對接的廣告商指定的 JS 文件中會隨機播放此種廣告，之前被痛罵的「短訊驗證碼騙話費」廣告也在其中**，維咔方後來也要求廣告投放方不再投此類廣告。
>
> 嗶咔團長經過與維咔方**比對賬單流水**後，確認了維咔方的確**需要投放廣告來維持基本的下載和遊戲儲存**，因此也不存在「打廣告出發點就是為了牟利賺錢」的說法。

**"短訊驗證碼騙話費"广告曾经出现在它的游戏区** ——**这是明确的诈骗类广告。** 平台的说法是广告商的 JS 随机投放、事后已要求停投。**但这暴露了一个结构性问题：把广告位外包给第三方 JS，就等于把内容审核权交了出去。§二 的攻击正是发生在广告系统上——同一个薄弱环节被打了两次。**

**这也反过来限定了它的变现空间**：**它把"永久免费"写进了品牌承诺，就再也不能向用户收费。**（收益分析见 §七）

**它的变现结构与本轮所有其他样本都不同：**

**平台侧广告收入的量级**：无法从样本估算，**但可以从成本反推下界** ——**一个每月现金支出上万到十几万的平台，持续运营四年以上，广告收入至少要覆盖这个量级。**

**频道本身的广告承载力**（若它愿意在频道内接广告）：19.1 万订阅、中位阅读 119,458、月发约 6 条、**月曝光约 72 万次**。**ACG 类 CPM 参考 ¥40–100，但它的受众属性使多数正规广告主不会投放：**

> **月度广告承载力约 ¥29,000–72,000（若接广告）。**

**区间宽的三个原因**：(1) 无任何报价信息；(2) **内容属性把广告主池子压缩到只剩同类平台与灰产**，实际成交价与名义 CPM 会严重偏离；(3) **0.19 条/天的极低频让广告位稀缺，但也意味着总量上不去。**

**它在频道内零广告，是刻意的**：**这个频道是官方公告渠道，是"辨别真假"的锚点（§四）。在这里插广告，等于自毁那份防诈骗声明的公信力。**

## 十、法律风险

> **level: criminal（本轮最高）。**
>
> **1｜传播淫秽物品牟利罪（核心）。** 嗶咔漫畫是面向中文用户的成人向漫画平台。中国大陆《刑法》第三百六十三条：**以牟利为目的，制作、复制、出版、贩卖、传播淫秽物品的，处三年以下有期徒刑…情节严重的处三年以上十年以下**；第三百六十四条为不以牟利为目的的传播。
>
> **"牟利"这一要件在本案中成立**：平台虽对用户免费，但公告明确承认游戏区有广告收入、广告位可对接可分成、且存在"对账流水"。**《关于办理利用互联网、移动通讯终端、声讯台制作、复制、出版、贩卖、传播淫秽电子信息刑事案件具体应用法律若干问题的解释》明确规定，以在网站上刊登收费广告等方式直接或间接收取费用的，属于"以牟利为目的"。**
>
> **情节认定上，19.1 万 TG 订阅只是其用户盘的一部分**，实际注册用户量级更大。**司法解释中"传播淫秽电子信息实际被点击数达到二万次以上"即属情节严重——本平台远超此数量级。**
>
> **责任主体**：平台运营团队（公告中自称"嗶咔團長""嗶咔漫畫工作組"）、游戏区受权运营方、以及本频道的管理者。**这是本轮唯一一个应当标记为 criminal 而非 high 的样本。**
>
> **2｜内容中的未成年人题材风险。** 成人向漫画品类普遍存在低龄化角色设定。**本次样本为频道公告与运营信息，未捕获作品内容，无法评估。** 但依中国大陆的从重处理原则，**若平台内容涉及此类题材，量刑将显著加重。这是本报告未能覆盖、且潜在后果最严重的一项。**
>
> **3｜广告链条中的诈骗类内容。** 公告自认游戏区曾出现「短訊驗證碼騙話費」广告，**这是典型的话费诈骗。** 平台的解释是广告商 JS 随机投放、事后已要求停投。**但《刑法》第二百八十七条之二帮助信息网络犯罪活动罪的构成要件是"明知他人利用信息网络实施犯罪而为其提供广告推广"——一旦被投诉后仍未彻底切断该广告源，"明知"即成立。** 公告表明它已知情并采取了措施，这是有利情节。
>
> **4｜被攻击注入政治内容（2025-07）。** 平台是受害方，且已完成完整复盘与系统重构。**中国大陆《网络安全法》第二十一条要求网络运营者履行安全保护义务、第二十五条要求制定应急预案——从事故记录看，它在被攻破 7 小时后才发现异常，事前监控明显不足。** 但由于平台本身在境外运营，该行政责任的实际适用有限。**列此项主要是为了说明：政治内容注入对这类平台是灭顶级风险，远重于其本业的色情内容风险。**
>
> **5｜企业证书分发与平台服务条款。** 使用企业签名证书向公众分发 App 违反 Apple Developer Enterprise Program 协议，**属合同违约，后果是证书吊销**（样本内"有效时间：随机"即其体现）。**不构成中国大陆法律下的独立罪名。** 已转向网页版后，此项风险自然消解。
>
> **6｜被冒用的一方。** §四 的防诈骗声明显示存在大量冒用其品牌进行收费的行为。**在这些交易中，嗶咔是被侵权方（商标/商誉），受害者是被骗的用户。** 但它无法通过任何法律途径维权——**因为它自身的业务在中国大陆法律下不受保护。这是这类平台的结构性困境：它的品牌越有价值，被冒用得越厉害，而它越无从主张权利。**
>
> **不适用的两条**：不涉及侵犯著作权罪的直接指控（平台内作品的授权状态样本无法核实，但该项风险显著轻于第 1 项）；不涉及非法经营罪的典型情形（无支付通道业务、无出版物销售、对用户不收费）。
