## 二、核心发现一：5.4% 的删除率，因为索引层在自己手上

**本语料的盗版资源号删除率谱系：**

| 频道 | 删除率 | 分发架构 |
|---|--:|---|
| [googlevoice](googlevoice.md) | 99.9% | 单一渠道 |
| [google_drive](google_drive.md) | 99.4% | 单一渠道 |
| [shareAliyun](shareAliyun.md) | 99.0% | **单一网盘** |
| [zaproshare](zaproshare.md) | 20.8% | 自有站 + 直接托管 |
| [vip115hot](vip115hot.md) | 2.9% | **四网盘冗余** |
| **yeqingjie_GJG666** | **5.4%** | **7 网盘 + 自建 Alist 索引** |

**本语料此前在 [vip115hot](vip115hot.md) 确立过"删除率由分发渠道的冗余度决定"（四网盘 → 2.9%，单一网盘 → 99.0%）。这个号是那条规律的第二个验证，而且多了一层：索引。**

**每帖的网盘数量分布：**

```
1 个  232 帖    2 个  55 帖    3 个  11 帖    4 个  1 帖    5 个  1 帖
```

**77% 的帖子只给一个网盘链接——冗余不在单条帖子里，在那 80 条指向自建 Alist 的链接里。**

**Alist 是一个把多个网盘挂载到同一个网页目录下的开源程序。** 它的作用是：**用户访问一个自有域名，就能浏览挂在后面的所有网盘的文件。** 这带来三个后果：

1. **单一网盘被封不致命**——换一个挂载源，前台目录不变。
2. **链接不会失效**——帖子里给的是自建域名的路径，而不是网盘的分享链接（后者会过期、会被举报删除）。
3. **删除率因此降到 5.4%**——**没有必要撤帖，因为帖子里的链接还能用。**

**这解释了一个本来矛盾的现象：** 一个分发了 300 部动画的号，**几乎不删帖**。**对照 [shareAliyun](shareAliyun.md) 的 99.0%——那个号把命交给了一家网盘，网盘删一次它就得撤一次。**

**代价是自建 Alist 需要一台服务器和一个域名，而这两样都是实名的（见第九节）。** **把风险从"内容被删"转移到了"主体被找到"。**

## 三、核心发现二：545 字的标准元数据块

**300/300 条帖都有正文，中位 545 字，最长 1,023 字。** 格式完全固定：

```
<中文名> <原名> (<年份>) [<片源规格>]

◎又  名: …
◎年  代: …
◎产  地: …
◎类  型: …
◎评  分: <豆瓣或 TMDB 分数>
◎IMDb : tt…
◎语  言: …
◎简  介: …
```

**这是影视资源站的标准元数据模板**，字段用全角空格对齐。**545 字的中位长度里，绝大部分是这个块**——**运营者不写自己的话，只搬元数据。**

**片源规格是这个号的差异化**：样本中反复出现 `REMUX Blu-ray`、`BD-REMUX`、`4K`、`1080P`。**REMUX 指从蓝光原盘无损提取、不重新编码**，是画质最高的一档，**文件体积通常是普通压制版的 5–20 倍。**

**这决定了它的受众：不是"想看"的人，是"要收藏"的人。** 数据支持这个判断：

- **转发中位 12**（对 22,270 订阅即 0.054%），**在本语料的资源号里偏高**——**收藏向的资源值得转给同好。**
- **评论覆盖 54%（162/300）、合计 567 条**——有人在讨论。
- **ER 只有 0.08%**——**读者不点表情，他们去下载了。**

**标签体系是双层的：** `#动画` 180 + `#爷青回` 180（品牌标签，覆盖 60%）、`#动画电影` 67、`#动漫` 60，外加类型标签（`#剧情` 18、`#动作` 16、`#冒险` 15、`#奇幻` 15、`#科幻` 14）与 IP 标签（`#LEGO` 9、`#乐高` 9、`#DC超级英雄` 8）。

**`#爷青回` 出现 180 次且与 `#动画` 完全同步**——**这是把频道名做成标签，每帖都打**。本语料此前记录的自我标注多在页脚（[thinkpositivewords](thinkpositivewords.md) 的 213 次署名），**用标签做品牌是另一种做法：它让频道内的搜索可以按品牌过滤。**

## 四、核心发现三：`菠菜` = 菠菜

**黑话粗筛命中 7 类，逐条核对全部是误报，其中一条值得单独记：**

| 命中词 | 灰产语义 | 本样本的实际语境 |
|---|---|---|
| **菠菜**（5 次） | **「博彩」的谐音代称** | **「一说到菠菜，很多人的第一反应就是大力水手…」——某部 1933 年动画的剧情简介** |
| 一手（3 次） | 一手资源 | 「曾**一手**毁灭某行星的宇宙最大恶魔」——某部动画的剧情简介 |
| 夸克（56）/ 阿里云盘（50）/ 迅雷（3） | 网盘黑话 | **真实命中**——确实是网盘名，但这是正常的资源分发用语，不是灰产 |
| 提取码（11） | 网盘提取码 | **真实命中** |
| 磁力（5） | 磁力链接 | 真实命中 |

**`菠菜` 这一条是本语料最完整的一次同形异义演示。** 在中文灰产语境里 `菠菜` 是「博彩」的谐音（本语料在 [fufeikc](fufeikc.md)、[inside1024](inside1024.md) 记录过），**而在这里它就是蔬菜——而且是被一部经典动画带火的那种蔬菜，剧情简介里写得明明白白。**

**误报谱系至此 17 类。** 本例与本语料此前记录的「剧情简介误报」（豆瓣的暗中合作/加盟/投放）同属一类，**但这一条更极端：命中的不是一个碰巧同形的普通词，而是一个专门用来规避关键词过滤的谐音代称。** **灰产为了躲开"博彩"二字选了"菠菜"，结果撞上了真的菠菜。**

**方法论上的推论：谐音代称类黑话的误报率可能高于直白黑话。** 因为谐音代称之所以被选中，正是因为它是一个常用词——**常用词在正常语料里出现的频率本来就高。**

## 五、实现技术思路

**完整架构：**

```
片源获取（REMUX / BD 原盘）
      ↓
上传到 7 个网盘（阿里云盘为主 173，夸克 59，115 系 46，迅雷/百度/PikPak/123 各 3–8）
      ↓
挂载到自建 Alist 索引（80 条链接，一个自有域名）
      ↓
Telegram 发布（海报 + 545 字元数据 + 链接 + 提取码）
      ↓
一个查询 bot（被 @ 223 次）+ 一个频道 bot（42 次）
```

**两个 bot 是这个号的检索层。** `@` 提及统计里：频道自身 283 + 275（页脚双署名），**一个查询 bot 223 次、一个频道 bot 42 次。** **223 次意味着约 74% 的帖子在页脚附了查询 bot**——**读者可以在 bot 里搜片名，而不是在频道里往回翻 300 条。**

**这是本语料"资源号 + 检索 bot"的第一个完整样本。** 对照：

| 频道 | 检索方式 |
|---|---|
| [shareAliyun](shareAliyun.md) | 只有频道内搜索 |
| [vip115hot](vip115hot.md) | 一个搜索 bot（被 @ 259 次） |
| [zaproshare](zaproshare.md) | 自有站的资源页 |
| **yeqingjie_GJG666** | **自建 Alist 目录 + 两个 bot** |

**三层检索（频道标签 / bot 查询 / Alist 目录）互为备份**——**这是整个架构里最值得注意的设计：它不只对"内容被删"做了冗余，对"用户找不到"也做了冗余。**

**自动化程度：低。** 间隔中位 49,829 秒（13.8 小时）、`<60 秒` 占 30%（成批发）、最大间隔 124 天；无 cron 指纹。**元数据块虽然格式统一，但来源是影视数据库的现成条目，复制即可。**

**发布极不均匀：** 2025-09 一个月发了 52 条（占样本 17%），而 2025-11、2026-05、2026-07 各为 0。**这是"攒一批发一批"的节奏。**

## 九、法律风险

**风险等级：刑事。**

- **侵犯著作权罪（《刑法》第 217 条）——构成要件明确。** 300 条帖分发日本与欧美动画作品的完整片源，**且以 REMUX / BD 原盘为主（从正版蓝光无损提取）**。
  - **「未经著作权人许可、复制发行」**：上传到 7 个网盘即是复制，提供链接与提取码即是发行。
  - **「通过信息网络向公众传播」**：第 217 条第（六）项直接命中。
  - **片源规格是加重情节**：REMUX 意味着源自正版蓝光，**对权利人的市场替代性远高于低码率压制版。**
  - **「以营利为目的」是唯一的争点，而本案很可能不成立**——第七节已论证零变现、零广告、零收款、且运营者在自掏七家网盘会员费。**这是本案与 [zaproshare](zaproshare.md)（营利目的有书面证据）最重要的区别。** 但需注意：2020 年《著作权法》修订后，**民事侵权与行政处罚不以营利为要件**，《著作权法》第 53 条的行政责任仍然成立。
- **自建 Alist 索引使运营者从"分享者"变成"服务提供者"。** 这是本案最关键的定性升级：
  - 只发网盘链接的号（如 [shareAliyun](shareAliyun.md)）在民事上尚可主张自己只是提供链接。
  - **而运行一个自有域名的 Alist 站，等于自己搭建并运营了一个作品目录与访问入口**——**这是直接提供作品的行为，不是提供链接。** 《信息网络传播权保护条例》下的"避风港"规则对自建服务不适用。
  - **域名与服务器是实名的。** 这是整个架构里最脆弱的一点：**它把"内容被删"的风险换成了"主体被锁定"的风险。**
- **两个 bot 的角色。** 查询 bot 需要持有一份完整的资源索引库。**它同时是分发工具与证据库**——一旦被取证，**bot 的数据库直接构成"传播作品数量"的完整清单**，而这正是《关于办理侵犯知识产权刑事案件具体应用法律若干问题的解释》里认定"情节严重"的核心数据。
- **删除率 5.4% 在法律上是不利的。** 本语料记录过删除率的多种成因（[Hao12News](Hao12News.md) 第九节），**但对侵权内容而言，几乎不删意味着没有任何"通知—删除"的执行记录**——**在被通知后未删除的情形下，这会直接削弱免责空间。**
- **境内连接点明确。** 网盘全部是中国大陆的服务（阿里云盘、夸克、115、迅雷、百度、123），**提取码模式、简体中文、豆瓣评分**——**受众与基础设施都在境内，中国法有完整的管辖基础。** 网盘账号的实名信息是运营者身份的直接暴露点，**而这里有七个。**
- **不适用**：不涉及开设赌场罪（0 条博彩内容、0 个博彩域名、0 个客服账号；`菠菜` 5 次命中全部是剧情简介里的蔬菜，见第四节）；不涉及传播淫秽物品罪（内容为公开发行的动画作品，无成人内容）；不涉及帮助信息网络犯罪活动罪（0 个收款账号、0 个联盟参数、0 条商业导流，1,308 天零商业行为）；不涉及非法经营罪（**零收入，经营要件不成立**——这一条与 [zaproshare](zaproshare.md) 形成明确对照）。

**责任主体**：频道运营者。**暴露面是本语料盗版分发号里最大的一个**——**七个实名网盘账号、一个自有域名、一台运行 Alist 的服务器、两个绑定 Telegram 账号的 bot。** 对照 [sizukon](sizukon.md)（一个网盘账号）、[shareAliyun](shareAliyun.md)（单一网盘）——**冗余度换来了 5.4% 的删除率，也换来了五倍于同类的可追溯面。**
