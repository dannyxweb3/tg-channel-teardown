## 三、核心发现二：免费代理是引流钩子

**URL 参数统计里有三个成对出现的字段：**

```
server 22 | port 22 | secret 22
```

**`t.me/proxy?server=…&port=…&secret=…` 是 Telegram MTProto 代理的标准链接格式。** 样本内**11 条帖子**在发这类代理。

**原文（已脱敏）：**

> **高速代理增加 6️⃣ 条**　…　1️⃣ 常用机器人　🤖 [某]机器人　代理机器人　🤖 搜片机器人…
> 1️⃣号[某地运营商]代理　[某 bot 深链]　2️⃣号[某地运营商]代理　[某 bot 深链]

**两个细节值得注意：**

1. **代理按运营商与省份分号发布**（"1 号浙江移动代理""2 号…"）——**说明它在做线路质量区分，不是随手转发。**
2. **代理链接被包进自家 bot 的深链**（`t.me/[某bot]?start=HuoQu_[uuid]`）——**用户不能直接拿到代理地址，必须先进 bot。**

**第 2 点是整个引流结构的关键：免费代理不是送出去的，是用来把人导进 bot 的。**

**`t.me` 引用分布印证了这套体系：**

```
某工具 bot   38   ← 代理获取、资源分发
proxy        24   ← MTProto 代理链接
TGGameku     12   ← 游戏库
TGshuku       9   ← 书库
TGxue         8   ← 学（教程）
TGruanku      3   ← 软件库
其余零星      1–2
```

**`TGGameku` / `TGshuku` / `TGxue` / `TGruanku` 是「TG + 品类 + 库」的命名家族** ——**这是本轮识别的第五个矩阵**（此前：[在花](TestFlightCN.md)、[1024](aigc1024.md)、[kk](blacktechsharing.md)、[喵](appmew.md)）。
