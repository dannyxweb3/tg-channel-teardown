**`RPReplay_Final` 是 iOS 系统录屏（ReplayKit）的默认导出文件名**，`IMG_####` 与 `.MOV` 是相机胶卷。**四个文件全部来自同一部 iPhone，没有任何一个经过剪辑软件。** 这与频道主题自洽——QuantumultX 是一款 iOS 代理客户端，**维护者本人就在 iOS 上用它、录屏演示。**

## 五、实现技术思路

**产品侧**：一个订阅格式解析器（以脚本形式挂在代码托管平台，用户在客户端配置里引用其 URL）+ 一个订阅转换 API 站点（提供网页版与接口调用）。

**频道侧**：纯变更日志，零自动化。分钟/秒分布完全随机、166 条帖跨越六年、无任何 cron 痕迹——**每一条都是人手写的。**

**外链只有四个域名**：自有 API 站 13 次、代码托管平台的原始文件地址 7 次、代码托管平台 7 次、`t.me` 7 次。**另有两个明显是示例的伪域名**（出现在参数示范里，用来演示配置写法），**这是本语料第一次遇到"正文里的域名不是真实链接而是文档示例"**——域名统计在技术文档类频道上需要人工剔除示例。

**互动配置**：评论开、反应关、六年发过 1 次投票。**评论开而反应关是一个有意思的组合**——运营者要的是可回复的具体问题，不是一个笼统的态度表态。

**删除率 9.8%（18/184）**，id 差值分布里 `2` 出现 3 次、`5` 出现 2 次，**是零星删除，符合"发错/重复后撤回"。**

## 九、法律风险

**风险等级：中。** 工具本身中性，风险来自它在中国法下的用途关联。

- **为规避网络管控提供技术便利（主要争点）。** 解析器与订阅转换 API 的功能是把各种格式的代理节点订阅转换成某客户端可读的格式。**它本身不提供任何节点、不提供任何服务器、不收取任何费用**——它处理的是配置文本。按《刑法》第 285 条第 3 款，该罪要求工具"专门用于"侵入或非法控制计算机信息系统，**格式转换工具不符合这一要件。** 但《计算机信息网络国际联网管理暂行规定》第 6 条与《计算机信息网络国际联网安全保护管理办法》第 6 条的行政责任仍可能适用，**实务上对这类纯工具的处置通常是访问层面的屏蔽而非追究个人。**
- **与 [projectXtls](projectXtls.md) 的定性对照。** 那个项目提供的是协议实现（更上游、更核心），本号提供的是配置格式转换（更下游、更边缘）。**两者的共同特征是：零收费、零经营、纯技术。** 与本语料的 [jichangtj](jichangtj.md)、[merlinclashcat](merlinclashcat.md)、[zaproshare](zaproshare.md) 有本质区别——**那三个有联盟返佣、有分销、有营利目的；这个一分钱都没有。** 在非法经营罪的认定上，经营要件完全不成立。
- **API 站点的运营者责任。** 自有域名的在线转换服务是这个项目唯一的实体资产。**它会接收用户提交的订阅链接**——这些链接可能包含节点地址与凭证。**若站点留存日志，则运营者持有大量用户的代理配置信息**，这在《个人信息保护法》下属于需要评估的处理行为，也构成一个潜在的执法切入点。**本样本无法确认是否留存日志。**
- **示例域名不构成风险。** 正文参数示范里出现的两个伪域名是文档占位符，不指向任何真实服务。
- **著作权：不适用。** 全部为自有项目内容（解析器脚本、API 文档）。
- **不适用**：不涉及开设赌场罪（0 条博彩内容、0 个博彩域名）；不涉及传播淫秽物品罪（0 条成人内容）；不涉及帮助信息网络犯罪活动罪（0 个收款账号、0 个联盟参数、0 条商业导流，六年零商业行为）；不涉及非法经营罪（零收入、无支付业务）；不涉及广告法责任（0 条商业广告）；不涉及侵犯公民个人信息罪（频道侧无任何个人信息处理，API 站侧见上）。

**责任主体**：解析器与 API 站点的维护者。**暴露面比 [projectXtls](projectXtls.md) 大**——**那个项目零域名，这个项目有一个自有域名，而域名注册信息是可查的。** 此外 iOS 录屏文件可能携带设备信息。**代码托管平台上的项目历史提交是第三个暴露点。**
