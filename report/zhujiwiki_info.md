## 二、核心发现一：96% 指向同一家商户

**288/300 条帖子的链接指向同一个主机商域名。**

**本语料的"单一域名集中度"排名：**

| 样本 | 最高域名占比 | 归属 |
|---|--:|---|
| [newmobilelife](newmobilelife.md) | **100%** | **自有站** |
| [Notionso](Notionso.md) | 99.8% | **第三方（无返佣）** |
| [wublock](wublock.md) | 97.7% | **自有站** |
| **zhujiwiki_info** | **96%** | **第三方（带返佣）** |
| [liyuans](liyuans.md) | 59% | 第三方聚合站 |

**前四名里有两个是自有站（导流给自己）、一个是无返佣的第三方（纯信息服务）、一个是带返佣的第三方。**

**这个样本是唯一的第四种，而它的性质完全不同：**

> **把 96% 的版面给了一家有商业关系的第三方。**

**本语料在 [Notionso](Notionso.md) 第四节提出过一条：**

> **外链的归属分布反映一个账号在为谁创造价值。**
> **全部指向自己是经营资产；全部指向第三方且无返佣参数，是纯粹的信息服务。**

**这个样本补上第三种情形：**

> **全部指向第三方且带返佣参数，是单一客户的代理。**

**与本语料另两个 VPS 推广样本的对照把这一点说得更清楚：**

| | [vpscang](vpscang.md) | [liyuans](liyuans.md) | **zhujiwiki_info** |
|---|--:|--:|--:|
| 归属参数 | 252 | 119 | **339** |
| 主商户占比 | 外部最高 64 次 | 三家各 27/25/20 | **288（96%）** |
| 商户数 | **多家** | **多家** | **一家为主** |
| 披露 | **写在频道名里** | 零 | **零** |
| ERR | 50.46% | 19.77% | **24.10%** |
| 评论/帖 | 8.9 | 2.1 | **0.28** |

**参数最多的那个，商户最少、披露最弱、评论最低。**

**本语料由此得到一条：**

> **联盟参数的数量不衡量一个推广号的规模，只衡量它的链接密度。**
> **真正区分"评测号"与"代理号"的是商户数：评测号必须覆盖多家才有可比性，代理号只需要一家。**

**而读者的反应印证了这条区分：评论密度 0.28 条/帖，是三个样本中最低的**（[vpscang](vpscang.md) 8.9、[liyuans](liyuans.md) 2.1）。

> **一个只推一家的账号，没有什么可讨论的。**

**样本中另有三家主机商域名（各 6–9 次），以及该主商户自己的公告栏被转发 12 次**——**这两项合起来说明它并非完全独家，但主次极为悬殊。**

## 三、核心发现二：第四个网络节点

**转自字段中，本语料已分析的 [zrj96](zrj96.md) 出现 4 次。**

**本语料在 [liyuans](liyuans.md) 第四节第一次观察到两个已分析样本之间的内容流动，并在 [vpscang](vpscang.md) 第五节把它扩成三节点：**

> **[zrj96](zrj96.md) → [liyuans](liyuans.md)、[zrj96](zrj96.md) → [vpscang](vpscang.md)。**

**这是第四个节点，而边的方向相同：[zrj96](zrj96.md) → zhujiwiki_info。**

**于是中文主机评测这个细分领域的可见网络变成：**

> **一个上游内容源（[zrj96](zrj96.md)，450 条链接零自有归属标识）**
> **向至少三个带联盟参数的下游节点供稿（119 / 252 / 339 个归属标识）。**

**这个结构与本语料在 [illusory_world](illusory_world.md) 第二节画出的个人频道转发网络形态相同，但性质完全不同：**

| | 个人频道网络 | **主机评测网络** |
|---|---|---|
| 节点 | [JISFW](JISFW.md)、[lychee_wood](lychee_wood.md)、[illusory_world](illusory_world.md) | [zrj96](zrj96.md)、[liyuans](liyuans.md)、[vpscang](vpscang.md)、zhujiwiki_info |
| 上游 | 一个个人频道 | **[zrj96](zrj96.md)** |
| 下游的商业状况 | **全部零变现** | **全部带联盟参数** |
| 内容流动的性质 | **兴趣共享** | **素材供给** |

**本语料由此得到一条：**

> **同样的转发网络形态，可以承载完全不同的经济关系。**
> **判据不是网络的拓扑，是节点的归属参数密度。**

**这条判断对本语料"矩阵识别八法"是一个必要的补充：**

**八法能识别"谁和谁是一伙的"，而"一伙"可以是同一个人（矩阵）、同一个圈子（转发网络）、或同一条供应链（本样本所在的这个）。**

**[zrj96](zrj96.md) 的位置尤其值得记：它自己零变现（第九节"收到了但没接"），而它的内容流向三个变现节点。**

> **本语料由此第一次看到一个完整的"内容生产—商业转化"分工：上游写，下游卖。**

## 四、核心发现三：用途标签

**标签体系的构成很特别：**

| 标签 | 次数 | 性质 |
|---|--:|---|
| 某 AI 服务解锁 | **9** | **用途** |
| 某跨境电商社媒运营 | **9** | **用途** |
| 双 ISP 住宅（网络类型） | 6 | 规格 |
| 某网络纯净度指标 | 6 | 规格 |
| 若干线路与号段类型 | 5 + 5 + 3 + 3 | 规格 |

**前两个是"这个东西能用来干什么"，其余是"这个东西是什么"。**

**本语料的"标签十六用"**（[moepic](moepic.md) 第二节确立第十六种"作者索引"）**中，"规格"类属于"属性检索"**（与 [askahh](askahh.md) 的省份运营商带宽同型），**而"用途"类此前只在 [liyuans](liyuans.md) 第六节以"卖点标签"的形式出现过。**

**这个样本把卖点标签推进了一步：**

> **[liyuans](liyuans.md) 的卖点标签是形容词（原生 IP、不限流量、机场主御用）。**
> **这个样本的用途标签是完整的使用场景**——**不是"这台机器有什么"，是"你可以拿它做什么"。**

**而那两个场景指向的东西值得单独记：**

**一个是访问某类 AI 服务，另一个是运营跨境电商与社交媒体账号。**

**本语料在 [what_youread](what_youread.md) 第四节、[sharecentre](sharecentre.md) 第二节、[lover_links](lover_links.md) 第三节三次观察过"境内用户需要境外大模型访问"这条需求链，而那三次看到的都是 API 中转这一侧。**

**这是第一次从基础设施侧看到同一条需求：**

> **住宅 IP 与特定线路被明确标注为"用来解锁 AI 服务"。**

**本语料由此把那条需求链补完整：**

| 层 | 提供什么 | 样本 |
|---|---|---|
| **基础设施** | **住宅 IP / 特定线路** | **zhujiwiki_info、[liyuans](liyuans.md)、[vpscang](vpscang.md)** |
| 中转服务 | API 额度的再分发 | [what_youread](what_youread.md)、[lover_links](lover_links.md) |
| 广告与导流 | 把用户送过去 | [sharecentre](sharecentre.md) |
| 需求侧 | 境内用户 | [ibetame](ibetame.md)、[ngcss](ngcss.md) |

**第二个场景（跨境电商与社媒账号运营）指向的是另一条需求：** **批量管理境外平台账号需要干净的住宅 IP，否则会被风控。**

**这条需求与本语料 [voice_google](voice_google.md) 第三节的账号交易、[kxswjs](kxswjs.md) 第二节的数据交易属于同一生态的不同环节，但本样本本身只卖基础设施。**

## 五、其余维度

**实现技术思路：内容聚合 + 自有百科站 + 单一商户导流。**

**自有百科站被引用 204 次（68%）**——**每条帖子几乎都同时给出一个自有站链接与一个商户链接。**

**这是一个两段式结构：**

> **Telegram 发摘要 → 自有站看详情 → 商户链接下单。**

**本语料在 [vpscang](vpscang.md) 第四节记录过另一种两段式（自有短链做跳转层），而这个样本的中间层是一个内容站，不是一个重定向器。**

**两者的差别：**

| | [vpscang](vpscang.md) | **zhujiwiki_info** |
|---|---|---|
| 中间层 | **短链**（可改指向） | **内容站**（可改内容） |
| 读者看到 | 直接跳到商户 | **先看一篇文章** |
| 历史链接失效时 | 改短链目标 | 改文章内容 |

**两者解决的是同一个问题（本语料 [vpscang](vpscang.md) 第四节："长期不删历史内容的推广号必须有一个自己可控的跳转层"），而这个样本的存活率是 99.7%——比 [vpscang](vpscang.md) 的 96.5% 还高。**

**3 个 apk 文件（109.9 MB）与主机业务无关**——**其中一个是某音乐应用的特定版本。** **这是样本中唯一一处偏离主题的内容，本报告不作进一步推断。**

**成本（月）：¥100–600。** 自有百科站的域名与托管；内容生产 2.54 帖/天。

**收益：¥5,000–30,000/月。**

**三条依据：**

1. **339 个归属标识 / 118 天，密度 1.13/帖**——**本语料最高**（[vpscang](vpscang.md) 0.84、[liyuans](liyuans.md) 0.40）。
2. **但高度集中在一家商户**——**收入的天花板由那一家的返佣政策决定，而不是由市场决定。** **这既是它的效率来源（谈一次合作就够了），也是它的风险（那家商户一旦调整政策或倒闭，收入直接归零）。**
3. **ERR 24.10% + 单帖 2,574 阅读**，**低于 [vpscang](vpscang.md)（50.46% / 5,964）而高于 [liyuans](liyuans.md)（19.77% / 2,829）。**

**估值因此落在两者之间偏上：参数密度最高，但触达与信任度不及 [vpscang](vpscang.md)。**

**增长：1.07 万订阅来自自有百科站与那个内容网络。** 转发均值 4.3（低）、零买量迹象；**频道名是"主机百科 + 资讯分享"，属"品类词 + 功能词"的关键词占位。**

## 六、法律风险

**风险等级：中。**

- **推广的商品本身合法。** 主机与住宅 IP 服务是正常的商业服务。
- **但两个用途标签是实质风险点。** **一个明示"解锁某类 AI 服务"，另一个明示"运营跨境电商与社媒"。** **这与本语料 [liyuans](liyuans.md) 第十节识别过的问题同构**（那个样本的标签明示目标客户包含代理服务运营者），**而本样本的标签更直接：它写的不是客户身份，是绕过地域限制与平台风控这两个具体用途。**
  - **"解锁 AI 服务"指向绕过服务方的地域限制**——**违反该服务的条款（民事违约）；若其实现方式为境内用户提供跨境通道，则落在《计算机信息网络国际联网管理暂行规定》第 6 条上。**
  - **"运营跨境电商与社媒"指向用住宅 IP 规避平台的多账号风控**——**违反相关平台的条款；若涉及批量注册或账号买卖，则另涉《刑法》第 253 条之一与第 287 条之二的讨论，但本样本只卖 IP，不涉及账号。**
  - **推广者的"明知"：这两个标签构成直接证据**——**它知道并宣传这些用途。** **这是《刑法》第 287 条之二帮信罪"技术支持"一项在认定上的关键要素。**
- **风险强度需要两点限缩**（同 [liyuans](liyuans.md) 第十节）：**住宅 IP 的合法用途极其广泛，"专门性"要件不成立；本频道是推广者而非服务提供方。**
- **未标注商业关系（主要合规问题）。** 339 个归属标识、96% 的版面给一家商户，**而样本中未见任何 `#ad` 或利益披露。** **依《广告法》第 14 条，广告应当具有可识别性。** **本语料"广告披露八档"中落在最低档**——**而同批的 [vpscang](vpscang.md) 把披露写进了频道名，两者形成本语料在这一项上最直接的一组对照。**
- **单一商户的关系性质。** 96% 的集中度与该商户公告栏被转发 12 次，**说明这更接近一种代理关系而非独立评测。** **若以"资讯分享"为名实为单一商户的推广渠道，则《广告法》第 28 条关于引人误解的商业宣传有讨论空间。**
- **3 个 apk 文件。** 其中一个是某音乐应用的特定版本。**若为官方分发版本则无问题；若为修改版则涉及《著作权法》第 10 条第 5 项与第 14 项**（参照本语料 [ksc666](ksc666.md) 第九节）。**本报告无法判断其性质。**
- **境内连接点明确。** 简体中文、受众为中国大陆用户、推广的线路与号段面向大陆网络环境。
- **不适用**：不涉及开设赌场罪（0 条博彩内容、0 个博彩域名、0 个客服号）；不涉及传播淫秽物品罪（0 条成人内容）；不涉及侵犯公民个人信息罪（无 bot、无表单）；**不涉及直接提供翻墙服务**（0 个机场域名、0 个订阅链接、0 个节点——**它卖的是服务器与 IP**）。

**责任主体**：频道运营者（拥有那个百科站，**本报告不复现**）。**暴露面：一个自有域名的注册信息，以及与那家主机商之间 339 次归属标识所对应的完整结算关系。** **本语料在 [sharecentre](sharecentre.md) 第十节、[askahh](askahh.md) 第十一节、[Pojieapp](Pojieapp.md) 第八节三次观察过"频道侧可以匿名，但资金链路在商业伙伴的后台里是完整的"，这是第四个实例，而且是最集中的一个：所有的链路都汇到同一家商户那里。**
