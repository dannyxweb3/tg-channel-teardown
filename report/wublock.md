# wublock · 吴说区块链 新闻与深度

> **频道 · 15,535 订阅 · 60.00 帖/天 · 中位阅读 407（未成熟）· 存活率 97.7%**
> 数据来源：`scripts/tg_recon.py dump wublock --limit 300` → [data/recon/wublock.jsonl](../data/recon/wublock.jsonl)
> 抓取时间 2026-09-20 · 样本 300 条（2026-09-15 → 2026-09-20，跨度 5 天）

**一句话结论：300 条帖子，293 条链接到同一个自有域名——97.7% 的覆盖率，是本语料"导流给自有站"这一形态迄今最彻底的一例。它一天发 60 条，每条正文中位 276 字，全部是"标题 + 一段正文 + 一个自有站链接"的新闻条目，零标签、零图片（仅 6 张）、零广告位、零联盟参数。它的阅读数分布窄得反常：300 条全部落在 93 到 603 之间，中位 407——一个日更 60 条的媒体号，单条只有四百人看。这个频道不是一个 Telegram 账号，是一个网站的 RSS 出口，而它的所有价值都在那个网站上被结算。**

## 二、核心发现一：97.7% 的自有站覆盖率

**300 条帖子里 293 条链接到同一个自有域名，另有 1 条链接到它的不带前缀版本。**

**本语料的"导流给自有站"样本对照：**

| 样本 | 自有域名占比 | 形态 |
|---|--:|---|
| **wublock** | **97.7%（293/300）** | **完整域名，每帖一条** |
| [hacker_news_feed](hacker_news_feed.md) | 高 | **自有短域名收口** |
| [lover_links](lover_links.md) | 11/300 | 个人站，承担身份而非流量 |
| [daily5kong](daily5kong.md) | 微店 4 次 | 商品页 |

**[hacker_news_feed](hacker_news_feed.md) 第二节被列为"链接处理六档"的第六档（自有短域名）。**

**这个样本在同一档上，但做法相反：它不缩短，不加跟踪参数，直接用完整域名。**

**这个差别不是技术细节，它反映两种不同的目的：**

> **短域名的目的是收口与计数**（[hacker_news_feed](hacker_news_feed.md) 需要知道有多少人点了）。
> **完整域名的目的是品牌露出**——**读者在看到链接的那一刻就知道这是哪家媒体。**

**本语料由此在第六档下分出两支：**

| 支 | 目的 | 样本 |
|---|---|---|
| 短域名 | 收口 + 计数 | [hacker_news_feed](hacker_news_feed.md) |
| **完整域名** | **品牌露出** | **wublock** |

**每帖链接中位 1.0（总 297/300）说明这是一条严格的一对一关系：一条新闻，一个链接，没有例外，也没有额外的推广位。**

**这个结构本身就是一份声明：这个频道不出售版面。**

## 三、核心发现二：反常地窄的阅读分布

**300 条的阅读数全部落在 93 到 603 之间，中位 407。**

**极差只有 6.5 倍，而本语料的其他频道样本普遍跨两到三个数量级**（[iingtw](iingtw.md) 最高 194,771 对中位 21,761；[daily5kong](daily5kong.md) 最高 99,003 对中位 4,393；[sharecentre](sharecentre.md) 最高 11,767 对中位 1,479）。

**这种窄分布有一个直接的解释：没有任何一条内容产生了外溢。**

**转发数据佐证：均值 2.1、中位 2、max 7。** **最高的一条只被转了 7 次。**

**本语料在 [cool_scripts](cool_scripts.md) 第二节确立过转发的双条件公式：**

> **高转发 = 内容可独立理解 + 有分享动机。**

**这个频道的内容完全满足第一个条件（每条都是完整的新闻摘要），但第二个条件不成立。**

**原因可以从内容结构推出来：** 60 条/天的快讯流里，**单条新闻的稀缺性趋近于零**——**转发一条"某人看涨某代币"没有任何社交价值，因为同一分钟里还有另外十条。**

**本语料由此给转发的五种边界**（[cool_scripts](cool_scripts.md) 第二节确立第五种）**补上第六种：**

> **密度边界。** **当同类内容以极高密度持续供给时，单条内容失去稀缺性，转发动机随之消失。**

**它与"时间边界"（[zuanke8](zuanke8.md)：线报过期了）的区别是：时间边界是内容会失效，密度边界是内容从未特殊过。**

**这也解释了 ERR 的低位：** **2.62% 是 5 天窗口下的未成熟下限，即便成熟后翻倍，也仍然处在本语料的低档。**

**对照本语料的频率/ERR 分类框架**（[iingtw](iingtw.md) 第二节确立）：

| 类别 | ERR 量级 | 本样本位置 |
|---|---|---|
| 工具/查阅型 | 60–170% | |
| 不可替代的信源本人 | 130%+ | |
| 人格化评论 | 20–60% | |
| 编辑型转载 | 10–20% | |
| **机器/高频聚合** | **3–10%** | **✓** |

**它落在最低一档，与 [zhihuribao_rss](zhihuribao_rss.md)（3.40%）、[Hao12News](Hao12News.md) 同组。**

**但它与那两个有一个关键差别：那两个是纯机器抓取，这个是有人写的。**

## 四、核心发现三：一个署名模板

**86 条帖子（28.7%）以同一个四字短语开头引述信源：「某某获悉，据…」。**

**这是一个媒体机构的标准归属句式：先声明本机构获得了信息，再交代来源。**

**本语料此前记录过两类固定话术：**

| 类型 | 样本 | 判据 |
|---|---|---|
| **模板**（完全一致） | [cool_scripts](cool_scripts.md)（`#changlog` 错拼重复 257 次） | 机器插入 |
| **人工**（细微变体） | [iingtw](iingtw.md)（称呼语三种写法） | 人工输入 |

**这个样本落在中间：** **短语本身完全一致（86 次），但它只出现在 28.7% 的帖子里。**

**如果是机器插入，应该是 100% 或 0%；28.7% 说明它是一条编辑规范——**引述第三方信源时用它，报道自有信息时不用。

**本语料由此把"固定话术"的判据补完整：**

> **覆盖率 100% + 完全一致 → 机器模板。**
> **覆盖率不足 100% + 完全一致 → 编辑规范（人工执行，但有明文约束）。**
> **覆盖率不定 + 细微变体 → 个人习惯。**

**三档的区分靠两个量：覆盖率与一致性。**

**这个样本是本语料第一个"编辑规范"档的实例**——**它说明背后有一个多人团队与一份稿件规范，而不是一个人的习惯。**

**其余 71.3% 的帖子不带这个短语，正文结构同样整齐（中位 276 字、max 662，从不超过一屏）。**

**60 条/天 × 276 字 ≈ 每天 1.6 万字。** **这不是一个人能做的量，第七节展开。**

## 五、核心发现四：零互动是一个设计

**评论未开放（0 条），反应只有 3 条帖子有。**

**本语料的频道样本里，这是互动最少的一个**（[zhihuribao_rss](zhihuribao_rss.md) 同为 0/0，但那是机器号）。

**一个有编辑团队、日产 1.6 万字的专业媒体账号，关掉了所有互动通道。**

**这个选择与它的整体结构是自洽的：**

| 设计 | 含义 |
|---|---|
| 97.7% 链接指向自有站 | **Telegram 不是终点** |
| 零标签 | **不需要在 Telegram 内检索** |
| 零评论、零反应 | **不需要在 Telegram 内沉淀关系** |
| 零广告位 | **不在 Telegram 内变现** |

**四项合起来说明：这个频道被定位成一个纯粹的分发管道。**

**本语料的"不变现十二种类型"**（[SteamNy](SteamNy.md) 第四节确立第十二种）**中，它属于"导流给自有站"一类**（与 [hacker_news_feed](hacker_news_feed.md) 同组），**但它是这一类里最彻底的：连读者停留的理由都不给。**

**代价是可测的：** **ERR 落在最低一档、转发 max 只有 7、零社群沉淀。**

**收益也是可测的：** **每天 60 次品牌露出 + 60 个回站链接，而零运营成本落在 Telegram 这一侧。**

## 六、实现技术思路

| 层 | 做法 |
|---|---|
| 内容 | **网站稿件的摘要版**（中位 276 字） |
| 归属 | **「某某获悉」句式**，28.7% 覆盖（编辑规范） |
| 链接 | **完整自有域名，每帖一条，零参数** |
| 图片 | **6/300**——几乎不配图 |
| 标签 / 互动 / 广告 | **全部为零** |
| 发布 | **60 条/天** |

**零跟踪参数值得单独记。**

**本语料的"链接处理六档"里，第五档（[theblockbeats](theblockbeats.md)）的做法是给自有站链接带一个 `from` 参数，用于区分流量来源。**

**这个频道不带。**

**同为中文加密货币媒体、同样把 Telegram 当分发渠道，一个要归因，一个不要。**

**两种做法的差别在于对渠道的态度：**

> **带 `from` 参数 = 把 Telegram 当成多个渠道之一，需要横向比较。**
> **不带参数 = Telegram 的流量与其他来源混在一起，不单独考核。**

**本语料由此得到一条：跟踪参数的有无，反映的是运营者是否在做渠道 ROI 核算。**

**这个频道不做，最可能的原因是它的 Telegram 流量占比小到不值得单独看**——**日均 60 条 × 407 阅读 ≈ 2.4 万次曝光，对一个有独立站的媒体机构而言是一个补充渠道。**

## 七、成本

**经常性（月）：内容成本不属于这个频道，但可以拆开说。**

| 项目 | 金额 | 依据 |
|---|--:|---|
| 频道本身 | **¥0** | 零 bot、零域名（站是自有的，但不为频道而建）、零服务器 |
| **网站** | **不属于本频道** | 域名 + 托管 + CMS |
| **编辑团队** | **不属于本频道** | **60 条/天 × 276 字 ≈ 1.6 万字/天** |

**1.6 万字/天这个量需要展开：**

**按一个熟练的财经快讯编辑每天产出 15–25 条计，60 条/天需要 3–4 个全职编辑，外加选题与审核。**

**本语料的其他"日更大量"样本对照：**

| 样本 | 日产量 | 谁在产 |
|---|--:|---|
| **wublock** | **60 条 / 1.6 万字** | **编辑团队（推定 3–4 人）** |
| [zrj96](zrj96.md) | 17.65 条 | 一个人筛选转载 |
| [sharecentre](sharecentre.md) | 2.68 条 / 1,675 字 | 一个人写长文 |
| [zhihuribao_rss](zhihuribao_rss.md) | 4.11 条 | 机器 |
| [Hao12News](Hao12News.md) | 高 | 机器 |

**这是本语料唯一一个需要多人全职编辑部的样本。**

**而这个成本完全不由 Telegram 频道承担**——**稿件本来就要为网站生产，推到 Telegram 是零边际成本的复用。**

**本语料在 [iingtw](iingtw.md) 第八节、[sspai](sspai.md)、[designers](designers.md) 记录过"第一方渠道"的这一结构；这个样本是其中产量最大的一例。**

## 八、收益

**频道侧可观测：¥0。**

**300 条里零广告、零收款账号、零联盟参数、零推广码、零订阅墙、零商品。**

**32 条粗筛命中全部是加密货币术语造成的误报**（命中词涉及代币名、"浮盈"、"持仓"、"资金流入"一类）。

**本语料的"关键词假阳性十八类"在这里得到一个新子类：**

> **金融术语与营销词的重合。** **加密货币报道必然高频出现"收益""浮盈""做多""空投"这些词，而它们同时是荐股与资金盘话术的核心词汇。**
> **这一类与本批 [iingtw](iingtw.md) 第九节的"公共政策名称含营销词"同型：命中率高（10.7% 与本样本的 10.7% 恰好相同）且 100% 是误报。**

**真实收益在站内，不可观测。** **本报告不给整体估算，只给频道可归因部分。**

**频道对站点的导流价值：¥2,000–12,000/月（等效媒体价值）。**

**估算口径与依据：**

1. **每天 60 条 × 407 中位阅读 ≈ 2.4 万次曝光/天，约 73 万次/月。**
2. **每条带一个回站链接。** **按财经资讯类 2–5% 的链接点击率推算，约 1.5–3.7 万次站内访问/月。**
3. **按中文财经内容站的广告变现水平**（本语料无直接样本，此处依赖行业常识）**折算，这个量级的增量访问对应四到五位数人民币。**
4. **上锚受一个因素压制：这些读者本来就可能通过其他渠道到达该站**——**Telegram 带来的是增量还是替代，本报告无法区分。**

**这是本报告给出的估算中最弱的一个，原因已在第 4 点说明。**

## 九、增长策略

| 机制 | 证据 | 判读 |
|---|---|---|
| **机构品牌** | 频道名即媒体名 | **唯一来源** |
| **高频覆盖** | 60 条/天 | **占满时间线** |
| 完整域名露出 | 293 次 | 品牌强化 |
| 转发外溢 | **max 7** | **几乎没有** |
| 标签 / 互动 / 互推 | **全部为零** | |
| 买粉 | **无从判断** | 窄阅读分布不支持也不排除 |

**这个频道没有任何 Telegram 内部的增长动作。**

**它的 1.55 万订阅来自机构本身的知名度**——**与 [iingtw](iingtw.md) 第十节的"频道外的既有身份"属于同一类，但强度低两个数量级**（那个样本 ERR 133.80%，这个 ≥2.62%）。

**差别的原因很清楚：**

> **[iingtw](iingtw.md) 的身份是不可替代的（只有那一个人能发那些内容）。**
> **这个频道的身份是可替代的（加密货币快讯有很多家在做）。**

**本语料由此把"频道外的既有身份"这一增长来源分成两档：**

| 档 | 特征 | ERR 表现 |
|---|---|--:|
| **不可替代的身份** | 内容只有这个来源能提供 | **130%+** |
| **可替代的机构品牌** | 内容有多个同类来源 | **3–10%** |

**60 条/天的高频是一种针对可替代性的补偿策略：**

> **既然单条内容不稀缺，就用覆盖面取胜——保证读者需要的任何一条快讯都在这里出现过。**

**代价在第三节已经量化：密度边界杀死了转发，而没有转发就没有外溢增长。**

**这是一个自洽但封闭的循环：高频 → 低稀缺 → 零转发 → 无外溢 → 只能靠机构品牌拉新。**

## 十、法律风险

**风险等级：中。**

- **加密货币内容在中国大陆的监管定位（主要风险）。** **中国人民银行等十部门《关于进一步防范和处置虚拟货币交易炒作风险的通知》（2021）明确：虚拟货币相关业务活动属于非法金融活动。** **该通知同时要求金融管理部门与网信部门加强对虚拟货币相关信息的监测与处置。** **一个面向中国大陆读者、日更 60 条虚拟货币行情与项目资讯的媒体账号，落在该通知的监管关注范围内。**
- **但报道与经营是两回事。** **本样本中的内容是资讯报道（价格变动、机构动向、人物观点），未见任何交易入口、钱包地址、交易所推荐链接、代币销售或收款渠道。** **上述通知规制的是"业务活动"，纯粹的资讯报道不构成其中任何一项。** **零广告、零联盟参数、零收款账号进一步切断了营利性经营的认定路径。**
- **《互联网新闻信息服务管理规定》的适用。** 这是一个持续、规模化的新闻信息服务。**该规定要求从事互联网新闻信息采编发布服务须取得许可。** **本报告无法核实该机构是否持有相应资质**——**但需要指出：其报道对象（虚拟货币）在中国大陆本身受限，这使得取得内地新闻资质的可能性很低，而这反过来说明该机构的主体与服务器更可能位于境外。**
- **荐股型表述的边界。** 样本中有对具体代币价格目标与持仓盈亏的报道（例如引述某人"看涨某代币至某价位"）。**这些是对第三方观点的转述，带明确的信源归属（「某某获悉，据…披露」）**，**不是本机构的投资建议。** **这与本批 [lover_links](lover_links.md) 第十节的情形有本质区别：那个账号是以第一人称给出判断并引导开户。** **转述 vs 建议，是《证券法》第 160 条与非法经营证券业务认定上的关键分界。**
- **未标注商业关系：无关系可标。** 零广告、零联盟参数——**《广告法》第 14 条不产生适用场景。**
- **零数据处理。** 无 bot、无评论区、无表单、无收款——**运营方不通过这个频道持有任何读者数据。**
- **境内连接点。** 简体中文、报道中国大陆相关人物与事件、受众以中文读者为主。**中国法有管辖意义，但主体与服务器位置未知（见上）。**
