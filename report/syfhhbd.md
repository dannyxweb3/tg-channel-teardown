## 二、核心发现一：本轮最清晰的一次买量取证

**反应的变异系数（CV）：**

```
样本：反应 ≥50 的帖 n=17
CV 中位：0.114
最低三个：0.041 / 0.047 / 0.049
```

**最低那三条的反应向量长这样：**

```
[419, 404, 399, 383, 373]     CV = 0.041
[385, 369, 367, 360, 333]     CV = 0.047
[221, 208, 201, 198, 192]     CV = 0.049
```

**五种表情，数量几乎一模一样。**

**自然的反应分布是幂律的** ——大多数人点同一个最顺手的表情，少数人点别的。本轮的自然样本：

| 频道 | CV 中位 | 典型向量 |
|---|--:|---|
| [TestFlightCN](TestFlightCN.md) | 1.910 | `[267, 109, 11, 7]` |
| [NekogramAPKs](NekogramAPKs.md) | 1.719 | `[162, 77, 59, 42, 12]` |
| [PicACG](PicACG.md) | 1.338 | `[161, 79, 62, 53]` |
| [Galgamer_Channel](Galgamer_Channel.md) | 1.232 | `[28, 26, 17, 5]` |
| **syfhhbd** | **0.114** | **`[419, 404, 399, 383, 373]`** |

**它比最接近的自然样本低一个数量级。**

**原因很直接：刷量服务按"总数"下单，系统把量平均摊到可选的表情上。** 真人不会协调出这种整齐。

**转发侧是同一个问题，形态不同：**

```
转发 = 0 的帖：111 条（41%）
转发 = 1 的帖： 66 条（24%）
转发 > 100 的帖：48 条（18%）——其中最高 1,443
```

**转发的中位数是 1，均值却是 99.8。**

**这不是长尾，是双峰**：绝大多数帖子零到一次转发，**而 48 条帖子挂着 200–1,443 次。** 自然传播不会这样分裂——**受欢迎的内容会形成连续的梯度，而不是"要么 0，要么 900"。**

**结论：它对少数"旗舰帖"选择性买量，其余听天由命。**

**被刷的是哪些帖？** 转发前四名全部是结构最完整、评分最详细的点评条目（转发 1,443 / 1,177 / 945 / 895）。**这些是它的招牌样品——用来向新访客证明"这里的内容值这个价"。**

**这也解释了 ERR 20.25% 为什么不可信**：中位阅读 1,659 里，有多少来自刷量带来的曝光、有多少是真实读者，样本无法拆分。

## 三、核心发现二：一套十字段的标准化表单

**样本内 18 条完整点评条目，字段完全一致：**

```
所在城市   17/18
所在区     18/18
老师名称   18/18
是否本人已探 18/18
上课价格   18/18
妹子年龄   18/18
妹子容貌   18/18
妹子身高   18/18
体重估计   18/18
是否抽烟   17/18
```

**（本报告只列字段名，不复现任何条目内容。）**

**这套表单的设计有三个值得分析的地方：**

**3.1 「是否本人已探」是它的信任机制**

**18/18 条都有这个字段，频道名里也写着「已探资源」。** **"探"即亲自消费过并记录。**

**这个字段的作用是把点评与转贴区分开** ——**在一个充斥着中介与虚假宣传的市场里，"我本人去过"是唯一能建立可信度的声明。**

**它同时也是这个号最大的法律暴露点（见 §八）。**

**3.2 「课表 vs 目测」的双栏记法**

样本内多条把年龄、体重写成"课表 XX / 目测 XX"两个值。

**「课表」指服务方提供的宣传资料，「目测」指点评者实际看到的。** **这个对照栏的存在，说明它的核心价值主张是"揭穿虚假宣传"。**

**这与本轮 [SecHorse](SecHorse.md)（二手数码挂单板）的 `#自刀` `#已出` 标签是同一类设计：把交易中最不透明的那一环公开化。** **区别在于 SecHorse 公开的是价格，syfhhbd 公开的是人。**

**3.3 价格分布**

从 16 条能解析出数字的条目看：

```
中位：¥800
范围：¥500 – ¥1,400
```

**标签体系印证了地域集中度**：某城市名 57 次、`#上门` 7 次，其余是个人代号（各 2–3 次）。

**「#上门」说明相当比例是上门服务而非固定场所** ——**这对后面的法律定性有影响（§八）。**

## 四、核心发现三：一条被施压后的公开回应

**样本内阅读第二高（6,000 次）、转发 677 次的一条，与所有点评条目格式都不同：**

> **私聊骂我的大哥大姐们：** 您好！我只是把我看到的**真实情况**反馈出来，当然肯定有主观意识，我不否认，**但是你让我改，我改不了，我不能撒谎，是啥样就是啥样，我也不赚**…

**这条帖子是理解这个号的关键，它透露了四件事：**

| 观察 | 含义 |
|---|---|
| 「私聊骂我的大哥大姐们」 | **被点评方在私下施压** |
| 「你让我改，我改不了」 | **有人明确要求修改评价** |
| 「我也不赚」 | **运营者自称不从点评中获利** |
| 拿到 677 转发（全样本第三） | **读者站在他这边** |

**「你让我改」这五个字暴露了这个生意的核心张力：**

> **一个点评板的价值完全建立在"评价不能被买"这个前提上；而一旦它有影响力，被点评方就必然会来买。**

**这与本轮 [Lottery_home](Lottery_home.md) 做 SHA-256 可验证开奖、[AppsSweepstakesNews](AppsSweepstakesNews.md) 加反羊毛党规则是同一类处境——都是"信任是唯一资产"的生意被现实教训之后的反应。**

**但有一个矛盾必须指出：他在这条帖子里说「我也不赚」，而 §二 的数据显示他在给旗舰帖买量。**

**买量要花钱。** **一个"不赚钱"的号为什么要给自己的内容买转发和反应？**

**两种解释，样本无法区分：**

1. **买量是为了扩大读者盘**（非直接变现，但为后续变现铺路）；
2. **"不赚"指的是"不收被点评方的钱"** ——这与买量并不矛盾，他可能有其他收入（导流、群费、广告）。

**从 §五 的导流结构看，第 2 种更可能。**

## 九、法律风险

> **level: criminal。**
>
> **1｜介绍卖淫罪（核心，且构成要件明确）。** 中国大陆《刑法》第三百五十九条第一款：**引诱、容留、介绍他人卖淫的**，处五年以下有期徒刑、拘役或者管制，并处罚金；**情节严重的，处五年以上有期徒刑，并处罚金。**
>
> **"介绍"的认定不要求收取报酬，只要求在卖淫者与嫖客之间起到中介、牵线作用。** 本频道同时具备三项：
>
> - **明确的服务信息**：城市、区域、代号、价格、年龄、外貌、服务评分
> - **明确的联系路径**：点评条目内附被点评方的联系账号
> - **持续、规模化**：118.8 天、8,194 订阅、18 条完整条目 + 216 张配图
>
> **「是否本人已探」这个字段在法律上是一把双刃剑**：它是频道的信任基石，**同时也是运营者本人多次实施嫖娼行为的自认。** 依《治安管理处罚法》第六十六条，卖淫、嫖娼的处十日以上十五日以下拘留，并处五千元以下罚款。
>
> **责任主体**：频道运营者（既是介绍者，也是嫖娼行为人）。**这是本轮唯一一个运营者本人的日常行为即构成违法、且被自己公开记录的样本。**
>
> **2｜传播淫秽物品罪。** 《刑法》第三百六十四条（不以牟利为目的）/第三百六十三条（以牟利为目的）。样本内 216 张图片与详细的服务过程描述，**在司法实践中通常被认定为淫秽物品。** 若 §七 推测的导流分成成立，则适用牟利条款。
>
> **3｜侵犯公民个人信息罪 / 人格权。** 点评条目包含从业者的代号、年龄、体型、外貌、所在区域、联系方式与身体特征。**《刑法》第二百五十三条之一**：违反国家有关规定，向他人出售或者提供公民个人信息，情节严重的，处三年以下有期徒刑或者拘役。
>
> **这一项常被忽略，但性质很实在**：**被点评者同样是《刑法》第三百五十八、三百五十九条的保护对象与潜在被害人**（组织卖淫罪的受害者），**而这些评分与身体描述会在她们脱离该行业后长期留存在网络上。** 她们与 [Aichengrenyulan](Aichengrenyulan.md) 里被深度合成的艺人一样，**几乎没有可行的救济路径。**
>
> **4｜数据造假（民事/行政层面）。** §二 已确证的刷量，违反《反不正当竞争法》第八条（虚假宣传、帮助虚假宣传）。**在本案的整体违法性面前，这一项量级很小，但它证明了运营者的主观积极性。**
>
> **不适用的三条**：不涉及组织卖淫罪（《刑法》第三百五十八条要求"组织"，即控制、管理多名卖淫人员——样本内它是外部点评者，不是组织者）；不涉及开设赌场罪（0 条博彩内容）；不涉及侵犯著作权罪（0 个资源链接、0 个网盘、52 个文件为自拍图片）。
>
> **一处定性上的区分值得写下来**：**"点评"与"介绍"在直觉上不同，但在《刑法》第三百五十九条的语境下没有区别** ——**只要评价里带着联系方式，信息就完成了从"评论"到"中介"的性质转变。这是本报告对这个样本最关键的一句判断。**
>
