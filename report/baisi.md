## 三、核心发现：一个不变现的擦边号

**变现关键词全量扫描的结果：只有 `写真` 命中 1 次。**

- 广告 / 投放 / 商务 / 频道主 / 联系 / 客服：**0**
- 机场 / 节点 / 订阅 / VIP：**0**
- 网盘 / 夸克：**0**
- 私聊 / 加群 / 定制 / 接单 / 返现 / 代理：**0**
- `t.me` 链接：**0 个**；bot：**0 个**；互推：**0 次**

**这在本轮是极罕见的。** 软色情号的标准变现路径——引流到付费群、卖"定制"、挂机场广告、导流成人站、网盘拉新——**它一条都没走**。

**16.5 万订阅、每条 3.35 万阅读、跑了近一年，账面上什么都没卖。**

**几种可能的解释**（样本内无法区分）：

1. **变现在频道外**：例如通过图片水印、或订阅者已知的其他渠道（但样本内的图片信息无法验证）
2. **养号待售**：16.5 万高 ERR 的擦边号在 TG 二手市场是硬通货
3. **纯兴趣运营**：与本轮 SomeACG（同样零变现）是同一类心态

**从"不删帖、保留作者 ID 标签、无任何导流设施"这三点看，第 3 种的可能性不低**——它的行为模式更像同人圈的图集搬运，而不是灰产运营。

## 七、法律风险

> **level: high。**
>
> 内容为软色情/擦边性质的 cosplay 与二次元图集。在中国大陆，此类内容处于《治安管理处罚法》与《刑法》第三百六十三至三百六十七条（制作、传播淫秽物品）的**判定边界**上——是否构成"淫秽物品"取决于具体尺度，"擦边"通常落在行政处罚而非刑事的区间，但以 16.5 万订阅、单条 3.35 万阅读的规模持续传播，情节因素会显著上移。
>
> 叠加的是**著作权问题**：内容源自推特作者（twitter/t.co 合计 223 次），未获授权转载；虽保留了作者 ID 作为标签，但未给出原作链接，规范性弱于 SomeACG。
>
> 减轻情节有两点：**零商业变现**（缺少"以牟利为目的"这一在传播淫秽物品罪中显著影响定性的要件）、**不删帖**（无规避举报的行为设计）。
