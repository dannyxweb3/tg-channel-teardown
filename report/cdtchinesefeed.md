## 三、内容生产：完全自动化的 RSS 管道

**3.1 定时痕迹是本轮最精确的**

```
分钟分布： :00 → 104 条    :20 → 87 条    :40 → 81 条   （合计 272/300 = 91%）
秒分布：   :01 → 190 条    其余零散
```

**每 20 分钟一个投递窗口，秒数固定在 `:01`。** 这是标准的 cron/RSS 轮询（`*/20 * * * *`），拉到新条目就推。间隔中位 1,203 秒（20.05 分钟）与之完全吻合；同时 `<10 秒` 的间隔占 24%——同一轮询窗口里一次推多条，也符合 RSS 批量出队的特征。

小时分布覆盖全天 24 小时（0 点 23 条、3 点 1 条、20 点 30 条），**没有人类作息**。

**3.2 内容结构：纯管道，无编辑加工**

- 300 条**全部是图文**（`MessageMediaPhoto` 300/300），格式统一
- 外链 **336 次全部指向 `chinadigitaltimes.net`**，另有 5 次 YouTube；**没有任何第三方链接**
- 正文中位 111 字、3 行——是摘要+链接，不是全文
- 固定栏目可从开头识别：「每日一语 YYYY.M.D」（31 条）、「中国数字时代 · 一周推荐」（5 条）

**自动化程度：接近 100%。** 人工投入在母站（chinadigitaltimes.net）的编辑部，TG 端只是一个转发出口，边际运营成本为零。

**3.3 无 bot、无矩阵、无互推**

`@` 提及 0 次、`t.me` 链接 0 次、bot 迹象 0 个。这在本轮样本里极为罕见——绝大多数号都有矩阵互链或 bot 承接。**它不做任何站内导流**，只把流量送回自己的网站。
