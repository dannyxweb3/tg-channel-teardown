## 二、核心发现一：一行五年不变的推广码

**56 条消息（37.6%）带着同一行推广。样本内的域名演变：**

| 域名 | 出现次数 | 时间跨度 |
|---|--:|---|
| 某 `.icu` 域名 | 1 | 2021-02 |
| **某 `.com` 域名** | 8 | **2021-04 → 2022-01** |
| 某 `.xyz` 域名 | 3 | 2021-07 → **2026-07** |
| **某 `.ru` 域名** | 21 | **2022-01 → 2024-02** |
| **某 `.work` 域名** | 20 | **2024-03 → 2026-04** |
| **`[32 位十六进制].36d.biz`** | 13 | **2024-08 → 2026-07** |

**（域名本身不复现，此处只列结构。其中三个短域名是该机场中文名的拼音首字母缩写。）**

**五年里换了五次域名，而 `code=` 参数的值只有 3 个不同取值，主推广码从 2021-04 到 2026-07 完全没变。**

**这是一个值得单独记录的结构：域名是消耗品，推广码是资产。**

- 域名被墙 / 被注册商处理 → 换一个，从 `.com` 到 `.xyz` 到 `.ru` 到 `.work`，最后到一个**随机 32 位十六进制的子域名**
- **`[32 位十六进制].36d.biz` 这种形态是刻意的**：随机子域名无法被批量枚举、无法被关键词匹配，需要精确知道完整串才能访问
- **而推广码跟着人走**，换域名不影响分成归属

**同一条推广在 149 条消息里稳定复现了五年，这说明它不是按月结算的广告位，而是一段长期的分成关系。**

**2025-12 起出现第二个机场**（`【推】🚀发射器`），**样本内最后五条发布公告都是两家并列。**

## 三、核心发现二：「佛(JI)系(CHANG)推广」

**每条带推广的公告，前面都有这一行：**

```
【推】佛(JI)系(CHANG)推广  【某机场】🙈🙉🙊
```

**拆开看：**

| 片段 | 解码 |
|---|---|
| **佛(JI)系(CHANG)** | 「佛系」两个字里塞进 **JI** 和 **CHANG** → **机场** |
| 🙈🙉🙊 | 非礼勿视 / 勿听 / 勿言 |

**它同时说了两件事：这是佛系（不强推）的推广；这是机场推广。**

**本轮此前见过的规避手法都是单向的**——形近字替换（[Aichengrenyulan](Aichengrenyulan.md) 的「氵」「呺」）、拼音缩写、emoji 替字。**这一个是反向的：它不是要藏起来不让人看懂，而是要让懂的人看懂、让机器扫不到。** 括号里是大写拉丁字母，任何中文关键词过滤都命中不了「机场」，而中文读者一眼就读出来。

**🙈🙉🙊 是同一个意思的第二层**：这三个 emoji 在中文 TG 语境里长期被当作「你懂的」使用。

**另一行同样重要的标注出现在 2022-03 之后的每条发布公告开头：**

```
【禁止转发国内网站】
```

**这是对用户下的指令，不是对平台的声明。** **它要防的不是版权投诉，是这条内容出现在国内论坛后带来的注意。**

> **1｜开发并分发翻墙工具（核心）。** 六年、149 条发布公告，产品是运行在华硕梅林固件上的 Clash 插件，支持 trojan / vmess / vless / ss，内置分流规则与 DNS 劫持，二进制通过配套的文件频道分发。
>
> 中国大陆《计算机信息网络国际联网管理暂行规定》第六条、《计算机信息网络国际联网安全保护管理办法》第五条、第六条。**这类案件的定性分两种：单纯开发分发工具而不经营服务的，实践中多以《治安管理处罚法》第二十九条或《网络安全法》处理；一旦认定"经营"，则可能适用《刑法》第二百二十五条非法经营罪。**
>
> **本案的关键在于它是否"经营"：插件本身开源、UnLicense、零收费、无付费入口、无打赏——工具侧完全无偿。** 但 §九 的推广分成使"无偿"这一抗辩并不干净（见第 2 条）。
>
> **2｜为机场提供长期推广导流（决定性质的一项）。** 56 条消息（37.6%）内嵌同一个推广码，历经五个轮换域名、五年不变；2025-12 起并列第二家机场；另有三条独立优惠码推送。
>
> **这一项把性质从"免费开发工具"推向"通过工具引流变现"。** 依《刑法》第二百八十七条之二帮助信息网络犯罪活动罪，或作为机场经营者非法经营罪的共犯评价。
>
> **本案在情节上的三个加重因素**：(1) **推广码五年不变，证明是稳定的长期分成关系而非偶发广告**；(2) **域名从 `.com` 一路换到随机 32 位十六进制子域，是明确的规避行为**；(3) **转化场景高度精准——读者此刻正在装 Clash 插件，推广的针对性远高于泛流量投放。**
>
> **3｜「佛(JI)系(CHANG)」与「禁止转发国内网站」的证据意义。** 前者是把"机场"二字拆成拉丁字母塞进括号的规避写法，后者是对用户下达的传播限制指令。**两者都不构成独立违法，但都直接证明运营者对内容违法性的清晰认知**——在"明知"要件上与本轮 [jichangtj](jichangtj.md) 的四条塌方报道属同一类自证。
>
> **4｜插件的 root 权限与供应链（独立风险）。** 该插件运行在路由器上，接管 DNS 与全网流量，具备 root 级能力。**一旦被二次修改并以相似名义分发，受害面是整个家庭网络。**
>
> 2024-12 的声明恰恰说明这件事已经发生过（「软件中心投毒事件」、「MerlinClash Lite 频道发布的插件，由热心群友二次修改」）。
>
> **该声明在责任划分上是有利的**：明确"本群未做任何代码审核"、建议用户自行审阅全部代码、声明官方渠道有且仅有两个。**在开源且无许可证的前提下，原作者对第三方分支造成的损害通常不承担责任**，而这份声明把边界说清楚了。**但"UnLicense、开放二改"的立场本身，也意味着作者主动放弃了通过许可证约束下游的手段。**
>
> **5｜安全教育内容（有利情节）。** 「不要没事干关防火墙」（156 转发）用真实事故警告用户不要暴露 socks 端口；FAQ 与 DNS 方案是纯技术文档。**这类内容在整体评价中是有利的，说明运营者并非以损害用户为目的。**
>
> **不适用的四条**：不涉及开设赌场罪（0 条博彩内容）；不涉及传播淫秽物品罪（0 条成人内容）；不涉及侵犯著作权罪（插件自身开源，未分发任何第三方版权内容，147/149 条是自制技术文档）；不涉及诈骗罪（无任何收款行为，六年零付费入口）。
