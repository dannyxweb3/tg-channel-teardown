## 九、法律风险

> **level: medium。**
>
> **1｜违反甲骨文云服务条款（主要项）。** 自动化脚本高频轮询 OCI API 抢占免费套餐资源，违反 Oracle Cloud 的可接受使用政策（禁止自动化滥用、禁止规避资源配额）。**这是合同违约而非违法**——后果是账号封禁与实例回收，由**使用者本人**承担；工具提供方在合同关系之外。**但它收费提供该服务，若甲骨文追究，运营者可能面临民事层面的主张（如干扰合同关系）。跨境执行难度极大，实际发生概率低。**
>
> **2｜经营行为的资质问题。** 它有充值、有订阅、有广告位，是实质的经营活动。中国大陆《电子商务法》第十条要求电子商务经营者办理市场主体登记；若运营者在境内且未登记，属行政瑕疵。**但从「闪电权限」「充值」这种规避性表述看，运营者大概率是匿名个人，实际追责路径不清晰。**
>
> **3｜「查询订阅信息」功能的边界。** 样本内提到「不止查免费订阅，付费类和其他类似教育订阅可能也支持查询了」。**若该功能是查询用户自己账号的订阅状态，完全合规；若是探测他人账号或绕过平台校验，则可能触及《刑法》第二百八十五条第二款非法获取计算机信息系统数据罪。样本信息不足以判断，这是本报告最大的不确定项。**
>
> **不适用的三条**：不涉及帮助信息网络犯罪活动罪（0 条博彩/诈骗/色情导流、0 个代收款账号）；不涉及侵犯著作权罪（自研软件，开源发布）；不涉及非法经营罪的典型情形（无「机场」经营、无支付通道业务、无出版物）。**它的风险集中在服务条款与经营资质层面，性质与本轮的灰产样本完全不同。**
