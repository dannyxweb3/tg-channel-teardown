## 二、核心发现一：两个样本收敛到同一个 ERR

**本批同时采到两个游戏限免推送号：**

| | [SteamNy](SteamNy.md) | **steamsteam** | 差异 |
|---|--:|--:|--:|
| 订阅 | 16,187 | **15,385** | 5.2% |
| 帖/天 | 0.47 | **0.41** | 14.6% |
| 成熟中位阅读 | 6,733 | **5,930** | 13.5% |
| **ERR** | **41.60%** | **38.54%** | **7.9%** |
| 转发均值 | 18.8 | **11.0** | 71% |
| 反应覆盖率 | 97.3% | **100%** | 2.8% |
| 评论/帖 | 7.9 | **1.8** | 339% |

**前四行几乎重合，后三行差异明显。**

**这组对照的价值在于它把"可复现的"与"可变的"分开了：**

> **ERR 由品类决定**——**两个独立运营、风格不同的账号，落在同一个数字附近。**
> **互动强度由运营决定**——**评论密度差 3.4 倍。**

**本语料在 [iingtw](iingtw.md) 第二节建立过 ERR 的分类框架（工具型 60–170%、不可替代信源 130%+、人格化评论 20–60%、编辑型转载 10–20%、机器聚合 3–10%）。**

**那个框架是从五个不同品类的单样本推出来的。**

**这是第一次有两个同品类样本互相验证，而它们确实落在同一格里。**

**"限免推送"这个品类的 ERR 基线因此可以确定为 38–42%。**

**这条基线的成因可以直接推出来：**

| 因素 | 作用 |
|---|---|
| **内容有确定的行动价值** | 看到 = 可以立刻领一个游戏 |
| **有时效** | 限免会结束，不看就错过 |
| **低频** | 0.4 帖/天，不会疲劳 |

**三者合起来使订阅者保持打开习惯，这就是 40% 量级 ERR 的来源。**

**本语料由此得到一条可用于估算的方法：**

> **判断一个账号的 ERR 是否正常，应当先确定它的品类基线，再看它偏离多少。** **脱离品类的 ERR 横向比较没有意义。**

## 三、核心发现二：反应覆盖率 100%

**300 条帖子，300 条有反应，中位 13 个。**

**本语料此前的最高值是 [SteamNy](SteamNy.md) 的 97.3%（292/300）。**

**这是第一个满分。**

**本语料在 [TimeHorizonX](TimeHorizonX.md) 第四节确立过：**

> **ER 由"内容能否就地产生反应"决定。**

**限免推送是这条规律的极端正例：一条"某游戏现在免费"的帖子，读者领完之后点一个表情是最自然的动作。**

**这个账号的正文中位只有 70 个字——它比 [SteamNy](SteamNy.md)（204 字）还短三分之二。**

**两者的形式对照：**

| | [SteamNy](SteamNy.md) | **steamsteam** |
|---|---|---|
| 正文 | 标题 + 商品名 + 原价/现价 + 简介 + 标签 | **一行标题 + 一条链接** |
| 标签 | **8 个，三维正交** | **0** |
| 中位字数 | 204 | **70** |
| 评论/帖 | **7.9** | 1.8 |
| **反应覆盖率** | 97.3% | **100%** |

**更短的帖子拿到了更高的反应覆盖率，但拿到的评论少得多。**

**这与本批 [sharecentre](sharecentre.md) 第五节的观察同向并补全了它：**

> **[sharecentre](sharecentre.md)（625 字）：正文越长，评论越少。**
> **本样本（70 字）：正文越短，反应越满。**

**两者合起来是同一条规律的两端：**

> **正文长度决定读者的参与形式。**
> **长文让人读完就走；短帖让人点一下；中等长度（[SteamNy](SteamNy.md) 的 204 字，给出价格、时限、简介）才给读者留下足够的讨论素材。**

**本语料由此得到一条可操作的观察：如果目标是评论，正文既不能太长也不能太短。**

## 四、核心发现三：零标签、零参数、零变现

**这个账号没有标签体系。**

**本语料的标签用法至此十二种**（[projectXray](projectXray.md) 第三节确立第十二种"工单编号标签"），**而这个样本是一个干净的"不用"。**

**它与本语料的"装饰性标签"**（[lover_links](lover_links.md) 八个各 1 次）**不同：那是想做没做起来，这是根本没打算做。**

**结合正文只有 70 字、287 条网页预览——这个账号把一切都压到了最简：一行字，一个链接，让商店页面的预览卡片承担剩下的全部信息。**

**参数分析：300 条帖子里只有 1 个查询参数，且属于发行商自身的站内标识。**

**没有 `utm_`、没有联盟码、没有 `from`、没有短链。**

**本语料的"链接处理六档"：**

| 档 | 做法 | 样本 |
|---|---|---|
| 1 | 上游参数都不洗 | [kejiqu](kejiqu.md)、[SteamNy](SteamNy.md) |
| 2 | 原样转发 | [moeisland](moeisland.md) |
| **3** | **裸链接** | **[sspai](sspai.md)、steamsteam** |
| … | | |

**它落在第三档（裸链接），比 [SteamNy](SteamNy.md) 的第一档更干净**——**那个账号从上游数据站复制链接时把跟踪参数带了出来，这个账号连这个都没有。**

**两个账号合计 728 条购买链接（[SteamNy](SteamNy.md) 的 450 个 `offers` 参数 + 这个账号的 214 + 150 + 13），自有返佣标识零个。**

**本语料在 [SteamNy](SteamNy.md) 第四节把这种情形记为"不变现的第十二种类型：唾手可得而不取"，并推测动机是保护推荐的可信度。**

**当时只有一个样本。**

**这是第二个独立样本，两个账号互不相关（域名、排版、标签、互动结构全都不同），而行为一致。**

**本语料由此可以把那条推测升格：**

> **在游戏限免这个品类里，不用返佣是行业惯例，不是个别账号的选择。**

**这个惯例的合理性可以从 ERR 反推：38–42% 的 ERR 意味着订阅者高度信任这些账号。** **而限免内容的特点是"本来就免费"**——**一旦链接里带上返佣码，读者会立刻怀疑推荐的动机，而这个品类的全部价值就是"他说免费就是真免费"。**

## 五、实现技术思路

| 层 | 做法 |
|---|---|
| 内容 | **一行标题 + 一条裸链接** |
| 形式 | **网页预览卡片承担全部信息呈现**（287/300） |
| 标签 / 参数 / 广告 | **全部为零** |
| 文件 | 1 个 |
| 互动 | **反应 + 评论全开** |
| 自动化 | **无**（限免时效需人工核实） |

**正文 max 263 字符、中位 70——300 条帖子的长度分布极窄。**

**这不是模板生成的**（本语料在 [wublock](wublock.md) 第四节确立的判据：机器模板的特征是覆盖率 100% + 完全一致，而这里的每条标题都不同），**是一个稳定的编辑习惯。**

**存活率 99.0%（300 条只删了 3 条）：** **限免信息过期后不删，与 [SteamNy](SteamNy.md)（97.4%）一致。**

**本语料在 [lychee_wood](lychee_wood.md) 第六节确立过"删除率的决定因素是内容有没有一个过期时刻"。**

**限免是有过期时刻的**——**但这两个账号都不删。**

**这给那条规律补一个例外说明：**

> **过期的内容是否被删，取决于它过期后还有没有档案价值。**
> **一条过期的限免记录仍然是"这个游戏曾经免费过"的证据，读者会回查。**
> **对照 [shareAliyun](shareAliyun.md)（99.0% 删除率）：一个失效的网盘链接没有任何档案价值。**

## 六、成本

**经常性（月）：¥0。**

| 项目 | 金额 | 依据 |
|---|--:|---|
| 频道 / bot / 域名 / 服务器 | **¥0** | 零自有基础设施 |
| **内容生产（时间）** | — | **0.41 帖/天，每条需核实限免是否真实生效** |

**这是本语料时间成本最低的有价值频道。**

**0.41 帖/天 ≈ 每 2.4 天一条。** **每条的工作量是：发现限免 → 核实 → 写一行标题 → 贴链接。**

**按每条 5–10 分钟算，约 2–4 分钟/天。**

**对照本批：** [sharecentre](sharecentre.md) 1.5–2.7 小时/天、[zrj96](zrj96.md) 60–120 分钟/天、[SteamNy](SteamNy.md) 5–10 分钟/天、[lychee_wood](lychee_wood.md) 约 15 分钟/天。

**它比 [SteamNy](SteamNy.md) 还低一半，因为它不写简介、不打标签、不做汇总。**

**而它的 ERR 只比 [SteamNy](SteamNy.md) 低 7.9%。**

**本语料由此得到一条：在有确定行动价值的品类里，内容加工的边际收益很低。** **读者要的是"哪个游戏免费了"，不是"这个游戏好不好玩"。**

## 七、收益

**可观测：¥0。**

**零联盟码、零返佣参数、零广告、零收款账号、零订阅墙、零商品。** **粗筛命中 0/300——本语料少有的绝对零。**

**未变现的承载力：¥2,000–15,000/月。**

**估算与 [SteamNy](SteamNy.md) 第八节同口径，四条依据：**

1. **返佣路径现成。** 377 条商店购买链接（214 + 150 + 13），**技术上只需加一个标识。**
2. **受众与转化质量高**：**ERR 38.54% + 反应覆盖率 100% 说明读者是真的在看并且在行动。**
3. **广告位价值：** 游戏发行商、外设、加速器是明确的潜在买家。
4. **上锚略低于 [SteamNy](SteamNy.md) 的 ¥20,000**，两条原因：**这个账号的评论密度只有那个的 23%（社群影响力弱），且完全没有标签体系（历史内容不可回查，广告的长尾价值低）。**

**下锚 ¥2,000 的依据：** **一个 1.54 万订阅、单帖 5,930 阅读、每帖必有反应的垂直号，即便只按最保守的单帖曝光计价，月度也在四位数。**

**区间宽的原因与 [SteamNy](SteamNy.md) 相同：返佣按成交分成、广告按帖报价，两种模式没有可换算的锚，且本报告看不到任何转化数据。**

## 八、增长策略

| 机制 | 证据 | 判读 |
|---|---|---|
| **刚需内容** | 限免是硬需求 | **主要机制** |
| **极简形式** | 一行字 + 一条链接 | **降低阅读成本** |
| 转发外溢 | 均值 11.0、max 91 | 强 |
| 互动全开 | 反应 100%、评论 145 帖 | 留存 |
| 零返佣 | 377 条链接无一自有标识 | **可信度** |
| 标签 / 互推 / 矩阵 | **全部为零** | |
| 买粉 | **无迹象** | ERR 38.54% + 100% 反应覆盖 |

**这个账号的增长机制里，唯一与 [SteamNy](SteamNy.md) 不同的是它没有投稿 bot。**

**[SteamNy](SteamNy.md) 第五节把投稿 bot 解释为"把最耗时的发现线索外包给读者"，并用它解释那个账号为何能以 0.47 帖/天维持 41.60% 的 ERR。**

**这个账号没有众包机制，却拿到了几乎相同的 ERR。**

**这说明那条解释需要修正：**

> **投稿 bot 提高的是覆盖率（能抓到多少条限免），不是单条内容的价值。**
> **而 ERR 是由单条内容的价值决定的。**

**两个账号的发帖频率几乎相同（0.47 vs 0.41），说明众包并没有显著提高产出量**——**限免这件事本身的发生频率就是这个量级。**

**这是本语料第一次能用双样本对照来证伪一条单样本推论。**

## 九、法律风险

**风险等级：低。** 与 [SteamNy](SteamNy.md) 第十节的结论一致，且比它更干净。

- **内容：商品折扣信息与官方链接。** 300 条全部指向商店官方页面，**未见任何盗版、破解、密钥交易或账号共享。** 与本语料 [Pojieapp](Pojieapp.md)、[shareAliyun](shareAliyun.md) 的分发性质不在一个范畴。
- **著作权：几乎无接触面。** **只有 1 个文件（4.0 MB 的 mp4）**，**其余 299 条是纯文本 + 网页预览。** **网页预览由 Telegram 自动抓取商店页面的公开 OG 元数据生成，不构成运营者的复制行为。** **这比 [SteamNy](SteamNy.md)（46 个文件 / 208 MB 的官方预告片）的接触面还小一个量级。**
- **未标注商业关系：无关系可标。** 零返佣、零广告、零赞助——**《广告法》第 14 条不产生适用场景。** **377 条链接中零个自有标识，这是可验证的。**
- **价格与时限信息的准确性。** 帖子声明某游戏限时免费。**若信息错误导致读者扑空，属事实性错误而非虚假宣传**——**这个账号不是经营者、不销售商品、不从成交中获利，不符合《消费者权益保护法》第 8 条与《广告法》第 28 条的主体要件。** **532 条评论构成事实上的纠错机制。**
- **境内连接点。** 简体中文、受众以中国大陆玩家为主、链接带简体中文语言参数。**中国法有管辖意义，但内容不涉及违法事项。**
- **不适用**：不涉及开设赌场罪（0 条博彩内容、0 个博彩域名、0 个客服号）；不涉及传播淫秽物品罪（0 条成人内容，唯一的文件为游戏视频）；不涉及帮助信息网络犯罪活动罪（0 个收款账号、0 个联盟参数、0 条商业导流、0 个支付通道）；不涉及非法经营罪（零收入）；不涉及侵犯公民个人信息罪（无 bot、无数据收集）；不涉及提供翻墙服务（域名中无机场、节点、订阅）。

**责任主体**：运营者（单账号署名，**身份在样本中不可见**）。**暴露面：零域名、零收款、零商业关系、零文件托管**——**这是本语料商业价值与暴露面之比最悬殊的样本之一：一个单帖 5,930 阅读、每帖必有反应、有成熟变现路径的账号，在 Telegram 之外几乎不留痕迹。**
