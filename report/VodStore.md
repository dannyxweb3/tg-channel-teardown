# VodStore · 影视搜索

> ⚠️ 本报告涉及博彩推广与境外招工信息。**不复现任何博彩站点域名、娱乐城品牌、招工联系人账号、搜索 bot 的用户名与深链载荷。**
>
> **群 · 23,322 成员 · 可见 300 条 · 发言人 70 · bot 消息 62% · 300 条/天 · 存活率 77.7%**
> 数据来源：`scripts/tg_recon.py dump VodStore --limit 300` → [data/recon/VodStore.jsonl](../data/recon/VodStore.jsonl)
> 抓取时间 2026-09-20（含发言人字段的重抓） · 样本 300 条（**同一天内**）

**一句话结论：62% 的消息来自同一个影视搜索 bot，而它每一条消息的第一行都是一条广告——不是附在末尾，是顶在最前面，正片名单排在广告下面。300 条里 1,727 个指向该 bot 的深链，全部带 `start=` 载荷。广告抬头逐条统计：博彩投注 59 条、境外"体育公司直招" 23 条、某娱乐城 21 条、另一家 18 条、出售一年以上的老 Telegram 账号 17 条。其中那条招工广告的卖点是「开放公司不禁足」——把"我们不会把你关起来"当作招聘优势写在广告里，这句话本身就是对那个行业常态的确认。而它推的一个博彩域名，与本语料此前分析过的 [soutv](soutv.md) 出现的是同一个（那边 21 次，这边 22 次）。**

## 二、核心发现一：广告在正文第一行，内容在下面

**该 bot 的每条消息结构完全固定：**

```
🎯 <一条广告，占满第一行>

1️⃣ [类型-地区] <片名>
2️⃣ [类型-地区] <片名>
…
🔟 [类型-地区] <片名>

🎗第 N 页，共 14 页
```

**广告在最上面，十条影视结果在下面，每条结果是一个 `t.me/<bot>?start=<载荷>` 深链。**

**这是本语料第一次看到"广告位在内容之前"的版式。** 此前记录的所有形态——页脚署名（[thinkpositivewords](thinkpositivewords.md)）、末尾 `#ad`（[tginfoen](tginfoen.md)）、独立成帖（[speedcentre](speedcentre.md)）、正文里的联盟短链（[BaccanoSoul](BaccanoSoul.md)）——**广告都在内容之后或之中。**

**把广告顶到第一行的效果很直接：** Telegram 的消息预览、通知栏、以及会话列表里显示的都是消息开头，**所以广告获得的曝光高于内容本身。**

**广告抬头逐条统计（300 条里）：**

| 广告类型 | 条数 |
|---|--:|
| **博彩投注（欧洲杯/百家乐/电子）** | **59** |
| **境外"体育公司直招"** | **23** |
| 代理服务推广 | 22 |
| **世界杯投注** | **22** |
| **某娱乐城品牌 A** | **21** |
| **某娱乐城品牌 B** | **18** |
| **出售一年以上的老 Telegram 账号** | **17** |

**博彩类合计 120 条，占全部 300 条的 40%、占 bot 消息的 64%。**

**这不是"群里有人发广告"，是这个 bot 的商业模式：它用影视搜索换流量，用流量位卖博彩广告。**

## 三、核心发现二：「开放公司不禁足」

**23 条招工广告的完整卖点结构是：**

> **「体育公司直招非中介—❤️开放公司不禁足｜多国岗位多多🇹🇭曼谷 🇦🇪迪拜 🇵🇭菲律宾 🇰🇭柬埔寨 🇱🇰斯里兰卡@…」**

**逐项解码：**

| 表述 | 含义 |
|---|---|
| **「体育公司」** | 中文灰产对**网络博彩平台**的通用代称（"体育"指体育博彩） |
| **「直招非中介」** | 不经过中间人——**中介环节是这类招工中最常发生诈骗与拘禁的一环** |
| **「开放公司」** | 与"封闭园区"相对 |
| **「不禁足」** | **员工可以自由出入** |
| 五个国别 | 东南亚与中东的已知博彩/诈骗产业聚集地 |

**「开放公司不禁足」这五个字是本报告最值得单独指出的一处。**

**一条招聘广告把"不限制人身自由"当作卖点写出来，前提是读者知道同类岗位普遍不是这样。** **这是一个行业常态的反向证据——不需要任何外部资料，这句广告词自己就说明了问题。**

**本语料此前解码过多条灰产黑话，但性质不同：**

| 黑话 | 出处 | 性质 |
|---|---|---|
| 「上押 X 万 U」 | [fufeikc](fufeikc.md) | 信用机制 |
| 「全民代理全民收单」 | [fufeikc](fufeikc.md) | 分工结构 |
| 「免实名 免绑卡」 | [fufeikc](fufeikc.md) | 规避手段 |
| 「官方零接触用户」 | [Meitian](Meitian.md) | 责任隔离 |
| **「开放公司不禁足」** | **VodStore** | **对人身自由状况的反向确认** |

**前四条说的是怎么做生意，这一条说的是人的处境。**

**同一批广告里还有一条与之呼应：「出一手 tg 号，一年以上老号」（17 条）。** "一手"指未被使用过、"一年以上老号"指注册时间久（不易被平台风控）。**本语料在 [voice_google](voice_google.md) 分析过这类账号买卖，在 [gouwu](gouwu.md) 记录过其供货端——这里看到的是它在博彩推广链条里的实际用途：需要大量老号来发广告、加好友、规避封禁。**

## 四、核心发现三：与 [soutv](soutv.md) 的同一个域名

**本报告对全语料 291 个 dump 做了交叉检索，发现本群推广的一个博彩域名同时出现在 [soutv](soutv.md) 的 dump 里：**

| 样本 | 该域名出现次数 |
|---|--:|
| [soutv](soutv.md) | 21 |
| **VodStore** | **22** |

**两个样本互不相关**——[soutv](soutv.md) 是此前批次分析过的一个影视搜索号，本群是本批次的一个影视搜索群，**它们由不同的运营者管理，却在推同一个博彩站。**

**这确认了一件此前只能推断的事：博彩平台是按"流量位"批量采买的，而中文影视搜索类流量是它的重点采买对象。**

**本语料的博彩载体清单至此八个：**

**八个里有三个是影视类（soutv、dianying4K、VodStore）**——**这是占比最高的一个品类。** 合理解释：找盗版影视的人群与博彩目标人群高度重合，**且影视搜索是"高频、低门槛、匿名"的行为。**

## 五、实现技术思路

**这是一个 bot 驱动的群，而不是一个有人聊天的群。**

| 维度 | 实测 |
|---|---|
| bot 消息 | 187/300（62%） |
| 其中单一搜索 bot | 185 |
| 人类发言 | 113 条，70 个发言人 |
| 人类发言的正文 | 极短（样本中可见的是片名、两三个字的查询词） |

**人类在这里只做一件事：打片名。** bot 返回一页十条结果 + 一条广告。

**分页机制**：每条 bot 回复末尾标注「第 N 页，共 14 页」——**说明库里对一个关键词有一百余条结果，用户可以翻页，而每翻一页就看到一条新广告。**

**这是广告曝光的放大器：一次搜索 = 最多 14 次广告曝光。**

**`start=` 深链 1,727 个**：每条结果都是一个带载荷的 bot 深链，**点击后由 bot 私聊发送实际内容。** **这意味着真正的影视资源从不出现在群里**——**群只是一个检索界面与广告位。**

**风险结构因此是分层的**（与本语料 [magazinesclubnew](magazinesclubnew.md) 的两层架构同理，但更彻底）：

```
群（公开可见）：只有片名列表 + 广告，无任何资源
      ↓  start= 深链
bot 私聊（不可见）：实际内容分发
```

**存活率 77.7%** 在本批十一个群里排第二——**因为广告本身就是 bot 发的，没有人删它。**

## 六、成本

**经常性（月）**

| 项目 | 金额 | 依据 |
|---|--:|---|
| **搜索 bot + 资源库** | **¥500–3,000** | 需要维护一个影视索引与分发后端 |
| 服务器 | ¥100–500 | 300 条/天的消息量 + 私聊分发 |
| 人力 | ¥0–500 | 几乎全自动 |

**经常性合计 ¥600–4,000/月。**

**这个数字对一个日发 300 条、成员 2.3 万的群来说极低**，**原因是所有内容都由 bot 产出，而广告位是直接卖的现成库存。**

**真正的成本不在群里，在 bot 后端**：一个能对一百余条结果分页的影视索引，**需要持续更新片源与元数据。** 本报告无法观测其规模，**但"第 N 页，共 14 页"说明单个关键词就有上百条结果，整库的量级不小。**

## 七、收益

**唯一路径：广告位。而这个位置的定价可以反推。**

**估算：¥6,000–40,000/月，置信度中。**

依据：

1. **曝光量**：300 条/天 × 每条一个广告位 = **每天 300 次广告曝光**，且这还只是可见部分（存活率 77.7%，实际约 386 次/天）。**加上分页机制，单次搜索最多 14 次曝光。**
2. **广告主数量**：至少 **7 个不同的广告主**（博彩 4 个品牌、招工 1 个、代理服务 1 个、账号买卖 1 个）。
3. **博彩广告在中文 TG 的定价远高于正规广告**——本语料 [Meitian](Meitian.md) 第七节估过单条 ¥500–5,000，**而这里是常驻轮播位而非单条。**

**按 7 个广告主 × 月费 ¥1,000–6,000 计：¥7,000–42,000/月。**

**区间宽的三条原因：**

1. **轮播位的定价方式不可观测**（按月、按曝光、按转化）。
2. **部分广告可能是自家的**——**"出一手 tg 号"这条与 bot 运营者的业务高度相关**（运营一个日发 300 条的 bot 需要大量账号），**它可能不是买来的广告位，是自营业务。**
3. **博彩广告主的付款稳定性差**，行业内跑路常见。

**一个结构性观察：这个群的商业模式与本语料的 [zaproshare](zaproshare.md)（盗版软件 + 三层变现）在形式上相似，但更纯粹。** zaproshare 还在写内容、还在挑资源；**这个群连内容都是 bot 生成的，人只需要收广告费。**

**这是本语料"内容成本趋近于零而广告收入不变"的极端案例。**

## 八、增长策略

| 机制 | 证据 | 判读 |
|---|---|---|
| **搜索即服务** | bot 185 条回复、1,727 个深链 | **唯一价值** |
| 分页 | 「共 14 页」 | **广告曝光放大器** |
| 零门槛 | 打个片名就有结果 | |
| 广告置顶 | 广告在正文第一行 | 曝光最大化 |
| 互推 | 三个第三方频道各 17–59 次 | 轻度 |
| 买粉 | **无从判断** | 群成员数无法验证 |

**2.33 万成员来自"能搜到片子"这一条。**

**与本语料的其他资源型样本对比，它省掉了最重的一环：** [yeqingjie_GJG666](yeqingjie_GJG666.md) 要自己上传到七个网盘、[zaproshare](zaproshare.md) 要写介绍配图、[magazinesclubnew](magazinesclubnew.md) 要跑 LLM 和 TTS——**这个群只需要一个 bot 和一个索引。**

**代价是它完全没有内容识别度。** 没有标签体系、没有栏目、没有任何编辑痕迹。**读者记住的是"那个能搜片的 bot"，不是这个群。**

**分页机制是这个模式里最精巧的一处设计。** 它同时做了两件事：**降低单条消息的长度（十条一页，可读）**，**以及把一次搜索变成最多 14 次广告曝光。** **本语料没有第二个样本用过这种手法。**

## 九、法律风险

**风险等级：刑事。** 本批风险最高的样本之一。

- **为境外赌博平台发布广告（主要风险）。** 120 条博彩广告（占全部消息的 40%），涉及至少四个娱乐城品牌，文案中出现「包出款」「注册送 28U」「上押」等本语料已解码的行业黑话。**依《关于办理网络赌博犯罪案件适用法律若干问题的意见》，为赌博网站提供宣传广告等直接帮助的，以开设赌场罪的共犯论处**；达不到共犯程度的落入《刑法》第 287 条之二帮信罪。**以 USDT 计价的表述另牵连 2021 年九部委通知项下的非法金融活动。** 责任主体为 bot 运营者与群主。
- **境外招工广告——本案最严重的一项。** 23 条广告招募人员前往东南亚与中东五国从事"体育公司"（网络博彩）工作。
  - **单纯发布境外招聘信息不必然违法**，但**为境外赌博企业招募人员，本身就是为赌博犯罪提供帮助。**
  - **更严重的是「开放公司不禁足」这一表述所指向的语境。** 该表述以"不限制人身自由"为卖点，**说明发布者明知同类岗位存在限制人身自由的情形。** 若被招募者实际遭到拘禁、强迫劳动，**发布广告者可能涉及《刑法》第 240 条拐卖妇女、儿童罪（如涉及）、第 244 条强迫劳动罪的帮助犯、或第 262 条之一组织残疾人、儿童乞讨罪之外的相关规定**；实务中此类案件更常以**组织他人偷越国（边）境罪（第 318 条）** 或**诈骗罪共犯**追究。
  - **中国对赴东南亚博彩园区务工的治理是近年的执法重点**，**发布此类招工信息在司法实践中已有入罪判例。**
  - **本报告不复现联系人账号与任何具体岗位信息。**
- **出售 Telegram 老号（17 条）。** 与本语料 [voice_google](voice_google.md)、[gouwu](gouwu.md) 记录的同类行为一致：**可能触及侵犯公民个人信息罪（若账号关联他人身份）或帮信罪（为他人规避平台风控提供工具）。**
- **影视资源的著作权。** bot 索引覆盖泰剧、韩综、恐怖片、纪录片、短剧等多类作品，**单个关键词就有十四页结果。** 虽然资源本身通过 bot 私聊分发、不在群内出现，**但运营者是索引与分发的直接提供者**，**《信息网络传播权保护条例》的避风港规则不适用于自营服务**（与 [yeqingjie_GJG666](yeqingjie_GJG666.md)、[magazinesclubnew](magazinesclubnew.md) 的分析一致）。**相对于博彩与招工问题，这一项反而是次要的。**
- **群主的管理义务。** 依《互联网群组信息服务管理规定》第 9 条，**群主对群内信息负管理责任。** 本案中广告不是"群成员发的"，**是群主自己的 bot 发的**——**不存在任何"未尽管理义务"的辩解空间，这是直接实施。**
- **跨样本证据。** 本群推广的一个博彩域名与本语料 [soutv](soutv.md) 中出现的是同一个（21 次 vs 22 次）。**这意味着若对该博彩平台立案，两个互不相关的中文 TG 流量位会被同时牵出。**
- **不适用**：不涉及传播淫秽物品罪（可见内容 0 条成人内容）；不涉及非法经营罪的出版物条款（无出版物销售）。

**责任主体**：搜索 bot 的运营者与群主（**大概率是同一人——bot 发了 62% 的消息且没有任何人删它**）。**暴露面**：bot 必须有服务器与后端索引库（与 [Hao12News](Hao12News.md)、[magazinesclubnew](magazinesclubnew.md) 同理）；**而 1,727 个 `start=` 载荷是一份完整的资源清单，取证价值极高。** 广告主一侧的域名、账号与品牌则是另一条独立的线索链。
