## 二、核心发现一：100% 的分钟 `:20`

**分钟分布只有一个值：**

```
:20  300 条（100%）
```

**这是本轮最干净的 cron 签名，没有之一。**

**本轮的 cron 指纹排名：**

| 频道 | 最强单字段聚集 | 覆盖率 |
|---|---|--:|
| **sspai** | **分钟 `:20`** | **100%** |
| [programmerjokes](programmerjokes.md) | 分钟 `:30` | 98% |
| [solidot](solidot.md) | 分钟 mod 5 = 0 | 92% |
| [AI_News_CN](AI_News_CN.md) | 秒 `:01–:03` | 58% |
| [NewlearnerChannel](NewlearnerChannel.md) | 分钟 `:59` | 53% |

**而秒是散的**（`:39` 15、`:36` 13、`:21` 12，最高仅 5%），**小时铺开在 7–23 点。**

**这三件事合起来只有一个解释：一个每小时在 `HH:20` 触发的轮询任务，抓取站点的新文章队列，逐条发出。** **秒的散布来自每次抓取的文章数不同、网络耗时不同。**

**小时分布反映的是少数派网站自己的发稿节奏：**

```
16 点 61 | 19 点 53 | 12 点 52 | 10 点 32 | 18 点 21 | 17 点 17 | 9 点 16
```

**16 点、19 点、12 点三个峰** ——**这是一家内容公司的编辑部排期，不是频道的排期。**

**间隔中位 14,370 秒（约 4 小时），`<60 秒` 仅 2%** ——**说明每次轮询通常只有一篇新文章，很少批量。**

## 三、核心发现二：栏目化的内容结构

**每条消息的格式完全固定：**

```
<标题> [by <作者>] https://sspai.com/post/<id>
```

**从标题的前缀能还原出站点的栏目体系：**

| 栏目 | 条数 | 性质 |
|---|--:|---|
| **本周看什么** | **13** | 影视推荐周更 |
| **派评** | **12** | 近期值得关注的新应用 |
| **角落新声** | **12** | 社区栏目 |
| **App+1** | **8** | 单个应用深度介绍 |
| **TDS REVIEW** | **7** | 评测 |
| **具透** | **6** | 系统更新解读 |
| 派早报 | 多条 | 每日新闻速递 |
| 开学季 | 4 | 季节性专题 |
| 线下活动 | 3 | |
| **声擎 × 少数派** | **2** | **品牌合作内容** |

**四个高频栏目（本周看什么 13、派评 12、角落新声 12、App+1 8）合计 45 条，占样本 15%** ——**这是固定周更的骨架，其余是单篇投稿与编辑部稿件。**

**`[by 作者]` 这个字段是关键**：样本内出现的署名包括 `克莱德`、`LOSSES`、`Cyanrel`、`Bestony`、`阿帅的健康笔记`、`neyham`、`少数派编辑部`。**大部分内容由外部作者投稿，编辑部只占一部分。**

**与 [solidot](solidot.md) 的对比很直接：**

| | [solidot](solidot.md) | **sspai** |
|---|---|---|
| 作者身份 | **科幻笔名，五十余个** | **真实 ID，部分是知名作者** |
| 内容性质 | **编译外文短讯** | **原创长文** |
| TG 里给什么 | **全文（494 字）** | **标题 + 链接（70 字）** |
| 站点回链 | 有但不必点 | **必须点** |

**两个都是站点的 TG 出口，但一个把内容给完，一个只给标题。**

## 四、核心发现三：14 条 Prime 链接

**样本内有 14 条链接指向 `sspai.com/prime/story/...`** ——**少数派的付费会员内容。**

```
具透 Plus：Android 17 的应用内存限制；谈谈 macOS 和 Linux 如何运行可执行文件
AI 时代的 Surface Pro 7 改造指南：看板、轻量工作站与 Linux 笔记本
```

**加上「声擎 × 少数派」这样的品牌合作内容 2 条。**

**这 16 条是整个样本里仅有的商业化痕迹，而且都不是 TG 侧的变现——它们是站点侧付费墙与品牌合作的入口。**

**这定义了这个频道的角色：它不产生收入，它把流量送到产生收入的地方。**

**Prime 内容占样本的 4.7%** ——**比例不高，说明它没有把频道当作会员转化的主战场。**

## 五、核心发现四：极低的互动，极稳的阅读

**两组反常的数字放在一起：**

```
反应   202 总计，ER 0.03%      ← 本轮最低之一
转发   中位 2，均值 4.1        ← 低
阅读   p10 2,262 / 中位 2,490 / p90 3,207，极差 42%   ← 本轮最稳之一
```

**帖龄分桶（九个桶，样本量 22–27 条，分布极均匀）：**

```
0–7 天    1,933（n=24）
7–14 天   2,279（n=27）
14–21 天  2,512（n=25）
21–28 天  3,012（n=24）
28–35 天  3,248（n=26）
35–42 天  2,306（n=24）
42–49 天  2,394（n=24）
49–56 天  2,510（n=22）
≥56 天    2,461（n=104）
```

**第 21–35 天是峰值（3,012 / 3,248），之后回落到 2,300–2,500 的稳定水位。**

**这条曲线与 [solidot](solidot.md) 的（7 天 2,967 → 21 天 3,677 → 之后持平）形状一致：三周饱和。** **两个独立样本互相验证了这条规律。**

**月度中位阅读几乎不动**：2026-06 的 2,478 → 07 的 2,451 → 08 的 2,601 → 09 的 2,071（未成熟）。**88 天内没有任何趋势。**

**「阅读极稳 + 互动极低」的组合说明了受众关系的性质：**

**订阅者把它当作 RSS 用。** **他们每天扫一眼标题，点开感兴趣的，不点赞、不转发、不评论。**

**对照本轮 [programmerjokes](programmerjokes.md)**（同样阅读分布极窄、极差 34%，但转发中位 209）：**两者的读者都极其稳定，但一个会转发，一个不会。** **区别在于内容能否脱离语境——梗图可以直接转给同事，一篇长文的链接不行。**

**转发榜也印证这一点：**

| 内容 | 转发 | 阅读 |
|---|--:|--:|
| **让 Windows 顺眼又省心：我的新设备配置经验** | **50** | 3,806 |
| **UniGetUI：可能是 Windows 下最好用的应用商店** | **44** | 4,379 |
| 写给「跑两步就喘」的你：调整跑步姿势 | 22 | 2,451 |
| 浏览器扩展合集：6 款实用有趣的「新玩意」 | 19 | **7,687** |

**转发前两名都是 Windows 配置类——可直接转给"刚装完系统的朋友"的内容。**

**而阅读第一（浏览器扩展合集 7,687）只有 19 次转发。**

**又一次验证了本轮的规律**：**阅读由好奇驱动，转发由"对方需要"驱动**（[shareAliyun](shareAliyun.md) 的剧 vs 课、[solidot](solidot.md) 的荒诞新闻 vs 切身议题）。

**阅读第二名值得一提**：

> **有毒职场正在炼成：OKR 变成 KPI，敏捷开发变成切碎的瀑布**（7,279 阅读）

**这与 [solidot](solidot.md) 转发第二（程序员猝死不认定工伤）是同一类选题**——**两个中文科技媒体在同一时期都把职场议题推到了前列。**

## 七、收益

| 路径 | 样本内证据 | 估算 |
|---|---|---|
| 广告帖 | **0 条** | **¥0** |
| 联盟 / aff | **0 个参数** | **¥0** |
| 付费 / 打赏 | **TG 侧 0 个入口** | **¥0** |
| Prime 导流 | **14 条 `/prime/` 链接（4.7%）** | 站侧收入不可观测 |
| 品牌合作导流 | 「声擎 × 少数派」2 条 | 站侧收入不可观测 |
| **TG 侧合计** | | **¥0/月** |

**TG 侧零收入，且这是设计如此——它的全部作用是把读者送回 `sspai.com`。**

**导流量可以估：**

- 3.41 条/天 × 88 天 = 300 条，**月曝光约 22 万次**（中位阅读 2,490 × 约 90 条/月）
- **每条都是一个必须点击才能读到内容的链接**
- 科技媒体 TG 链接的点击率参考 3%–10%

> **月导流约 6,600–22,000 次点击。**

**区间宽的三个原因**：(1) **点击率完全不可观测**——没有任何 UTM 或 `?from=` 参数；(2) **正文只有标题，点击率高度依赖标题质量，栏目化内容（「本周看什么」）的点击率与深度评测差别很大**；(3) 部分订阅者可能只扫标题不点。

**「零 UTM 参数」本身是一个发现**：**300 条链接全部是裸的 `sspai.com/post/<id>`，没有任何来源追踪。** **这意味着站点无法区分 TG 来的流量和其他来源——一个自动化程度很高的频道，却没有做最基本的效果归因。**

**广告承载力另算**：3.82 万订阅、中位阅读 2,490、月发约 103 条、月曝光约 26 万次，中文科技类 CPM ¥50–120：

> **月度广告承载力约 ¥13,000–31,000。**

**但这个数字对本案没有意义**：**这是一家有自有媒体资产的公司的分发渠道，在自家渠道上卖第三方广告会与站点广告位竞争。**

## 八、增长

`paid_acquisition: none`（反应量不足以做 CV 检验；零外链、零互推、零买量迹象）。

| 机制 | 证据 | 判读 |
|---|---|---|
| **母品牌** | `sspai.com` 300/300 | **订阅全部来自站点既有读者** |
| 栏目化 | 本周看什么 / 派评 / 角落新声 / App+1 等 | 可预期，形成习惯 |
| **完全自动** | 分钟 `:20` 100% | **零边际成本** |
| 阅读极稳 | p10 到 p90 差 42% | **RSS 式的固定读者** |
| 从不删除 | id 缺口 0.0% | |
| **零外部手段** | 零 @、零标签、零外链、零互推 | |
| **零互动经营** | ER 0.03%、转发中位 2 | **不试图把读者变成社区** |

**3.82 万订阅，完全靠母品牌。**

**这个号在本轮是一个对照组：它证明了一件事——一个成熟内容品牌可以用近乎零成本把 TG 变成一个稳定的分发终端，但也仅此而已。**

**它拿不到 [tginfo](tginfo.md) 的 296/300 帖评论，拿不到 [programmerjokes](programmerjokes.md) 的转发中位 209，也拿不到 [solidot](solidot.md) 的 ER 1.33%。**

**原因不在内容质量，在形态**：**只给标题和链接的频道，读者没有可互动的对象。** **要讨论就得先点出去，而点出去之后讨论发生在站点上，不在这里。**

**这是一个明确的取舍，不是一个疏忽。**

## 九、法律风险

> **level: low。**
>
> **自有内容的分发。** 300 条链接全部指向 `sspai.com`，内容由该站及其签约作者生产，`[by 作者]` 署名完整保留。**不存在第三方内容的转载或聚合问题。**
>
> **不适用的五条**：不涉及开设赌场罪（0 条博彩内容）；不涉及传播淫秽物品罪（0 条成人内容）；不涉及侵犯著作权罪（全部为自有内容，且逐条署名）；不涉及帮助信息网络犯罪活动罪（0 个第三方链接、0 个收款账号、0 条导流）；不涉及非法经营罪（TG 侧零收入，站侧为正规经营的内容平台）。
>
> **它与 [programmerjokes](programmerjokes.md)、[solidot](solidot.md) 同属本轮合规状况最干净的一档，其中 sspai 是唯一一个连著作权灰区都没有的样本**——programmerjokes 的梗图无署名，solidot 的编译稿是演绎作品，**而 sspai 分发的是自己的东西。**
