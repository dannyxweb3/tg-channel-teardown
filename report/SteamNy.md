## 二、核心发现一：本语料的互动天花板

**三项指标同时排第一：**

| 指标 | SteamNy | 本语料此前最高 |
|---|--:|---|
| 有反应的帖占比 | **97.3%** | [lychee_wood](lychee_wood.md) 39.3% |
| 评论总数 | **1,999** | [zrj96](zrj96.md) 714 |
| 评论/帖均值 | **7.9** | [zrj96](zrj96.md) 4.8 |

**反应中位数 15**——**意味着一半以上的帖子拿到 15 个以上的反应。** **本语料的其他高互动样本**（[lychee_wood](lychee_wood.md) 中位 9、[zrj96](zrj96.md) 中位 9）**都低一档。**

**本语料在 [lychee_wood](lychee_wood.md) 第三节确立过：**

> **ERR（阅读/订阅）被频率稀释；评论率（评论/阅读）不被稀释，因为分子分母都是"看到的人"。**

**用这个口径算：1,999 / (253 × 6,733) ≈ 0.12%**——**每 850 个看到的人里有 1 个留言。**

**这个数字低于 [lychee_wood](lychee_wood.md) 的 1.46%（每 68 人 1 个）。**

**两个样本合起来说明一件重要的事：评论总量与评论率是两回事。**

| | [lychee_wood](lychee_wood.md) | **SteamNy** |
|---|--:|--:|
| 单帖阅读 | 1,827 | **6,733** |
| 评论/帖 | 4.7 | **7.9** |
| **评论率（评论/阅读）** | **1.46%** | **0.12%** |

**[lychee_wood](lychee_wood.md) 是一个小而极密的圈子；这个频道是一个大而松的受众。** **前者的每个读者更可能说话，后者的每条帖子收到更多留言。**

**本语料由此补一条方法论：**

> **评论总量衡量社群规模 × 触达；评论率衡量单个读者的投入深度。** **拿总量排名会把大频道排在前面，拿比率排名会把小圈子排在前面，两者都不错，但不能混用。**

**反应率 97.3% 则指向另一件事：这个频道的内容天然适合"表态"。** **一条"某游戏现在免费领"的帖子，读者的自然反应就是点一个表情**——**本语料在 [TimeHorizonX](TimeHorizonX.md) 第四节确立过"ER 由内容能否就地产生反应决定"，这是那条规律迄今最干净的一个正例。**

## 三、核心发现二：一个真正在工作的标签体系

**八个标签的分布是 202 / 140 / 75 / 65 / 19 / 10 / 9 / 7。**

**这是本语料唯一一个呈自然幂律分布的标签体系。**

**对照本语料已经记录的三种失败形态：**

| 形态 | 样本 | 分布 |
|---|---|---|
| **装饰性**（想做索引没做起来） | [lover_links](lover_links.md)、[zrj96](zrj96.md) | 八个标签各 1 次 |
| **模板堆叠**（机器插入，无区分度） | [cool_scripts](cool_scripts.md) | 四个标签各 257 次 |
| **修辞性**（压根不为检索） | [iingtw](iingtw.md) | 整句话当标签 |
| **工作中** | **SteamNy** | **202/140/75/65/19/10/9/7** |

**分布形态本身就是判据：**

> **一个真正被用于检索的标签体系，其频次分布应当是长尾的**——**因为内容的类别分布本来就是长尾的。**
> **各用一次是没在用；全部相等是机器贴的；只有长尾分布说明每次发帖时有人在判断这条属于哪一类。**

**这个体系的结构也值得拆开看：**

| 层 | 标签 | 作用 |
|---|---|---|
| **栏目** | `#喜加一` 202 | **主线内容的固定名称** |
| **平台** | `#Epic` 140、`#Steam` 75、`#GOG` 9 | **按分发平台筛** |
| **形态** | `#移动端` 65 | 按设备筛 |
| **类型** | `#资讯` 19、`#汇总` 10、`#年度` 7 | 非主线内容 |

**三个维度正交：一条帖子可以同时是"喜加一 + Epic + 移动端"。**

**本语料的"标签十一用"**（[iingtw](iingtw.md) 第四节确立第十一种）**里，这个样本同时用了"栏目"（[jike_collection](jike_collection.md) 那一种）与"属性检索"（[AndroidThemesGroup](AndroidThemesGroup.md) 的颜色那一种），而且把它们叠在一起。**

**这是本语料第一个多维标签体系。**

## 四、核心发现三：450 个购买参数，零个自己的

**样本里 `offers` 参数出现 450 次，`curator_clanid` 18 次，`snr` 8 次，`utm_source` 若干。**

**逐个查证它们的归属：**

| 参数 | 归属 | 说明 |
|---|---|---|
| `offers` 450 | **商店自身** | 购物车预填充的商品 id |
| `curator_clanid` 18 | **上游数据站** | 一条链接同时带着 `utm_source=SteamDB`，说明是从那个站复制来的 |
| `snr` 8 | **商店自身** | 站内导航来源 |
| `l` 27 | **商店自身** | 语言 |

**没有一个是这个频道自己加的。**

**本语料的"链接处理六档"**（[kejiqu](kejiqu.md) 第二节确立）：

| 档 | 做法 | 样本 |
|---|---|---|
| **1** | **上游参数都不洗** | **[kejiqu](kejiqu.md)、SteamNy** |
| 2 | 原样转发 | [moeisland](moeisland.md) |
| 3 | 裸链接 | [sspai](sspai.md) |
| 4 | 为读者做代理 | [titan_pain](titan_pain.md)、[zhihuribao_rss](zhihuribao_rss.md) |
| 5 | 带自己的 `from` 参数 | [theblockbeats](theblockbeats.md) |
| 5.5 | 第三方短链 | [iingtw](iingtw.md) |
| 6 | 自有短域名 | [hacker_news_feed](hacker_news_feed.md) |

**它落在第一档，与 [kejiqu](kejiqu.md) 同组——那个号把上游 RSS 的跟踪参数原样带了出来。**

**但这个样本的意义比 [kejiqu](kejiqu.md) 大得多，因为它是一个游戏折扣频道。**

**这个品类有成熟的联盟体系：** 游戏商店普遍提供创作者返佣计划，**只要在链接里加一个标识，读者的购买就能产生分成。** **这是整个行业的标准做法。**

**而这个频道每天推送购买链接，累计 450 个购物车参数，一个返佣标识都没有。**

**本语料的"不变现十一种类型"**（[iingtw](iingtw.md) 第九节确立第十一种"变现即毁灭"）**在这里出现第十二种：**

> **放弃了一条现成的、零摩擦的、技术上只需加一个参数的变现路径。**

**它与已有类型的区别在"容易程度"：** [lychee_wood](lychee_wood.md) 拒绝的是需要谈判的广告；[zrj96](zrj96.md) 收到的是需要判断的询价；**这个频道放弃的是一个改链接就能拿的钱。**

**记为：唾手可得而不取。**

**这个选择的可能动机可以从 ERR 41.60% 反推：** **一个推荐限免游戏的频道，读者信任的基础是"他推荐这个是因为真的免费/真的便宜"。** **一旦加上返佣码，每一条推荐都会被重新解读。** **本语料在 [QuanX_API](QuanX_API.md)、[tginfoen](tginfoen.md)、[cool_scripts](cool_scripts.md) 记录过同构的"不该变现"逻辑，但那三个是工具/资讯类；这个是导购类**——**导购类放弃返佣，是本语料唯一一例。**

## 五、核心发现四：双人署名与投稿入口

**发言人字段显示两个：主账号 299 条，另一个署名 1 条。**

**这说明频道开启了消息署名，且有至少两个管理员。**

**本语料的频道样本绝大多数是单人署名或不署名**（[zrj96](zrj96.md)、[lover_links](lover_links.md)、[lychee_wood](lychee_wood.md)、[zhihuribao_rss](zhihuribao_rss.md) 均为 1）。**这是第一个能看到"第二个人偶尔发一条"的样本。**

**它的运营含义是：主力是一个人，但有备份。** **本语料在 [ruanlu](ruanlu.md) 第三节记录过一个 7 万人频道因原频道主退出而整体移交；这个频道的双人结构是对那种单点风险的一个轻量对冲。**

**样本中还出现了一个投稿 bot 与另一个频道名构成的三行页脚**（频道 / 群聊 / 投稿 bot）。**结合 `转自` 里最高的一个来源出现 26 次，这最可能是一条转发帖保留的上游页脚**——**本语料"转发帖保留原页脚"机制的第六次印证。**

**但无论归属如何，它揭示了这个品类的一个标准配置：**

> **频道（发布）+ 群聊（讨论）+ 投稿 bot（收集线索）。**

**限免信息是时效性极强且分散的**（不同商店、不同时区、随时开始随时结束），**单人不可能盯全。** **投稿 bot 把读者变成了线人。**

**这解释了 0.47 帖/天为什么能维持 41.60% 的 ERR：不是发得少所以珍贵，是发出来的每一条都恰好是读者需要的**——**因为线索本来就来自读者。**

## 六、实现技术思路

| 层 | 做法 |
|---|---|
| 内容 | **结构化模板**：标题行 + 商品名 + 原价/现价 + 简介 + 链接 + 标签 |
| 形式 | **网页预览 268/300**——依赖商店页面的 OG 卡片 |
| 链接 | **第一档**：原样复制，含上游参数 |
| 标签 | **三维正交体系** |
| 文件 | 46 个 / 208 MB，**36 个 mp4 为游戏预告** |
| 互动 | **反应 + 评论全开** |
| 自动化 | **无**（内容需要逐条判断价格与时限） |

**一条典型帖子的结构（脱敏后）：**

```
喜加一 | 某商店 限免（12.12）第一弹
🎮 本期限免
  「游戏名」
💝 其他
  「附赠品」
链接：STEAM
#Steam  #喜加一  #NS2682
```

**注意最后一个标签 `#NS2682`**——**一个编号标签。** **它与 [projectXray](projectXray.md) 的 `#6788`（工单号）、[nicegramchat](nicegramchat.md) 的 `#232` 同属"只有内部人看得懂的编号标签"。** **本语料至此三个样本，可以确认这是一个真实存在的用法而不是偶然。**

**文件名 `哔哩哔哩_《影之刃零》预购开启，11分钟实机预告公开_0_36284.mp4` 是本语料"文件名取证十形"第四形（短视频下载器）的一个变体：** **`站名_标题_序号_数字`。** **它比已记录的形态多了一个站名前缀**——**说明用的是一个支持多站点的下载工具，而不是某个站点的专用下载器。**

## 七、成本

**经常性（月）：¥0–100。**

| 项目 | 金额 | 依据 |
|---|--:|---|
| 频道 / bot / 域名 / 服务器 | **¥0** | 零自有基础设施（投稿 bot 若为自有则需一台机器，但样本无法确认归属） |
| **内容生产（时间）** | — | **0.47 帖/天，但每条需要核价、核时限、写简介、打标签** |
| 视频素材 | ¥0 | 46 个文件全部是下载的官方预告 |

**时间成本的形态与本批其他样本不同：** **[zrj96](zrj96.md) 的成本在"筛选"（17.65 帖/天、60–120 分钟/天），这个频道的成本在"核实"。**

**一条限免帖如果价格写错或者时限过期，读者点进去会扑空**——**而 1,999 条评论意味着任何错误都会被立刻指出来。**

**按每条 10–20 分钟（核价 + 截图 + 写简介 + 打三个标签）、0.47 帖/天算，约 5–10 分钟/天。**

**这是本批时间投入最低的高质量频道，而它的 ERR（41.60%）是本批第二高。** **原因在第五节：投稿 bot 把最耗时的"发现线索"外包给了读者。**

## 八、收益

**可观测：¥0。**

**零联盟码、零返佣参数、零推广位、零收款账号、零订阅墙、零商品。**

**10 条广告粗筛命中全部是游戏名与商品名造成的误报。**

**未变现的承载力：¥3,000–20,000/月。**

**这是本批个人/小团队频道里最高的估值区间，四条依据：**

1. **返佣路径是现成的。** 第四节已说明：这个品类的商店普遍提供创作者分成，**技术上只需在 450 个购买链接里加一个标识。** **按 1.6 万订阅、ERR 41.60%、单帖 6,733 阅读、导购类 1–3% 的点击转化与 5% 的分成率保守推算，仅此一项就在四位数。**
2. **广告位价值高。** **受众是有可支配收入的 PC/主机玩家，且 97.3% 的帖子有反应说明他们真的在看。** **游戏发行商、外设厂商、加速器服务都是明确的潜在买家。**
3. **上锚 ¥20,000 对应"返佣 + 广告"同时做满。**
4. **下锚 ¥3,000 反映一个现实约束：0.47 帖/天意味着可售版面极少。** **本语料在 [pythonzh](pythonzh.md) 第七节确立过"定价锚是活跃度不是规模"，这里是频道侧的对应：一个月只有 14 条内容，能插的广告位屈指可数。**

**区间宽的具体原因：返佣是按成交分成（浮动、与游戏单价强相关），广告是按帖固定报价，两种模式的量级差异完全取决于读者的实际购买行为，而本报告看不到任何转化数据。**

## 九、增长策略

| 机制 | 证据 | 判读 |
|---|---|---|
| **刚需内容** | `#喜加一` 202/300 | **限免是硬需求** |
| **投稿 bot** | 三行页脚 | **线索众包** |
| **互动全开** | 292 帖有反应、253 帖有评论 | **最强留存** |
| 多维标签 | 三个正交维度 | **可回查** |
| 转发外溢 | 均值 18.8、max 139 | 强 |
| 零返佣 | 450 个参数无一自有 | **可信度** |
| 互推 | 91 次 `t.me`，其中 88 次自指 | **几乎不外导** |
| 买粉 | **无迹象** | ERR 41.60% + 1,999 条评论 |

**91 次 `t.me` 里有 88 次指向自己**——**这是本语料自指比例最高的样本（96.7%）。**

**对照 [cool_scripts](cool_scripts.md) 的 300:16（自有:第三方）与 [zhihuribao_rss](zhihuribao_rss.md) 的 298 次单向指向枢纽——** **那两个都在给别的账号导流，这个只指向自己。**

**本语料"矩阵识别六法"在这个样本上的结论是：它不属于任何矩阵，也不经营矩阵。**

**它的增长完全靠内容本身的刚需属性 + 转发外溢。**

**「喜加一」这个词值得单独记：它是中文游戏圈对"白嫖到一个游戏"的固定说法，占了 202/300 条。** **本语料"关键词占位"的第十五种形态：圈内黑话占位。**

**它与已记录的十四种的区别是：前十四种占的是通用词或专名（地名、产品名、语言名、信源名、官方身份），这一种占的是一个只有圈内人才会搜的词。**

**代价是天花板极低（不懂这个词的人搜不到），收益是精准度极高（搜这个词的人 100% 是目标受众）。**

## 十、法律风险
