## 二、核心发现一：四条变现线叠在一个人格上

**样本中四条线并存，彼此没有内容上的关联，只共享一个发布者身份：**

| 线 | 证据 | 形态 |
|---|---|---|
| **券商开户返佣** | 两条帖，列出七档佣金费率，「有需要的朋友可以私信我…我这里推荐过去有专属优惠」 | **私信成交** |
| **跟投组合** | 两条帖指向同一个财富平台的组合详情页（同一个 `portfolioId`） | **晒单** |
| **虚拟信用卡** | 3 次指向某境外虚拟卡平台，帖文说「我的…万事达虚拟卡已经开好了，看到群友的实体卡也收到了」 | **自述体验** |
| **大模型 API 转售** | 一条闭站公告，自陈「累计用户有将近两千人」 | **已关停** |

**这四条线的共同点不是主题，是"私信我"。**

**本语料此前记录的变现路径都有明确的载体**：[jichangtj](jichangtj.md) 的机场订阅、[Licensesss](Licensesss.md) 的拼车席位、[voice_google](voice_google.md) 的账号库存、[daily5kong](daily5kong.md) 的微店。**这个样本没有载体，只有一个人。**

**它与本语料的 [titan_pain](titan_pain.md)、[misakatech](misakatech.md)、[limboprossr](limboprossr.md) 同属"个人笔记频道"这一品类，但那三个都不卖东西。这一个把个人信任直接兑换成了四条独立的转化路径。**

**ERR 22.48% 是这个模式能成立的基础。** 在 5 帖/天的频率下拿到 22.48%——**对照本语料的频率/ERR 横截面：**

| 样本 | 帖/天 | ERR |
|---|--:|--:|
| [misakatech](misakatech.md) | 0.13 | 59.38% |
| [TimeHorizonX](TimeHorizonX.md) | 1.69 | 27.50% |
| [titan_pain](titan_pain.md) | 1.92 | ≈30.9% |
| [kejiqu](kejiqu.md) | 3.12 | 9.99% |
| **lover_links** | **5.00** | **22.48%** |

**它明显高于同频率区间的曲线值**（[kejiqu](kejiqu.md) 3.12 帖/天只有 9.99%）。**这是本语料"发得越少读得越多"这条规律的一个偏离点，而偏离的方向是有利的。**

**可能的解释：内容是第一人称的判断而非转述。** 本语料在 [titan_pain](titan_pain.md) 第三节观察过"人格化频道的阅读留存更高"——**这里是第二例，而且是在更高频率下做到的。**

## 三、核心发现二：一份闭站公告

**样本中有一条 3,519 阅读的公告，全文披露了一个 LLM API 转售站点的生命周期：**

> 「…运行了一段时间，累计用户有将近两千人了，感谢大家支持。Claude 官方最近封号严重，我一直无法解决相关技术问题，也存在一些协同的问题。疲于奔命，却依旧无法提供稳定的服务，最终决定闭站。」
> 「有余额的用户，快来申请退款吧！写邮件给 … 并附上你的微信收款码和余额截图，还有你的帐户邮箱信息。退款比例是充值余额的 80%，我会在两周内处理完毕。」
> 「如果你们依旧有海外模型使用的需求，我这里有 … 的渠道，可联系我。」

**这份公告是本语料关于"API 中转站"这一业态的第一份一手记录，它给出了四个此前只能推测的数字与事实：**

1. **规模：将近两千用户。**
2. **失败原因：上游封号。** 「Claude 官方最近封号严重」——**直接说明这类站点依赖的是非正规渠道获取的模型访问权，而不是官方经销。**
3. **退款比例：80%。** **不是 100%。** **剩下的 20% 没有说明理由**——**用户在关停时承担了两成损失，且没有任何合同或平台托底。**
4. **退出方式：转介。** 公告结尾把需求引向另一个渠道，**说明业务没有停，只是换了供给方式。**

**本语料在 [PinYunPs](PinYunPs.md) 第三节记录过代理圈 2026 上半年的跑路盘点（4,541 阅读）；这一条的性质不同：它不是跑路，是有序关停 + 部分退款 + 公开说明。**

**两者对照给出一条判断：这类灰色服务的"信用"完全依附于运营者的个人账号，因为没有任何第三方在托底。** **这个人选择退 80% 而不是清零走人，唯一的约束就是他还要继续用这个频道卖别的东西。**

**这也解释了第二节的结构：四条变现线共享一个人格，意味着任何一条线的失信都会污染其余三条。** **人格化变现的高转化率与高约束是同一件事的两面。**

## 四、核心发现三：券商开户的七档费率

**样本中有一条帖子逐项列出某大型券商的佣金条件：**

> 股票：万 0.86（假若入金 50 万，可以申请万 0.8，调完后永久）／ETF、LOF：万 0.5（0.2 元起）／可转债：万 0.5（0.2 元起）／北交所：万 1.8／港股通：万 0.8／国债逆回购一折／信用账户：3.98–2.4
> 「有需要的朋友可以私信我，… 我这里推荐过去有专属优惠。」

**这是本语料第一次拿到一个变现环节的完整价目表，而且是由运营者自己公布的。**

**它的信息价值在于可以反推收益结构：** 券商开户返佣在中国大陆通常按新开户数或按客户日后交易佣金的分成计算。**本报告不掌握这个人的分成比例**，但可以确定两件事：

- **他掌握的是"专属优惠"的发放权**——**这意味着他与券商侧存在一个可识别的推荐关系，而不是简单地贴一个公开链接。**
- **成交在私信里完成**——**频道上看不到任何转化数据。**

**另一条帖子把动机说得更直白：「开这个银河证券，就是为了单做这只票。需要的开户优惠的私我。」**

**同期还有两条帖子公开了美股跟投组合的详情页链接**（同一个组合 id），**以及大量对行情的判断**（「二季度 GDP 增速只有 4.3%，宏观政策在下半年『踩油门』几乎是必然的…政策面不支持股市全面转熊」「股市又好起来了，大家来开个新户吧」）。

**「对行情下判断 + 公开持仓 + 引导开户」这三件事同时出现在一个无牌照的个人账号上，是这个样本最实质的风险点，第九节展开。**

## 五、核心发现四：98.0% 的存活率

**300 条里只删了 6 条。**

**本语料的"删除成因七类"**（[creativemotion](creativemotion.md) 第四节）**中，它属于"时间序列从不删"一类**，与 [jin10light](jin10light.md)（0.0%）同型。

**但它的内容不是快讯，是笔记 + 荐股 + 推广。**

**一个同时在做金融导流的账号选择不删任何东西**，**包括那条闭站退款公告、包括所有的行情判断。**

**这与本语料的 [voice_google](voice_google.md)（99.1% 删除，库存清理）、[creativemotion](creativemotion.md)（99.9% 删除，营销物料下架）形成极端对照。**

**合理的解释是：这个账号的资产就是连续的历史。** **一个人格化的荐股账号，如果删掉自己说错的行情判断，信任就没了；而它的商业模式完全建立在信任上。**

**本语料由此补一条：删除率与变现方式相关——按信任变现的账号不能删，按库存变现的账号必须删。**

## 六、实现技术思路

| 层 | 做法 |
|---|---|
| 内容 | 第一人称短笔记（中位 25 字），133 张图片多为截图 |
| 分发 | 代码托管 21 次为最高频域名，其次是**某第三方 API 中转服务 11 次** |
| 标签 | **八个标签各 1 次**——有标签体系的形状，没有标签体系的功能 |
| 转发来源 | 5 个频道（最高 4 次），其中包含本语料已收录的 [kejiqu](kejiqu.md) 生态（频道 / 群 / bot 各 1 次引用） |
| 文件 | 6 个 / 14.9 MB，zip 3（含一个 macOS 应用包）、pdf 2、md 1 |
| **第三方 API 中转服务** | **11 次** |

> ⚠️ **更正。** 本报告初稿曾把这个出现 11 次的域名判定为该频道的"自有域名"，并据此论证它是"这个样本在技术上唯一的自建部分"。**该判断是错的。**
> 本语料在后续分析 [what_youread](what_youread.md) 时拿到了直接证据：该域名是一个大模型 API 中转服务，由另一个运营者经营，他在那个群里以第一人称发布它的上游切换、额度调整与模型上线公告。
> **因此这 11 次引用是第三方引用，不是自有资产。这个频道零自建。**

**更正后的含义反而更完整：** **那条闭站公告（第三节）里写着「如果你们依旧有海外模型使用的需求，我这里有…的渠道」**——**而这个频道同期在反复引用另一个仍在运营的同类服务。**

> **一个关停了自己服务的人，转而向读者引荐同行的服务。**

**本语料由此得到一条方法论教训**（详见 [what_youread](what_youread.md) 第三节）：

> **单样本内的域名归属判断（"这是不是它自己的站"）在没有外部证据时不可靠。**
> **一个高频出现的域名可能是自有资产，也可能只是这个人常用的第三方服务，而两者在数据上完全一样。**

**标签的用法值得单独记一笔：八个标签各出现 1 次。** **本语料的"标签八用"**（[AndroidThemesGroup](AndroidThemesGroup.md) 第三节）**在这里遇到第一个反例：标签被当成装饰而不是功能。** **一个各用一次的标签体系既不能分类也不能检索——它只是让帖子看起来更像"笔记"。**

## 七、成本

**经常性（月）：¥200–1,000。**

| 项目 | 金额 | 依据 |
|---|--:|---|
| 自有域名 / 托管 | **¥0** | **零自建（见第六节更正）** |
| **内容生产（时间）** | **—** | **5 帖/天 × 60 天，第一人称笔记，按每帖 5–15 分钟计 25–75 分钟/天** |
| API 中转站的残余成本 | ¥0 | **已关停** |
| 退款支出 | **一次性，规模不可测** | 「将近两千人」×80% 余额 |

**一次性（已发生）：API 中转站的退款。** **本报告无法估算金额**——**公告只说了用户数与退款比例，没有说平均余额。** **但这是本语料唯一一个能看到"关停成本"的样本。**

**真正的成本是时间。** 5 帖/天、60 天不间断，**且内容需要跟行情、跟 AI 工具两条完全不同的信息流。** **本语料在 [ruanlu](ruanlu.md) 第七节记录过一个人每天 20–40 分钟手打早报；这个账号的投入量级相近，但它是变现的。**

## 八、收益

**估算：¥3,000–25,000/月。区间跨度接近一个数量级，四条线各自的不确定性叠加所致。**

| 线 | 估算 | 判断依据 |
|---|--:|---|
| **券商开户返佣** | ¥1,000–15,000 | **价目表公开、发放"专属优惠"的权限、两条帖直接引导私信。分成比例与转化数完全不可观测** |
| **虚拟卡推广** | ¥500–5,000 | 3 次提及、自述体验形态；这类平台通常有邀请返佣 |
| **跟投组合** | ¥0–3,000 | 平台侧是否有跟投分成不可知；也可能纯属晒单 |
| **API 中转** | **¥0（已关停）** | 公告自陈 |
| 广告 | ¥0 | **样本中无第三方广告** |

**区间宽的四条具体原因：**

1. **全部成交在私信里，频道侧零转化数据。** 本语料在 [TimeHorizonX](TimeHorizonX.md)、[Licensesss](Licensesss.md) 都遇到过这个盲区，**但那两个至少能看到价目与席位数；这个连成交动作都看不到。**
2. **券商返佣的计费方式有两种**（按开户数 vs 按佣金分成），**两者的收入量级差十倍以上。**
3. **主力线刚刚关停。** API 中转站是四条线里唯一能估规模的（近两千用户），**而它在样本期内归零了。** **当前收入结构处在重组中。**
4. **ERR 22.48% 说明触达是真实的**，**但"看笔记的人"与"会去开户的人"之间的转化率，本语料没有任何可比样本。**

**下锚 ¥3,000 的依据：** 1.97 万订阅 × 22.48% ERR ≈ 4,400 次曝光/帖，**两条开户帖分别拿到 4,065 与 3,201 阅读。** **即便按千分之一的转化与单户 ¥200 返佣计，也在四位数。**

**上锚 ¥25,000 的依据：** **若券商返佣按客户佣金分成、且导入了少量高净值账户**（帖文中提到「入金 50 万」这个门槛），**单个客户的长期分成就能顶几十个开户奖励。** **这条路径的收入上限由客户资产规模决定，而不是由粉丝数决定。**

**这个账号的增长逻辑与本语料的工具类、资源类样本完全不同：它不靠占关键词、不靠发资源、不靠互推矩阵。它靠一个人持续说话。**

**代价是不可复制也不可转让。** [ruanlu](ruanlu.md) 第三节记录过一个 7 万人频道的运营权可以整体移交（「发车流程及相关规则维持不变」）；**这个账号移交不了——它的价值就是发言者本人。**

**跨领域内容是它扩大变现面的手段，也是它最大的结构性风险：** **AI 工具的读者与荐股的读者不是同一批人，而四条变现线共享同一个信任池。** **任何一条线出问题，四条一起受损——第三节的 80% 退款正是这个约束在起作用。**

## 十、法律风险

**风险等级：高。** 本语料的非博彩类样本中最高的一档。

- **无牌照从事证券投资咨询（主要风险）。** 样本中存在对大盘走势的明确判断（「政策面不支持股市全面转熊」）、公开的持仓组合、以及「大家来开个新户吧」式的引导。**《证券法》第 160 条规定从事证券投资咨询业务须经国务院证券监督管理机构核准**；**未经许可从事该业务，依《证券法》第 199 条责令改正、没收违法所得并处罚款；情节严重的，触及《刑法》第 225 条非法经营罪第 3 项（未经批准非法经营证券业务）。** **本样本未见收费荐股的直接证据**（判断是免费发布的），**这是有利情节——非法经营罪的"经营"要件需要营利性，而免费评论更接近言论。但"引导开户并从中获取返佣"使免费性存疑：荐股是前端，返佣是后端。**
- **券商开户返佣的资质问题。** **《证券法》第 122 条及《证券经纪人管理暂行规定》要求证券经纪人须经证券公司委托并在协会登记；证券公司不得委托无资格的机构或个人招揽客户。** **样本中"我这里推荐过去有专属优惠"表明存在一个非公开的推荐通道**——**该通道若未经合规登记，券商侧同样违规。** **这是一个双向风险点。**
- **公开佣金费率表。** 帖文逐项列出七档费率并提供"专属优惠"。**这可能涉及《证券法》第 133 条（证券公司不得以不正当竞争手段招揽业务）在渠道端的延伸，以及监管对佣金恶性竞争的持续关注。** **对个人而言，这加重了"实质从事经纪业务"的认定。**
- **境外虚拟信用卡推广。** 样本 3 次指向某境外虚拟卡平台。**此类服务涉及跨境资金流动，若被认定为变相买卖外汇或非法支付结算，触及《刑法》第 225 条非法经营罪第 4 项**（参照《关于办理非法从事资金支付结算业务、非法买卖外汇刑事案件适用法律若干问题的解释》）。**本样本中运营者是使用者与推荐者，不是发行方，参与程度是四条线里最低的一条**，**但推荐行为本身可能被评价为帮助。**
- **大模型 API 转售（已关停）。** 闭站公告自陈「Claude 官方最近封号严重」，**这句话说明该站点通过非官方渠道获取模型访问权并转售。** **这违反上游服务条款（民事违约）**；**在中国法下，若涉及规模化收款（近两千用户）与跨境技术服务，可能触及《刑法》第 225 条非法经营罪的讨论，但司法实践中此类案件极少见，且该业务已关停并退款 80%。** **退款行为在法律上是显著的有利情节。**
- **数据处理。** 退款流程要求用户提供「微信收款码和余额截图，还有你的帐户邮箱信息」。**收集他人收款码属于处理个人信息与支付信息，依《个人信息保护法》第 13、17 条需有合法性基础与告知，且第 28 条将金融账户列为敏感个人信息。** **一个个人运营者通过邮箱收集近两千人的收款码，在合规上没有任何保障措施可言。**
- **未标注广告关系。** 四条线中至少两条（券商、虚拟卡）存在利益关系，**而帖文以"我自己在用"的第一人称叙述呈现，未作任何利益披露。** **依《广告法》第 14 条，广告应当具有可识别性；第 28 条规制虚假广告。** **本语料的"广告披露八档"**（[creativemotion](creativemotion.md) 第五节）**中，这个样本落在最低一档：零披露，且伪装成个人体验。** **这比 [BaccanoSoul](BaccanoSoul.md)、[theblockbeats](theblockbeats.md) 的"无标注"更进一步——那两个至少形式上是独立帖，这个是以第一人称背书。**
