## 二、异常数据深挖：44.9% 的消息去哪了

样本 id 区间 `14,677 → 15,220`，理论 544 条，实存 300 条，**缺口 244 条（44.9%）**。

关键是看**缺口的形状**，而不只是比例：

```
相邻 id 差 = 1（未删）  199 次   ← 三分之二是连续的
差 = 2（删 1 条）        32 次
差 = 3（删 2 条）        25 次
差 = 4（删 3 条）        22 次
差 = 5（删 4 条）        12 次
差 = 6–8（删 5–7 条）     9 次
```

**删除是成簇发生的，不是每条后面跟一条。** 这可以排除 xiaoshuwu 那种"每条广告 24 小时后自毁"的模式（那种会表现为大量规律的差=2）。

成簇删除（一次连删 3–7 条）更符合两种解释：**(1) 软件版本迭代后批量清理过期帖**（对软件分享号是最自然的行为，旧版本链接失效就删）；**(2) 阶段性清理某一批不便留存的内容**。样本内证据更支持 (1)——因为存活内容里几乎没有需要"阅后即焚"的东西。

## 三、简介 vs 正文：一场关键词诱饵与实际内容的分裂

**3.1 简介是投喂给检索的**

```
专注于Windows、Mac OS、Linux、Android、iPhone、iPad、TV、
影-视、福利、磁-力、软-件、插件、脚-本、-破-解、教程、-音.乐等资源分享
```

注意那些**插进汉字中间的连字符与点**：`影-视`、`磁-力`、`软-件`、`脚-本`、`-破-解`、`音.乐`。这是**规避关键词匹配**的标准手法——让 Telegram 的举报关键词扫描与第三方内容审查抓不到"破解""磁力"这些词，同时人眼与模糊搜索仍能识别。

它规避的同时又要保留这些词，目的很明确：**这些高需求词是检索诱饵**，用来在 TG 站内搜索与第三方搜索 bot 里被"想找破解/磁力"的人命中。

**3.2 正文却基本是干净的**

对 300 条正文做词频：

| 词 | 次数 | | 词 | 次数 |
|---|---|---|---|---|
| 下载 | 97 | | 激活 | 17 |
| 教程 | 30 | | 夸克 | 6 |
| 网盘 | 25 | | **破解** | **1** |

`破解` 全样本只有 **1 次**。而 `广告` 出现 31 次，其中 **17 次是"无广告"、1 次是"去广告"**——是在把"无广告"当作推荐软件的卖点，不是在卖广告位。

实际内容长这样（真人写的，不是模板）：

> `#Mac #提词器` textream，免费开源的 macOS 提词器 —— 一款免费开源的 macOS 提词器，无需注册、可离线使用、自由调整位置，提供逐词跟踪、自动滚动和声控三种模式，适用于直播、主持、播客等场景。
> 🥰 https://textream.fka.dev/ 🧐 https://github.com/f/textream/releases

外链结构印证：`github.com` **72 次**居首，其余是官网、`greasyfork.org`、微软商店、Chrome 商店。**这是标准的开源软件策展号。**

**3.3 但转发数据暴露了受众真正想要什么**

按内容分两类比较扩散力：

| 类别 | 条数 | 中位转发 | **均值转发** | 中位阅读 |

中位数几乎一样（31 vs 27），**但均值差 1.5 倍**——差异全部来自头部爆款。看转发榜前五：

| 转发 | 内容 |

## 四、技术方案：矩阵结构与自动化程度

**4.1 双频道架构——这是本号最值得注意的设计**

正文里 `t.me` 链接指向 **`@yy_app` 共 53 次**，远超其他任何目标。典型用法：

> `#文件对比` Beyond Compare —— 使用官网下载安装包制作，去除多余菜单，去除主页横条，**集成注册码**，集成汉化帮助文件，包含单文件版和安装版。
> 🧐 https://t.me/yy_app/437

**主频道只放介绍文字和官网/GitHub 链接（干净），真正"集成注册码"的成品安装包放在 `@yy_app`。** 这是一次明确的风险隔离：

- 主频道 89,954 订阅，内容看上去全是开源推荐，**被举报下架的理由很薄**
- 分发频道承载实际侵权文件，即便被封，主频道的粉丝资产不受影响

同一个运营方还有：`@yysgchat`（交流群）、`@youyoushare_bot`（私信 bot）、`twitter.com/ishare365`（站外备份）。这是一个**四件套矩阵：策展位 + 分发位 + 社区位 + 私信位**，外加一个墙外备份。

**4.2 内容生产：人写的，不是机器**

- 文案有个性化表达和真实使用评价（"注重设计""界面简洁明快""适用于直播、主持、播客"），不同帖子句式不重复
- 有 `#Codex` `#ClaudeCode` `#Skill` 等紧跟前沿的标签，说明作者本人在用这些工具
- 标签体系细（`#Mac` 21、`#Codex` 10、`#Windows` 8、`#音乐播放器` 7、`#电子书阅读器` 5），是人工分类
- 2.0 条/天的低频，与"每条都要试用并写评价"的成本相符

**自动化程度低**——这是它和 dajiajia（全自动 276 条/天）的镜像对立面：**youyou 用人力换质量，dajiajia 用机器换数量**。

**4.3 定时痕迹：明显的晚间批量投放**

小时分布高度集中：

```
17 点 65 条 │ 18 点 112 条 │ 19 点 39 条   → 三小时占 216/300 = 72%
```

而且**相邻消息间隔 <60 秒的占 41%，<10 秒的占 15%**。这说明内容是白天攒好、傍晚 17–19 点集中排队投放（很可能用发布队列/定时工具一次性放出），而不是随写随发。分钟与秒数无固定值聚集，说明是"队列连续排空"而非整点 cron。

## 六、收益：一个几乎没在变现的优质盘

**6.1 可观测的变现动作：接近于零**

样本 300 条里：

- 无联盟码、无邀请码、无优惠码
- 无付费入群、无会员制
- 网盘链接仅 6 次（夸克 4 + 百度 1 + 腾讯 1），且未见拉新推广参数
- `机场`/`节点` 各 2 次，是软件介绍语境，不是分销

**最硬的锚点是反证：** 一个 89,954 订阅、ERR 8.4%、转发中位 28 的号，在 153 天、300 条样本里**一条广告都没接**。这不是"我们没观测到"——广告帖有极强的文本特征（报价、联系方式、招商话术），全样本零命中。

**这说明它当前处于"高资产、零变现"状态**，与本轮的 aboutrss、GoReading 同型：作者在用爱发电，商业潜力完全未兑现。

**6.4 收入趋势预测**

**区间宽的根源**：`@youyoushare_bot` 的私信内容和 `@yy_app` 的独立运营都在本次抓取范围之外，两者都可能承载未观测到的变现。本报告只给主频道可归因部分。

## 八、法律风险

> **level: medium（中低）。**
>
> **主体内容合法**：300 条里 269 条是 GitHub 开源项目、免费软件与官网直链的正常推荐（`github.com` 外链 72 次），正文中"破解"仅出现 1 次。把整个频道当"盗版资源号"并不准确——它的准确画像是一个高质量开源策展号，掺入了少量高扩散的侵权与成人内容。
>
> 风险集中在三处：**"集成注册码"的成品安装包**（Beyond Compare）与"一键激活 JetBrains 全家桶"，涉《刑法》第二百一十七条与《著作权法》第五十三条第六项，权利人为跨境主体、维权能力强；**成人内容检索工具 AVScan**（转发 272，唯一用途是反查 AV 番号）与个别影视压制资源；以及**简介用 `影-视`、`磁-力`、`-破-解` 等分隔符规避关键词识别**——规避行为本身构成主观明知，属加重情节而非中性技术选择。（"破除 AI 内容安全限制"一类新型行为目前定性不清晰，违反服务条款明确，是否入刑尚无成熟判例。）
>
> 需要指出的是，运营方已把实际侵权文件挪至独立频道 `@yy_app`，主频道只保留介绍与官网链接。这在实务上降低了主频道被举报下架的概率，**但不构成侵权抗辩**——引导并提供获取途径，同样落入"发行"的评价范围。
