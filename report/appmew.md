## 二、核心发现一：八个自家账号的矩阵，备份规则写在用户名里

**664 个 `t.me` 链接的分布：**

```
amiaotgbot   170   ← 搜索/工具 bot
appmiao      155   ← 主频道（另一个）
miaobbbbb    107   ← 备用 B
miaoaaaaa     80   ← 备用 A
appmew        78   ← 本频道自指
amiaoapp      17   ← App 相关
miaoccccc     15   ← 备用 C
jisou2        12   ← 第三方搜索 bot
```

**`miaoaaaaa` / `miaobbbbb` / `miaoccccc` 是同一个命名模板的 a / b / c 三个版本。**

**这是本轮第一次看到"备用账号的命名规则"被直接暴露在用户名上。** 本轮此前识别的矩阵——[在花](TestFlightCN.md)（zaihuapd / zaihuachat / zaihuabot / zaihuanews）、[1024](aigc1024.md)（aigc1024 / https1024 / knowledge1024）、[kk](blacktechsharing.md)（kkaifenxiang / KKSOC / ioskk）——**都是按功能或主题命名。appmew 这一组是纯序号。**

**纯序号备份的用意很直接：主号被封，用户按字母顺序去找下一个。** 用户不需要记住新名字，**只要记住"喵"这个词根加一个字母。**

**这与 79.8% 的删除率是同一套抗封策略的两面**：**删除历史 + 预置备用号。**

**外部域名同样指向自建生态：**

| 域名 | 次数 | 性质 |
|---|--:|---|
| github.com | 87 | 开源项目 |
| **www.appmiao.com** | **61** | **自家站** |
| **www.appmiu.com** | **24** | **自家备用站（miao → miu）** |
| store.epicgames.com | 8 | 限免游戏 |
| pan.quark.cn | 5 | |
| 其余零星 | 3–4 | |

**`appmiao.com` 与 `appmiu.com` 是同一套备份逻辑在域名上的复刻** ——**连拼写变形的手法都一样。**

## 三、核心发现二：内容主体是工具，但传播最广的是成人搜索引擎

**标签体系给出的是正经的软件频道画像：**

```

#限免 11 | #iOS 10 | #游戏 10 | #Android 7 | #日常 7 | #提示词 5
```

**87 个 GitHub 链接、`#源码` 27 次** ——**它确实在做开源与工具推荐。** 样本内可见完整的开发者自荐帖（某 Rust + Tauri 的代理客户端，附 GitHub 地址与项目简介）。

**但把阅读与转发排行拉出来，画像就变了：**

| 内容 | 转发 | 阅读 |
|---|--:|--:|
| **以图搜片 / 截图识别番号的成人内容搜索引擎** | **561** | 45,909 |
| 免费代理网站分享 | 228 | **85,629** |

**转发第一与第四都是成人内容站点，第二与第三都是翻墙相关。**

**量级上它们是少数**：NSFW 相关帖 5 条（1.7%）、机场/代理相关 19 条（6.3%）。

**但它们拿走了传播量的大头。**

**这个分裂很说明问题**：**频道的日常内容（开源工具、限免游戏、Windows 软件）撑起了 16.6 万订阅的体面，而真正被用户转发收藏的是那几条踩线内容。**

**「可以换邮箱撸」这半句也值得单独记**：它在教用户用不同邮箱重复领取免费额度，**与本轮 [feiyu123](feiyu123.md) 的"白嫖"教程是同一类。**

## 四、核心发现三：79.8% 的删除率

```
id 17156 → 18643，1,488 个号位存活 300 条，缺口 1,188
id 差：+1 出现 194 次（65%）| +2 38 | +3 33 | +4 12 | +6 9
```

**131 天里产生 1,488 条、删掉 1,188 条。** 按留存速度反推，**实际产生量约 11 条/天（而不是 2.29 条）。**

**本轮删除率排行更新：**

```
bigdongdongGroup  96.1%  ← 新
blacktechsharing  92.9%
Python            85.4%
gitbig            85.2%
appmew            79.8%  ← 新
abc999222         74.8%
```

**对一个内容主体合规的工具频道来说，79.8% 需要解释。** 结合 §二 与 §三：

1. **踩线内容的定期清理** ——成人站点、机场推荐、白嫖教程是最容易被投诉的部分；
2. **失效链接** ——`#限免` 11 次是有时效的；
3. **抗封的常规动作** ——不留可取证的历史，与预置备用号配套。

**第 1 种最可能**：**它把最能带流量的内容发出去，收完转发之后删掉。**

**这个推断有一个旁证**：样本内 NSFW 只剩 5 条、机场只剩 19 条，**而它们的转发量却排在前列——被删掉的 1,188 条里，这类内容的占比很可能远高于存活样本。**

## 五、节奏与形态

```

分钟最高 :05 仅 13 次｜秒 :01 出现 42 次（14%）
```

**秒 `:01` 出现 42 次是唯一的聚集信号（14%）** ——**不足以判定为严格 cron，更可能是发布脚本的固定延迟。**

**分钟完全随机、小时集中在白天 9–19 点** ——**人工为主。**

**媒体**：图片 265（88%）、网页预览 18、文件 7（0.42 GB）。**几乎不托管文件，只做索引** ——与 [WidgetChannel](WidgetChannel.md)（0.35 GB）、[feiyu123](feiyu123.md)（0.03 GB）同类，**与 [gitbig](gitbig.md)（29.01 GB）相反。**

**固定页脚**：`🌍频道 😮群聊 🉐投稿 🔥合作` 出现 77 次 + 变体 59 次。

**「🔥合作」这两个字是它的招商入口** ——**「合作 107」这个高频关键词命中，全部来自这个页脚，不是正文里的商务洽谈。**（这是本轮又一例关键词误报，但性质不同：**它确实在招商，只是命中来自页脚而非内容。**）

## 十、法律风险

> **level: high。**
>
> **1｜成人内容站点的导流（主要项）。** 样本内至少 2 条明确指向成人内容：一个"以图搜片 / 截图识别番号"的成人影像搜索引擎（**561 转发，全样本第一**），以及一个自述"二次元、福利姬、SE 图、写真…真不适合公众场合打开"的 NSFW 站点合集（197 转发）。
>
> 中国大陆《刑法》第三百六十四条**传播淫秽物品罪**（不以牟利为目的）/ 第三百六十三条（以牟利为目的）。**本频道不托管内容本体（仅 0.42 GB，且是软件），只提供站点入口——这使它处于传播链条的外围**，但"561 次转发"意味着实际的扩散规模不小。**若"🔥合作"的广告收入被认定与这类内容存在关联，则适用牟利条款。**
>
> **2｜为"机场"与自建代理提供推广（次要但明确）。** 19 条机场/代理相关内容，含免费代理站点分享（228 转发）、sing-box/v2ray 一键自建脚本（223 转发，正文自述"最近真的机场不稳定"）、以及一个 Mihomo 代理客户端的开发者自荐。
>
> **需要做一个区分**：**推荐开源客户端与自建脚本，与"为收费机场做有偿广告"不是一回事。** 样本内**未见任何机场品牌名、优惠码或 CPS 落地页**——这一点上它比本轮 [feiyu123](feiyu123.md)（两家机场各投 4 次带优惠码）、[blacktechsharing](blacktechsharing.md) 轻。**但"分享免费代理站"仍触及《计算机信息网络国际联网管理暂行规定》第六条。**
>
> **3｜规避技术措施与薅平台补贴。** 样本内可见"绿色版"软件（`#限免` 11、「破解 13」「绿色版 2」）与"注册即赠送 1 个月，**可以换邮箱撸**"这类表述。**前者触及《著作权法》第五十条，后者是教唆违反服务条款重复领取免费额度——与本轮 [feiyu123](feiyu123.md) 的同类内容性质一致，量级很轻。**
>
> **4｜79.8% 删除率的证据法意义。** 高删除率本身不违法，**但在本案中它与预置序号备用号（`miaoaaaaa/bbbbb/ccccc`）、变形备用域名（`appmiao.com`/`appmiu.com`）构成一套完整的抗查体系。** **在司法评价中，这类安排通常被作为"主观明知违法性"的情节，而非中性的运营习惯。**
>
> **5｜主体内容合规。** 必须同时指出：87 个 GitHub 链接、`#源码` 27 次、`#AI` 27 次、开发者自荐帖——**这个频道的绝大多数内容是合法的开源与工具推荐。** 它的风险来自那少数几条高传播的踩线内容，**而不是它的日常。**
>
> **不适用的两条**：不涉及开设赌场罪（样本内 0 条博彩内容——这一点上它明显好于本轮同量级的 [dianying4K](dianying4K.md)）；不涉及帮助信息网络犯罪活动罪的典型情形（0 个代收款账号、0 条诈骗导流、0 条境外招工）。
