## 二、核心发现一：四盘并行

**外链域名分布：**


**URL 参数：`pwd` 312 个、`password` 78 个** ——**390 个提取码。**

**一条帖子平均挂 2.2 个网盘链接。**

**这与本轮 [shareAliyun](shareAliyun.md) 的单盘策略形成直接对比：**

| | [shareAliyun](shareAliyun.md) | **vip115hot** |
|---|---|---|
| 网盘 | **只用阿里云盘** | **夸克 + 迅雷 + 百度 + 115 + 阿里 + 移动** |
| 链接/帖 | 约 1 | **2.2** |
| 删除率 | **99.0%** | **2.9%** |
| 订阅 | 20.2 万 | 5.2 万 |

**多盘并行是一种冗余设计：任何一家平台删掉分享，帖子里还有另外几个链接活着，不需要删帖。**

**这就是 2.9% 与 99.0% 的差距来源** ——**不是 vip115hot 不清理，是它不需要清理。**

**代价是运营成本：同一部片子要转存到四个不同的网盘账号，各自生成分享链接与提取码（§六）。**

**标签体系是按画质与类型双轴组织的：**

```

#喜剧 38 | #动画 33 | #经典 33 | #动作 31 | #悬疑 29 | #科幻 28
```

**`#4K` 77 + `#高码率` 61 + `#1080p` 60 = 198 次画质标注** ——**画质是这个号的核心卖点。**

**样本内可见的规格描述精细到发烧级**：「4K.REMUX UHD 原盘」「HDR10 & 杜比视界」「内封简繁英双语特效字幕」「1080p 原盘 REMUX」「国粤双语」。

**这些术语指向一个特定受众：用投影仪或大屏、在意码率与色深的人。** **与 [shareAliyun](shareAliyun.md) 的泛用户定位不同。**

## 五、核心发现四：与 dianying4K 的关系——一条单向的引用

**[dianying4K](dianying4K.md) 的报告里留了一个待核问题：它自称「分屋」，且 189 次引用 `vip115hot`，是否与本频道同属一个运营者。**

**现在可以定论：不是。**

**证据是引用的不对称性：**

| 方向 | 次数 |
|---|--:|
| [dianying4K](dianying4K.md)（8.7 万订阅）→ `vip115hot` | **189 次**（占其 300 条样本的 63%） |
| **vip115hot → [dianying4K](dianying4K.md)** | **1 次**（一条普通转发） |

**而 vip115hot 自己的页脚指向的是另一套账号：**

```
t.me 引用：vip115hot 261（自指）| xbso1 240 | 某博彩客服号 56 | jisou 13
@ 提及：  某搜索 bot 259 | 某博彩客服 ×2 各 8
```

**关键在于：vip115hot 的页脚里没有 dianying4K。**

**按本轮已经验证过四次的页脚密度规则**（1 次 = 被动继承自上游、约 4 次 = 刻意投放、200+ 次 = 自有基础设施）：

- **dianying4K 的 189 次（63% 的帖子）属于"刻意且持续的投放"** ——**它在系统性地把流量导向 vip115hot**
- **vip115hot 的 1 次属于"偶发转发"**

**如果两者同属一个运营者，页脚会是双向的、或共用同一套账号。** **实际情况是单向的，而且 vip115hot 有自己独立的一套（`xbso1` 240 次 + 一个搜索 bot 259 次）。**

**结论：dianying4K 是上游导流方，vip115hot 是落地方；两者是合作或买量关系，不是同一个运营者。**

**`xbso1` 被引用 240 次、搜索 bot 被 @ 259 次** ——**这两个才是 vip115hot 自己的基础设施。** **259 个 `?start=` 参数说明搜索 bot 是每条帖子的标配入口。**

## 十、法律风险

> **level: criminal。**
>
> **1｜为境外赌博平台提供广告推广（决定性质的一项）。** 19 条博彩广告（6.3%），分属两个平台，含「返水」16 次、「首充」11 次、「返利」8 次、「抽奖」5 次，两个以品牌缩写命名的客服账号、一个高频引用的客服频道（56 次）、两个落地页域名。
>
> **《刑法》第三百零三条开设赌场罪**；依《关于办理网络赌博犯罪案件适用法律若干问题的意见》，**为赌博网站提供广告宣传等服务的以共犯论处**；另可依**帮信罪**追究。
>
> **本案在情节上有三点加重：**
>
> (1) **广告内容明示了赌博的全部要素** ——「体育｜电竞｜真人娱乐｜小游戏｜棋牌｜电玩｜彩票」「日返水最高 1.1%」「加拿大 PC28 超高赔率」「上押 1000 万 U」，**没有任何需要解读的暗语。**
>
> (2) **曝光量远高于常规插帖** ——推断为置顶位，单条 19,907 阅读，是频道普通帖的 10.8 倍。**在传播效果的认定上，置顶位的情节重于普通广告帖。**
>
> (3) **跨样本的产业链关联**：「加拿大 PC28」与「上押 X 万 U」两个词同时出现在本轮的 [fufeikc](fufeikc.md)（卖 PC28 机器人）、[inside1024](inside1024.md)（投放同类广告）与本案。**同一广告主在多渠道投放，在司法认定中通常合并评价、传播量累加。**
>
> **2｜大规模分发盗版影视（核心的另一半）。** 8.59 条/天、664 个网盘链接、390 个提取码，内容为院线电影、剧集、动画的 4K REMUX 原盘、UHD 蓝光、HDR10 与杜比视界版本。
>
> **《著作权法》第十条第（十二）项；《刑法》第二百一十七条侵犯著作权罪。**
>
> **「以营利为目的」在本案成立** ——**§八 的博彩广告收入即为营利证据。** 这与本轮 [lihaiba](lihaiba.md)（824 天零收入，因此停留在民事行政层面）形成关键分野：**有广告收入的盗版分发，刑事入罪的要件是齐的。**
>
