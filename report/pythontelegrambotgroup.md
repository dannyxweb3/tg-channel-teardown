## 二、核心发现一：同一项目的两个阵地，链接密度差 45 倍

**本语料已收录同一项目的发布频道，两者可以直接对照：**

| | [频道](pythontelegrambotchannel.md) | **群组（本样本）** | 倍数 |
|---|--:|--:|--:|
| 规模 | 17,517 订阅 | 10,002 成员 | 1.75× |
| 频率 | **0.04 条/天** | **9.68 条/天** | **242×** |
| 存活率 | 95.8% | **54.7%** | |
| 外链总数 | **997**（159 条里） | **42**（300 条里） | |
| **链接密度** | **6.3 个/条** | **0.14 个/条** | **45×** |

**这两个数字的差距不是偶然，它来自版面性质的根本区别：**

> **频道是档案：每一条发版公告都要让读者能逐条回溯到具体的代码改动，所以每一个条目都必须挂一个链接。**
> **群组是对话：链接只在有人需要被指向某处时才出现。**

**本语料由此得到一条：**

> **档案型版面与对话型版面的链接密度差两个数量级，即使它们服务同一批人、同一个项目、由同一批人维护。**
> **链接密度不是一个账号的风格，是版面功能的函数。**

**这条结论对本语料此前的链接分析是一次约束：**
本语料在多个样本里把链接密度当作"内容是否外向"的指标（[cool_scripts](cool_scripts.md) 2.81 次/帖、[Meitian](Meitian.md) 零站外链接）。**那些比较全部发生在频道之间，因而是成立的；但频道与群组的链接密度不可直接比较**——**这是本语料在指标可比性上继续到的一条边界**（前一条是 [testflights](testflights.md) 里"频率只在同类目内可比"）。

**存活率的对照同样说明问题：** 频道 95.8%（十一年几乎没删过），群组 54.7%（删了 45%）。**在本语料的存活率四格框架里，群组这一格是"低存活 + 幸存干净"（清理有效）**——**广告粗筛 0/300 印证了这一点：删掉的 45% 里有相当部分是被清理的垃圾。**

## 三、核心发现二：外链构成测出了提问者的水平

**42 个外链里，22 个指向文档与教材。把它们按"指向什么"分开：**

| 指向 | 次数 |
|---|--:|
| **通用 Python 学习资源**（官方 wiki 10 + 官方文档 5 + 一本公开教材 5 + 一个入门站 5） | **25** |
| **本库自己的官方文档** | **12** |

**指向"去学 Python"的链接，是指向"去看本库文档"的链接的两倍多。**

**这是一个关于提问者的推论：**

> **如果群里的问题主要是"这个库怎么用"，老手的回应会是本库文档。**
> **而实测里老手更常给出的是 Python 语言本身的入门资源**——**说明相当一部分问题的根因不在库，在语言。**

**Python 官方 wiki 被引用 10 次尤其说明问题**：那是一个面向初学者的入门索引页，不是 API 参考。**一个老手会把人送去那里，只有在判断对方"还没到能看 API 文档的阶段"时。**

**本语料由此得到一条可推广的方法：**

> **一个技术社群的外链构成可以测量其提问者的水平分布：**
> **指向本项目文档的比例高 → 提问者已经掌握了前置知识，问题在项目层；**
> **指向前置知识（语言、协议、基础概念）的比例高 → 提问者的短板在前置层，项目只是他第一个撞上的具体对象。**

**这对本语料此前的判断补了一层：**
本语料在 [tdlibchat](tdlibchat.md)、[projectv2ray](projectv2ray.md) 等技术群里用过"外链域名反映社群性质"的推法。**这里把它细化为"外链域名的层级反映社群的水位"**——**不只是"这是个什么群"，还包括"这个群里的人在什么水平"。**

**顺带：这解释了为什么这个群的存活率只有 54.7%，而它对应的频道是 95.8%。** **一个持续接待初学者的群，必然持续接待重复问题、走错门的人、和垃圾**——**而清理的代价由版主承担。**

## 四、其余维度

**实现技术思路：无自动化内容生产。** 唯一的 bot 占 10%（30 条），是群管性质（规则与提醒）。**本语料"bot 九种用途"中的"群管"一类。**

**本语料在 [nasfan](nasfan.md) 里修正过的那条**（"bot 占比与技术水平反向"只适用于工具型 bot）**在这里得到又一个正向支持点：一个 Python bot 框架的官方群，bot 占比只有 10%，而且是群管而非服务。** **写 bot 的人自己的群里，bot 最少。**

**发言集中度：90 个发言人，top10 占 45%。** **这是一个分散的群**——**没有单一主导者，讨论由 90 个人共同承担。** 对照本语料的高集中度群（top10 常在 60–90%），这里的 45% 说明**答疑责任是分摊的，而不是压在一两个人身上。**

**成本（月）：¥0。** 无自有站点、无 CDN、无付费工具；**唯一成本是版主的清理与答疑时间**（9.68 条/天 + 45% 的删除率意味着版主每天要处理约 8 条需要判断的消息）。

**收益：¥0。** **广告粗筛 0/300**——**在一个万人技术群里，零命中本身就是强信号：说明清理是持续且有效的。** 零收款账号、零联盟参数、零推广码。

**属"不变现十五种类型"中的"载体不允许变现"一类**（与 [openwrt_flippy](openwrt_flippy.md) 同组）：**这是一个开源项目的官方支持群，变现会立刻与项目的开源定位冲突。**

**未变现的承载力：¥0–500/月。** 上锚极低，**理由是这个群的受众虽然精准（Python 开发者），但群组版面本身几乎不可售**——**本语料在多个群组样本里确认过：广告主为群组出的价远低于同规模频道，因为群里的广告会被淹没，而置顶只有一个位置。**

**增长：完全依赖上游项目。** 频道名与群组名都是项目标识；零关键词占位、零买量、零互推、零邀请奖励。**1 万成员是十一年里由项目用户自然汇集的。**

## 五、法律风险

**风险等级：低。**

- **内容性质。** 全英文技术问答，外链全部指向代码托管、官方文档与公开教材；零商业行为、零收款、零推广。
- **不适用**：不涉及开设赌场罪、传播淫秽物品罪、帮助信息网络犯罪活动罪、非法经营罪、侵犯著作权罪——样本中无任何对应内容。
- **境内连接点弱。** 语言为英文、项目为国际开源社区、受众分布全球；**中国大陆法律的适用性需要具体的境内连接点，而本样本中看不到。**

**责任主体**：开源项目的维护团队（公开、有明确的治理文档）。
