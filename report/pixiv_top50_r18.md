## 一、实现技术思路

### 1.1 全自动，频道名就是产品说明

```
每日抓取 Pixiv 综合 R-18 每日排行榜
   → 取前 50 位作品图像
   → 按 24.8 条/天推送（282/300 条为 photo）
   → 另打包当日全量为 zip 附件
```

zip 命名规整：`[pixiv] 综合R-18每日排行榜 2026年9月11日.zip`，单包 48–96 MB。

### 1.2 编辑内容几乎为零

**259/300 条完全无正文。** 有正文的绝大多数只有一行署名：

```
By：PIXIV每日R18 Top50 搬运
```

### 1.3 一个值得单独记录的细节：它给自己署名，但不给原作者署名

- 39 个 `telegram.me` 链接**全部指向本频道自身**
- 样本内**未见任何指向 Pixiv 原作品页或原作者的链接**

原作者信息在搬运过程中被完全剥离。这直接影响著作权项下的署名权认定，见法律风险 5.2。

### 1.4 托管

全部直传 Telegram，零托管成本。日包 48–96 MB，全年不足 30 GB。

**判读**：阅读分布**极紧**（p10 3,205 / p90 5,138）说明这 3,800 左右的阅读是真实的；但 16 万订阅对应 2.4% 的 ERR，意味着绝大多数订阅者早已不看。

转发 13.2 次/帖证明内容本身有扩散力——**强于 [syrjfx_sl](syrjfx_sl.md)（0.7）和 [bookMiao](bookMiao.md)（0.09）**。

所以它的问题不是「买了死粉」，而是「**靠互推堆了订阅数之后真实活跃没跟上**」。反应仅 159 个也印证：用户来看图就走，不互动。

## 五、法律风险

> 本节为外部法律风险识别，不构成法律意见。

**两条线叠加：成人内容的批量传播，以及对大量在世插画师作品的系统性侵权。后者的权利人数量以千计。**

### 5.1 传播淫秽物品 —— 🔴 critical

《刑法》第三百六十三条、第三百六十四条；《关于办理利用互联网……传播淫秽电子信息刑事案件具体应用法律若干问题的解释》。

R-18 定级的成人向插画在中国法下属淫秽物品范畴。司法解释设有数量与点击量入罪标准——**日更 24.8 条、160,753 订阅、单条中位 3,828 次阅读，两项标准均被大幅超出**。

因挂有带推广码的机场广告，属「牟利」情形，适用第三百六十三条。

### 5.2 系统性侵犯插画师著作权（权利人以千计）—— 🔴 critical

《著作权法》第十条（复制权、信息网络传播权、**署名权**）、第五十三条；《刑法》第二百一十七条；《伯尔尼公约》。

每日搬运排行榜前 50，意味着**每天未经授权复制并传播约 50 位不同作者的作品，一年涉及的权利人以千计**。

且样本内未见任何指向原作品页或原作者的链接——**原作者信息被完全剥离，同时侵犯署名权**。

Pixiv 用户条款明确禁止未经授权的转载与再分发，而多数 R-18 作者对转载的态度更为严格。

### 5.3 打包 zip 加重传播情节 —— 严重

除逐条推送外，另打包当日全量为 zip 供整包下载。这使**单次传播行为覆盖的作品数量从 1 件变为 50 件**，在复制品数量的认定上是显著的加重因素，也便利了下游的二次分发。

### 5.4 违反平台条款与绕过访问限制 —— 中等

Pixiv 利用規約；《反不正当竞争法》第十二条；《著作权法》第四十九条（规避技术措施）。

Pixiv 对 R-18 内容设有年龄门与登录限制，对批量抓取设有频率与地区限制。系统性绕过这些限制进行日更规模的抓取，既违反平台条款，也可能触及规避技术措施的规定。

### 5.5 未成年人准入无任何限制 —— 严重

《未成年人保护法》第八十条；《网络安全法》第十三条。

频道对未成年人没有任何准入门槛，**简介为空、无任何年龄提示**。

Pixiv 原站至少设有年龄门，**搬运后这道门被完全移除**——这是搬运行为独立造成的额外危害，不能以「原站也有」抗辩。

### 5.6 为无证跨境代理服务导流 —— 中等

《刑法》第二百八十七条之二。挂带推广码的机场注册链接，与 [ffqchannel](ffqchannel.md)、[jcplnanmin](jcplnanmin.md) 同类风险，但规模较小（样本内仅 2 条）。
