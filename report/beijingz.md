# beijingz · 北京

> ⚠️ 本报告不复现群内出现的个人账号、联系方式与交易信息。
>
> **群 · 30,452 成员 · 可见消息 300 条 · 发言人 162 · bot 消息 1% · 1.2 条/天（可见）**
> 数据来源：`scripts/tg_recon.py dump beijingz --limit 300` → [data/recon/beijingz.jsonl](../data/recon/beijingz.jsonl)
> 抓取时间 2026-09-19（含发言人字段的重抓） · 样本 300 条（2026-01-13 → 2026-09-19，跨度 248 天）

**一句话结论：248 天里消息 id 前进了 300,149 个，只有 300 条还在。存活率 0.10%——本批十个群里最低。也就是说这个群平均每天产生约 1,210 条消息，其中只有 1.2 条活到今天。而幸存下来的那 300 条是完全正常的城市闲聊（「朝阳公园附近有没有搭子」「北京比深圳贵多了呀」「今儿咋了这是，外卖点不了」），来自 162 个不同的人，bot 只占 1%，正文中位 7 个字。一个 3 万人的城市群，真实社交流量被淹没在每天上千条看不见的东西里。**

## 二、核心发现一：存活率是群分析的新指标

本批重抓的十个群，用同一个脚本、同一个账号、同一个 `--limit 300`，得到的 id 跨度与可见条数差别极大。**把"可见条数 / id 跨度"定义为存活率，十个群排出一条清晰的谱系：**

| 群 | 成员 | id/天 | 可见/天 | **存活率** |
|---|--:|--:|--:|--:|
| [PublicTestGroup](PublicTestGroup.md) | 26,759 | 350 | 300 | **85.71%** |
| [v2rayN](v2rayN.md) | 25,234 | 243 | 100 | 41.10% |
| [BotTalk](BotTalk.md) | 26,499 | 249 | 100 | 40.21% |
| [M_Team_Chat](M_Team_Chat.md) | 31,150 | 1,133 | 300 | 26.48% |
| [giantcutie6688](giantcutie6688.md) | 26,531 | 191 | 10.7 | 5.61% |
| [jinan_tg](jinan_tg.md) | 26,357 | 2,169 | 60 | 2.77% |
| [GIFgroupTW](GIFgroupTW.md) | 25,735 | 222 | 5.0 | 2.26% |
| [nexitallyusers](nexitallyusers.md) | 24,947 | 9 | 0.1 | 0.68% |
| **beijingz** | **30,452** | **1,210** | **1.2** | **0.10%** |
| [gouwu](gouwu.md) | 26,565 | 976 | 0.1 | **0.02%** |

**存活率与成员数无关（十个群都在 2.5 万–3.1 万），与语言无关，与 bot 占比也无关。** 它测的是另一件事。

**两个候选解释，数据能部分区分：**

1. **管理员/反垃圾 bot 批量删除。** 若成立，幸存消息里应当几乎没有广告——**beijingz 符合（7 条粗筛命中，且都是日常用语）。**
2. **发言账号被 Telegram 全局封禁后，其历史消息一并消失。** 城市名群是垃圾账号的重灾区，这类账号大批量注册、大批量被封。

**本案两种可能同时成立，且互相强化。** 但有一条证据偏向第二种：**bot 消息只占 1%。** 如果是靠反垃圾 bot 大规模清理，通常会看到 bot 的操作痕迹（提示消息、警告）；这里几乎没有。**更像是"账号没了，消息跟着没了"。**

**实务结论：对群做竞品分析时，`--limit 300` 取到的不是"最近 300 条聊天"，而是"最近 300 条还活着的聊天"。** 两者在高存活率的群里等价，在低存活率的群里差了三个数量级。**id 跨度必须与可见条数一起报，只报其中一个会得出完全错误的活跃度判断。**

## 三、核心发现二：幸存的部分是一个正常的城市群

**162 个发言人、top10 只占 30%**——这是本批十个群里发言最分散的一个（对照 [PublicTestGroup](PublicTestGroup.md) 的 37 人 / top10 占 81%、[nexitallyusers](nexitallyusers.md) 的 24 人 / top10 占 84%）。

**内容是典型的城市生活话题**：本地物价与深圳的对比、外卖平台故障、公园找搭子、出差问路、某区域因活动交通管制。**正文中位 7 个字**，最长 127 字——**全是短句口语，没有一条超过两行。**

**链接几乎为零（300 条里 1 条）**，那一条指向本语料 [tgzhcn](tgzhcn.md) 报告里那个中文化项目的频道——**即一个新人被告知"先去装中文包"。** 这条链接本身是那个矩阵渗透度的一个侧证。

**反应 66/300、评论 44 条**——有互动但很轻。**这不是一个热闹的群，是一个稀疏但真实的群。**

## 四、核心发现三：1,210 条/天的那部分是什么

**本报告看不到它们，只能从三条间接证据推断：**

1. **幸存消息里的 `@` 提及包含多个随机串形式的用户名**（无意义字母组合），**这是批量注册账号的典型命名。**
2. **幸存消息里有若干带暗示性的短句**（提到"小姐姐"及其去向），**在城市名群的语境下，这类用语通常是招嫖内容被删除后残留的对话上下文**——即有人在回应已经不存在的消息。
3. **1,210 条/天 vs 30,452 成员 = 每人每 25 天发一条**，这个密度对一个城市闲聊群是正常的；**但配上 0.10% 的存活率，说明绝大多数发言在很短时间内就消失了。**

**本报告的判断：这是一个被垃圾/招嫖内容长期淹没的城市名群，真实社交流量只占千分之一。** 置信度为中——**推断链条完整，但缺少直接证据，因为那些内容已经不在了。**

**这个结论对整份报告的其余部分有决定性影响**：下面的成本、收益、增长三节，都必须区分"可见的群"和"实际的群"。

## 五、实现技术思路

**群配置**：公开群、历史对非成员开放（与 [tgzhcn](tgzhcn.md) 相反）、允许发言、反应开、评论（回复）开。

**管理**：3 条 bot 消息、无可见的管理公告、无置顶提示、无入群验证痕迹。**这是一个几乎不管理的群**——而 0.10% 的存活率说明**要么管理发生在看不见的地方（批量删除），要么根本没管理（靠平台封号）。**

**没有任何运营设计**：无标签体系、无规则说明、无矩阵（唯一的外链指向一个第三方项目）、无 bot 服务、无置顶。

**它和本批其他群的形态差别很大：**

| 群 | 有无运营 | 证据 |
|---|---|---|
| [v2rayN](v2rayN.md) | **有** | 自有 bot 回复关键词、置顶规则、推广合作邮箱 |
| [M_Team_Chat](M_Team_Chat.md) | **有** | 官方 bot 播报站内数据（49 条） |
| [jinan_tg](jinan_tg.md) | **有** | 两个管理 bot、`#提问` 标签体系 |
| **beijingz** | **无** | 无 bot、无置顶、无标签 |

**"北京"这个群名本身就是它的全部运营。** 它不需要做任何事就能持续获得新成员——**这既是它 3 万成员的原因，也是它被垃圾内容淹没的原因。**

## 六、成本

**经常性（月）：¥0–300。**

| 项目 | 金额 | 依据 |
|---|--:|---|
| 服务器 / bot / 域名 | **¥0** | 一样都没有 |
| 管理人力 | **¥0–300** | 见下 |

**管理时间投入是这份报告里最不确定的一项，而它不确定的原因很特别：本报告看不到管理动作本身。**

- **如果 0.10% 的存活率来自人工或 bot 删除**，那么每天要处理约 1,200 条，**即便有工具辅助也需要每天 0.5–2 小时，月投入 15–60 小时。**
- **如果来自 Telegram 的全局封号**，管理成本为 **0**——平台替你清理了。

**本报告倾向后者**（依据是第二节：bot 消息只占 1%，没有清理痕迹），**所以成本估为接近 0。** 但这一判断的置信度是中，**如果错了，成本会差两个数量级。**

**这是一个值得记下来的方法论问题：当一个群的治理主要由平台完成时，运营者的成本可以真的是零，而外部观察者无法区分"没人管"和"管得很好"。**

## 七、收益

**¥0，且不存在变现痕迹。**

248 天、300 条可见消息里：**0 条广告、0 个联盟参数、0 个收款账号、0 个 bot 深链、0 个商业域名、0 次置顶推广。** 唯一的外链指向一个非商业的中文化项目。

**但这个结论只对"可见的 300 条"成立。** 那 299,849 条看不见的消息里是否存在变现（卖群、置顶广告、招嫖抽成），**本报告无法判断。** 这是与 [tgzhcn](tgzhcn.md) 完全相同的盲区，成因不同（那个是配置隐藏，这个是内容消失），**但结论一样：不可观测不等于没有。**

**未变现的潜在价值：** 一个 3 万成员的一线城市名群，在中文 TG 的群交易市场里是有明确价格的——**这类群的转让报价通常在 ¥3,000–20,000**，取决于活跃度与是否被平台标记。**若按置顶广告出租计，月租金在 ¥500–3,000。**

**区间宽的两条原因：**

1. **真实活跃度不可验证。** 买家会看在线人数和实际聊天量，**而这个群的可见聊天只有 1.2 条/天。**
2. **被垃圾内容淹没的群会被压价。** 一个需要买家自己从头清理的群，价值显著低于一个干净的群。

**倾向判断：靠近下沿。** 依据是第 2 条——**0.10% 的存活率是买家一眼就能看出来的问题。**

## 八、增长策略

| 机制 | 证据 | 判读 |
|---|---|---|
| **群名即关键词** | 群名是一个一线城市名 | **唯一且充分的机制** |
| 搜索可发现 | 公开群 | |
| 历史开放 | 与 [tgzhcn](tgzhcn.md) 相反 | 新人能看到内容 |
| 互推 | **0** | |
| 运营 | **0** | 无 bot、无置顶、无规则 |
| 买粉 | **无从判断** | 群成员数无法用 ERR 类指标验证 |

**"占住一个通用名词"是这个群的全部策略，而且它有效——3 万成员，零运营投入。**

**本语料此前在 [tgzhcn](tgzhcn.md) 记过"占住必经之路"（新用户必然遇到汉化问题），**这里是它的变体："占住一个所有人都会搜的词"。** 两者的共同点是**流量来自搜索而非推荐**，因此不需要任何主动获客。

**代价也一样：占住通用词的群，控制不了来的是谁。** [tgzhcn](tgzhcn.md) 的应对是隐藏历史、把治理压力挡在门外；**beijingz 什么都没做，于是每天承受 1,200 条垃圾。**

**这两个群构成本语料关于"通用名群组"的一组完整对照：同样的获客逻辑，两种治理选择，两种结果。**

## 九、法律风险

**风险等级：中。** 可见内容本身完全无害，风险全部集中在不可见的部分与管理者责任。

- **群主/管理员对群内违法信息的管理义务（主要风险）。** 中国法下，《网络安全法》第 47 条要求网络运营者发现违法信息应停止传输、采取消除措施；《互联网群组信息服务管理规定》第 9 条明确**"谁建群谁负责、谁管理谁负责"**，要求群主对群组内信息发布行为进行管理。**本群每天约 1,210 条消息、只有 1.2 条存活，而管理动作在样本中不可见。** 若这些消息中包含招嫖、诈骗或其他违法信息，**群主是否尽到管理义务是责任认定的核心**；而"平台自动删除"不等于"群主履行了义务"。
- **招嫖信息的传播（推断，非直接证据）。** 第四节论证了存在此类内容的间接迹象（随机串账号名、残留的对话上下文）。若成立：发布者可能触及《刑法》第 359 条介绍卖淫罪或《治安管理处罚法》第 67 条；**群主若明知而放任，可构成共犯或行政责任。** **本报告未取得任何具体的招嫖内容、账号或报价，因此这一条的置信度为中，不作为确定结论。**
- **无经营行为。** 可见样本中零广告、零收款、零导流，**不涉及非法经营罪、不涉及帮助信息网络犯罪活动罪**（帮信罪需要"提供互联网接入、服务器托管、网络存储、通讯传输等技术支持或者广告推广、支付结算等帮助"，单纯提供一个聊天群且无收益不构成）。
- **境内连接点明确。** 群名、语言、内容全部指向中国境内的一座城市，**成员大概率以境内用户为主**，中国法在本案有实际的管辖意义——这与本语料的 [BotTalk](BotTalk.md)、[PublicTestGroup](PublicTestGroup.md) 等英文群处境不同。
- **不适用**：不涉及开设赌场罪（可见内容 0 条博彩、0 个博彩域名、0 个客服账号）；不涉及侵犯著作权罪（无内容分发）；不涉及传播淫秽物品罪（可见内容 0 条成人内容，且"招嫖"与"传播淫秽物品"是两个不同的罪名，前者针对交易撮合、后者针对物品传播，本案可见部分两者皆无）；不涉及侵犯公民个人信息罪（无信息收集或交易的可见证据）。

**责任主体**：群主与管理员。**样本中未暴露任何管理员身份**——没有置顶、没有公告、没有管理 bot、没有任何一条以管理者口吻发出的消息。**这在本批十个群里是唯一的：其余九个群都能从 bot 或置顶里看出谁在管。** 一个 3 万人的群没有任何可见的管理者，本身就是第一节那个 0.10% 存活率最合理的注脚。
