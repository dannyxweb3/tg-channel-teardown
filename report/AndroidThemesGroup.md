## 二、核心发现一：一个不离开平台的经济体

**530 个 `t.me` 链接 vs 4 次站外域名。比例是 132:1。**

**`t.me` 的用途分布：**

| 形式 | 次数 | 作用 |
|---|--:|---|
| `t.me/addtheme/<hash>` | **279** | **一键安装主题（Telegram 原生深链）** |
| `t.me/bg/<hash>` | 63 | 一键应用背景图 |
| 各主题频道用户名 | 73 | 互推 |
| `t.me/boost/<name>` | **25** | **请求会员助力** |
| 自指 / 其他 | 90 | |

**`addtheme` 与 `bg` 是 Telegram 内置的深链协议**——**点开直接在客户端里装上，不下载文件、不访问网站、不经过任何第三方。**

**本语料至此，"零/极少外链"的成因增至七种：**

| 成因 | 样本 |
|---|---|
| 设计如此 | [jin10light](jin10light.md) |
| 载体不含文字 | [GIFgroupTW](GIFgroupTW.md) |
| 被删光了 | [jinan_tg](jinan_tg.md) |
| 内容就是文件 | [ruheyushadiaoxiangchu](ruheyushadiaoxiangchu.md) |
| 对话不需要链接 | [loveapps](loveapps.md)、[pythonzh](pythonzh.md) |
| 内容是观点 | [V2EXPro](V2EXPro.md) |
| **商品是平台原生对象** | **AndroidThemesGroup** |

**第七种与前六种性质不同：前六种是"没有链接可贴"，这一种是"链接不需要指向站外"。**

**这个差别有实质后果。** 本语料反复出现的一条结构性规律是：

> **要做流量生意就得有域名（[hacker_news_feed](hacker_news_feed.md)）/ 做工具就必须有服务器（[Hao12News](Hao12News.md)）/ 要收钱就必须实名（[TimeHorizonX](TimeHorizonX.md)）。**

**这个样本是那条规律的边界案例：它做的是分发生意，却不需要域名，因为它的商品是平台自己的一种数据格式。**

**代价同样明确：它对平台的依赖是百分之百的。** **Telegram 一旦调整 `addtheme` 协议或封禁某个主题频道，整条链路当场失效，而运营者手上没有任何可迁移的资产**——**没有域名、没有站、没有邮件列表、没有文件备份（群里只有 1 个文件，5.2 MB 的 mp4）。**

**与 [voice_google](voice_google.md)（99.1% 的删除率，库存清理）、[Licensesss](Licensesss.md)（有限席位）比，这是本语料平台依赖度最高的一个商业形态。**

## 三、核心发现二：颜色标签

**八个高频标签里，六个是颜色：`#dark` 98、`#black` 53、`#light` 32、`#blue` 29、`#brown` 25、`#pink` 22。**

**另外两个是 `#darktheme` 32（类别）与 `#Android` 25（平台）。**

**本语料的"标签七用"**（[limboprossr](limboprossr.md) 第三节确立）**在这里出现第八种：属性检索。**

| 用途 | 样本 | 性质 |
|---|---|---|
| 分类 | 多数样本 | 内容归属 |
| 品牌 | `#爷青回` 180 次 | 身份 |
| 栏目 | [jike_collection](jike_collection.md) | 固定版面 |
| 纠错 | `#勘误` | 事后修正 |
| 自评 | `#NSFW` | 风险提示 |
| 自嘲式偏题 | [misakatech](misakatech.md)、[pythonzh](pythonzh.md) `#ot` | 社交润滑 |
| 运营通报 | [limboprossr](limboprossr.md) | 公告 |
| **属性检索** | **AndroidThemesGroup** | **按外观筛选** |

**前七种回答的是"这条内容是什么"，第八种回答的是"我想要什么样的"。**

**这个差别来自商品形态：主题是一个视觉产品，用户的需求是"我要一个暗色的/粉色的"，而不是"我要一个 2026 年 9 月发布的"。**

**颜色标签把一个 300 条的消息流变成了一个可按外观查询的目录。** **这在 Telegram 里是唯一可行的做法**——**平台没有筛选器，标签是仅有的检索入口。**

**`#dark` 98 次 vs `#light` 32 次，3:1**。**暗色主题的供给是亮色的三倍**，这与移动端主题市场的普遍偏好一致。

## 四、核心发现三：内容是转进来的

**转自字段显示五个来源频道：** 某主题频道 23 次、某动漫频道 20 次、另三个各 19 / 15 / 14 次。

**本样本中数据最好的两条都是转发帖：**

| 阅读 | 转发 | 内容 |
|--:|--:|---|
| 84,293 | 464 | 一条纯 `addtheme` 深链 + 分隔线 |
| 72,638 | 667 | 装饰性排版 + 「APPLY THEME / WALLPAPER / JOIN CHANNEL」 |

**8.4 万阅读、667 转发**——**这是本语料群类样本里见过的最高单帖数据，而它不属于这个群。**

**这说明这个群在链路上的位置是"汇集点"而不是"产出点"：** 主题由各个专门频道制作，**这个群把它们聚在一起。**

**36 个发言人、top10 占 65%、bot 0 条**——**没有自动化，是人在手工转。**

**第二条帖子的正文结构值得注意：**

```
➿➿➿🎀➿➿➿
⬇️ APPLY THEME ✌️
📁 WALLPAPER 💙
👥 JOIN CHANNEL 🐰
Theme Link 🔗✅
```

**三行功能链接 + 一行引流（JOIN CHANNEL），用花体字与 emoji 分隔线包装。**

**这是本语料的"页脚引流"在非中文语境下的形态**：与 [thinkpositivewords](thinkpositivewords.md)、[BaccanoSoul](BaccanoSoul.md) 的"转发帖保留原页脚"是同一机制——**原频道的引流行在转发后仍然生效，转的人替原频道做了推广。**

**本语料"矩阵识别五法"的第三法（转发帖保留原页脚）在这里第四次得到印证。**

## 五、核心发现四：伊朗

**四个站外域名里，两个是伊朗站点（一个图片服务、一个下载站）。**

**发言人名单里出现波斯语命名习惯的账号，转发来源里也有波斯语频道名。**

**这与本语料已有的地域样本形成对照：**

| 地域 | 样本 | 特征 |
|---|---|---|
| 中国大陆 | 多数样本 | 代理、合租、线报 |
| 俄罗斯 | [creativemotion](creativemotion.md) | **法定 `erid` 广告标识** |
| **伊朗** | **AndroidThemesGroup** | **主题美化、本地图床** |

**三个地区的共同点是：本地互联网服务受限，Telegram 成为基础设施。**

**但变现形态完全不同。** [creativemotion](creativemotion.md) 因为俄罗斯法律要求而给每条广告加合规标识；**这个群零广告、零收款、零联盟参数**——**而它的成员数（2 万）与传播数据（单帖 8 万阅读）并不小。**

**25 个 `t.me/boost/` 链接给出了唯一的"收益"线索：**

**Boost 是 Telegram 的会员助力机制**——**成员用自己的 Premium 订阅给频道投票，换取频道解锁更多功能（自定义表情、更多故事位等）。**

**这是一种非货币的收益形式：用户支付给 Telegram，频道获得权益。** **本语料第一次见到把它作为主要"变现"路径的样本。**

## 六、实现技术思路

**零基础设施：0 个 bot、0 个自有域名、0 个服务器、1 个文件（5.2 MB mp4）。**

**全部技术实现由平台提供：**

| 功能 | 谁实现 |
|---|---|
| 主题打包与安装 | **Telegram（`addtheme` 深链）** |
| 背景图应用 | **Telegram（`bg` 深链）** |
| 检索 | **Telegram（标签）** |
| 分发 | **Telegram（转发）** |
| 激励 | **Telegram（Boost）** |

**运营者只做三件事：转发、打标签、排版。**

**这是本语料"基础设施最少"的记录保持者**——**比 [V2EXPro](V2EXPro.md)（2 个文件、2 个域名）还少一个维度：那个群至少产出原创内容（观点），这个群连内容都是转的。**

**经常性（月）：¥0。**

|---|--:|

## 十、法律风险

**风险等级：低。**

- **主题文件本身不构成侵权。** Telegram 主题是配色与字体设置的集合，**不包含第三方美术作品**，`addtheme` 深链只携带一个 hash。
- **背景图（`bg` 深链 63 次）有边界问题。** 背景图是图片作品，**若使用了受著作权保护的图像（样本中有动漫主题的转发来源），则涉及《著作权法》第 53 条信息网络传播权。** **但样本中未见任何一张图片的来源标注，无法判断权属；且这是非商业的个人分享，规模远低于 [magazinesclubnew](magazinesclubnew.md)、[shareAliyun](shareAliyun.md) 那类系统性分发。**
- **商标与角色形象。** 转发来源中有动漫相关频道，**主题的命名与配图可能使用了受保护的角色形象。** **实践中此类美化资源社群极少被追究，权利人通常直接向平台投诉下架。**
- **零商业行为。** 无收款、无广告、无推广分成——**这切断了绝大多数刑事路径的"营利目的"要件。**
- **群主的管理义务：履行情况可接受。** 存活率 63.2%、0 条粗筛命中、零 bot——**这是内容本身无争议的结果，不是治理的结果。**
- **境内连接点：弱。** 内容为英语、成员构成以波斯语区为主、**未见中文内容与中国大陆指向**。**中国法的管辖意义有限。**
- **不适用**：不涉及开设赌场罪（0 条博彩内容、0 个博彩域名）；不涉及传播淫秽物品罪（245 张图片均为手机界面截图与壁纸，0 条成人内容）；不涉及帮助信息网络犯罪活动罪（零收款、零支付通道、零推广分成）；不涉及非法经营罪（零收入）；不涉及侵犯公民个人信息罪（零 bot、零数据收集）；不涉及提供翻墙服务（内容与代理无关）。

**责任主体**：群主与管理员，**身份不可见**（无管理发言、无自有 bot、无置顶可见）。**暴露面：零域名、零收款、零服务器**——**它唯一的资产是一个 Telegram 用户名，而这个资产完全握在平台手里。**
