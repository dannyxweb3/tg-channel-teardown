## 二、核心发现一：2,169 ids/天，2.77% 存活

**本批十个群的 id 吞吐排序：**

| 群 | id/天 | 可见/天 | 存活率 |
|---|--:|--:|--:|
| **jinan_tg** | **2,169** | 60 | **2.77%** |
| [beijingz](beijingz.md) | 1,210 | 1.2 | 0.10% |

| [gouwu](gouwu.md) | 976 | 0.1 | 0.02% |
| [PublicTestGroup](PublicTestGroup.md) | 350 | 300 | 85.71% |

**jinan_tg 的 id 吞吐比 [beijingz](beijingz.md) 高 79%，而存活率高 28 倍。** 两个都是中国城市名群、都是简体中文、成员数相近（2.6 万 vs 3.0 万）——**差别在治理。**

**jinan_tg 有 4 个 bot（占发言 10%），[beijingz](beijingz.md) 只有 1%、且无可辨识的管理动作。** 本报告的判断：**4 个管理 bot 把一部分垃圾在发出后立刻删掉，使幸存比例从千分之一提到百分之三。**

**但 2.77% 仍然意味着每天有 2,100 条消息消失。** 治理的效果是相对的——**它没有把垃圾挡在门外，只是删得比 [beijingz](beijingz.md) 勤快。**

| [GIFgroupTW](GIFgroupTW.md) | 0 | 80% 是纯图 |

| [BotTalk](BotTalk.md) | 50 | 技术问答 |

**[GIFgroupTW](GIFgroupTW.md) 的 0 是因为没有文字；jinan_tg 的 3 是因为文字全是指令与暗语。**

样本里出现的典型发言：

| 词 | 性质 |
|---|---|
| **「导航」** | **bot 关键词**，触发一个群内导航菜单 |
| **「钢镚」「钢蹦」** | **bot 关键词**（同音异写，两种都有人发，说明关键词表做了同音兼容或用户在试） |
| 「泄火」 | 交易暗语 |
| 「这群啥情况」「光人机发言」 | **成员自己的观察** |

**「光人机发言」这四个字是这份报告里最有价值的一条人类证言**——**一个群成员在群里公开说"只有机器人在说话"。** 而数据同意他：**10% 的发言来自 bot，而人类发言的中位长度是 3 个字。**

**"钢镚 / 钢蹦"同时出现是一个细节。** 两种写法是同音异形，**而两种都有人发**。这说明要么 bot 的关键词表做了同音兼容，要么**用户不确定正确写法所以两个都试**——后者更可能，因为同一条会话里出现了不同用户分别发这两种写法。**这与 [v2rayN](v2rayN.md) 的「文挡」错别字是同一类现象：群的交互入口是一张人工维护的关键词表，而用户必须猜对它。**

## 四、核心发现三：4 个 bot，一个零外链的群

**30 条 bot 消息来自 4 个 bot：**

| bot | 条数 | 推断功能 |
|---|--:|---|
| 某助手 bot | 16 | 关键词响应（导航等） |
| 某群管 bot | 11 | 群管理 |
| 某多功能 bot | 1 | |
| 某封禁 bot | 1 | 自动封禁 |

**4 个 bot 是本批十群里最多的**（[M_Team_Chat](M_Team_Chat.md) 3 个、[GIFgroupTW](GIFgroupTW.md) 2 个、[v2rayN](v2rayN.md) 1 个）。

**而全群 300 条消息里的域名统计只有 `t.me` 23 次，站外链接为零。**

**零站外链接 + 4 个 bot + 2.77% 存活率，这三个数字合起来说明一件事：所有带外链的消息都被删掉了。** 一个 2.6 万人的城市群在五天里不可能没有人发过任何链接——**它们不在了。**

**23 条 `t.me` 引用是仅存的导流痕迹**，指向群内导航菜单里的其他群/频道。**这是本语料"零外链"的第三种成因：**

| 成因 | 样本 | 机制 |
|---|---|---|
| 设计如此（内容自足） | [jin10light](jin10light.md) | 快讯不需要链接 |
| 载体不含文字 | [GIFgroupTW](GIFgroupTW.md) | 图里看不到链接 |
| **被删光了** | **jinan_tg** | **带链接的消息活不下来** |

**第三种最容易被误读为"这个群很干净"。** 实际恰恰相反——**它说明有大量需要被删的东西。**

**标签体系（`#济南` 11、`#提问` 10）表明群主做过内容组织的尝试**，`#群友投稿` 说明有过 UGC 机制。**但在 2.77% 的存活率下，这些标签只在幸存的 60 条/天里偶尔出现。**

## 五、实现技术思路

**群配置**：公开群、历史开放、4 个 bot、有标签体系、有导航菜单。

**这是本批十群里配置最完备的一个**——对照 [beijingz](beijingz.md)（什么都没有）、[gouwu](gouwu.md)（1 个反诈 bot），**jinan_tg 的群主确实在管。**

**自动化程度：治理完全自动，内容完全人工。** 与 [GIFgroupTW](GIFgroupTW.md) 相同的结构，但工具更多。

**「导航」是核心设计。** 一个城市总群通常需要分流到细分群（租房、二手、招聘、吃喝），**而"发一个词唤出菜单"是成本最低的分流方式**——不需要置顶（会被忽略）、不需要人工回答。

**这与 [v2rayN](v2rayN.md) 的关键词 bot 是同一种做法**，区别是：v2rayN 用它回答技术问题（降低答疑成本），**jinan_tg 用它做流量分发（把人送到子群）。**

## 六、成本

**经常性（月）：¥100–800。**

| 项目 | 金额 | 依据 |
|---|--:|---|
| 4 个 bot | ¥0–200 | 多为第三方现成 bot；若有自建的导航 bot 则需要一台最小 VPS |
| **管理人力** | **¥100–600** | 见下 |
| 服务器 / 域名 | ¥0–100 | |

**管理时间投入：每月 5–20 小时。** 虽然 4 个 bot 承担了大部分清理，**但每天 2,100 条消息被删这个量级意味着规则需要持续调整**——新的垃圾话术出现、bot 误删正常发言、用户投诉，都需要人处理。

**这比 [beijingz](beijingz.md)（¥0–300，倾向 0）高，但比一个纯人工管理的群低得多。** 第二节已论证：**同样是城市名群，多花这点钱换来存活率从 0.10% 提到 2.77%。**

**值得指出的是投入产出比并不好。** 28 倍的存活率提升，**换来的仍然是一个"光人机发言"的群。** 治理解决了"垃圾可见"的问题，**没有解决"没有真实对话"的问题**——而后者才是一个城市群的价值所在。

## 七、收益

**可观测：¥0。**

**300 条可见消息里零广告、零联盟参数、零收款账号、零站外商业链接。**

**但与 [beijingz](beijingz.md) 同样的限制：2.77% 的存活率意味着 97% 的内容不可见。** 一个每天删 2,100 条消息的群，**它的商业行为（如果有）很可能就在被删的部分里，或者根本不发在群里（在导航菜单指向的子群里）。**

**23 条 `t.me` 引用是唯一的线索**——**如果导航菜单指向的某些子群是收费的、或者是广告主买下的位置，这条链路本报告看不到。**

**未变现的潜在价值：** 2.6 万成员的省会城市总群 + 一套可分流到子群的导航系统，**这在中文 TG 的本地生活类群里是有价格的。** 置顶或导航菜单位的月租参考 **¥500–3,000**；**若导航菜单里有多个位置，收入按位置数叠加。**

**区间宽的两条原因：**

1. **菜单内容不可观测**（与 [v2rayN](v2rayN.md) 的置顶问题相同）——**本报告看不到导航里有几个位置、哪些是自家的、哪些是租出去的。**
2. **本地生活类群的广告主分散**（本地商户、租房中介、招聘），**客单价低但数量多，总量难估。**

**这是本语料第二次遇到"商业信息在抓不到的地方"**（第一次是 [v2rayN](v2rayN.md) 的置顶）。**对群做分析时，bot 菜单与置顶是两个系统性的盲区。**

## 九、法律风险

**风险等级：高。** 比 [beijingz](beijingz.md) 高一档，原因不是内容更糟，而是**群主的管理动作证明了他知情。**

- **群主的管理义务与知情程度（核心）。** 4 个 bot、每天删除约 2,100 条消息——**这是一套主动的、持续的治理动作，它同时证明群主明知群内存在大量需要删除的内容。** 依《互联网群组信息服务管理规定》第 9 条与《网络安全法》第 47 条，**主动管理是履行义务的正面证据；但"知道有大量违法信息而仍维持该群运行"在情节认定上是一把双刃剑。** 对照 [beijingz](beijingz.md)（无任何管理痕迹，群主尚可主张不知情）、[gouwu](gouwu.md)（幸存内容里挂着黑产广告，证明没清理）——**jinan_tg 处在"知道且在处理但处理不完"的中间状态，这在实务中通常被认定为已尽合理注意义务，但前提是能证明删除记录。**
- **交易暗语的指向。** 样本中出现的某个双字暗语在中文城市群语境下通常指向色情服务的撮合。**本报告未取得任何具体的账号、报价或交易证据，仅记录该词出现。** 若群内确实存在此类撮合，发布者可能触及《刑法》第 359 条介绍卖淫罪或《治安管理处罚法》第 67 条。**这一条的置信度为中**——与 [beijingz](beijingz.md) 的同类推断一样，**证据是残留的词而非完整的内容。**
- **境内连接点明确。** 群名是中国某省会城市名，标签含 `#济南`、`#山东`，语言为简体中文，**成员以境内用户为主的可能性极高。** 中国法在本案有实际管辖意义。
- **导航 bot 指向的子群不可观测。** 若导航菜单指向的子群中存在违法内容，**作为分流入口的本群可能被一并评价。** 这是本报告最大的盲区。
- **零站外链接不能作为"干净"的证据。** 第四节已论证：零外链的成因是"带链接的消息活不下来"，**而不是没人发过链接。**
- **不适用**：不涉及开设赌场罪（可见内容 0 条博彩、0 个博彩域名、0 个客服账号）；不涉及侵犯著作权罪（无内容分发）；不涉及帮助信息网络犯罪活动罪（可见内容 0 个收款账号、0 个联盟参数、0 条商业导流）；不涉及非法经营罪（可见部分零收入）；不涉及传播淫秽物品罪（可见内容 0 条成人内容——**"介绍卖淫"与"传播淫秽物品"是两个不同罪名，前者针对交易撮合、后者针对物品传播，本案可见部分只涉及前者的争点**）。

**责任主体**：群主与管理员。**与本批其他中文群不同，这个群的管理者是"可见"的**——4 个 bot 的配置、标签体系、导航菜单都是主动运营的证据。**虽然样本中没有出现任何管理员账号的直接发言，但运营痕迹本身就是身份的一部分。** 对照 [beijingz](beijingz.md)（完全不可见）——**管得越多，留下的痕迹越多。**
