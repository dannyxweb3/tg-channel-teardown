## 一、实现技术思路

### 1.1 结构：文件倾倒 + 结构化卡片

271/300 条是 document（电子书直传 Telegram），其中 **113 条完全无正文**——纯文件倾倒。

有正文的用固定卡片：

```
群友求书——
书名：…
作者：…
文件：简体中文 · TXT · 2MB ·
分级：🔞
标签：#人物名 #人物名 #人物名
```

**自建内容分级**（🔞 成人向 / 🌱 非成人向）是它最成体系的一处。标签位放的是书中人物名，用于检索与同人向导流。

**混入的正规书目起两个作用**：让频道在检索与人工审视下看起来像正常读书号；同时这些（社会学专著、心理学译作、知名网文作者作品、7 种外文报刊 PDF）**也全是盗版**。

`#乱伦` 8 次、`#母子` 4 次、`#虐待` 3 次——题材本身在量刑上属情节加重项，见法律风险 5.2。

### 1.3 供给由需求驱动

「群友求书——」是主要帖型，说明**有配套群在收集需求、频道负责交付**。

### 1.4 托管

全部文件以 document 直传 Telegram，**零托管成本**。电子书体积小（2–16MB），比 lps999 的 GB 级 APK 更没有成本压力。外链极少：300 条里仅 12 条有链接，非 t.me 外链只有 `telegra.ph` 与 `mp.weixin.qq.com` 各 1 条。

## 二、增长策略

**批量灌库 + soso 互推。两条都是量的逻辑，不是留存的逻辑，结果就是 0.2% 的 ERR。**

### 2.1 soso 互推网络

样本内 1 条 `#频道互推 #相似推荐`，含 10 个归因链接：

```
t.me/sooo?start=<推广载荷·已脱敏><伙伴ID>_<hash>
尾部：🤝 加入互推 · 获得曝光，赚邀请奖励
```

与 `syrjfx_sl`、`xph_fx` 用的是**同一套 SOSO 互推产品**。自身频道 ID 是 `-1001582596993`。

**伙伴列表清一色是影视、里番、本子、以及带地名的约炮向频道**——换来的量与"读书"定位完全不匹配。这直接解释了为什么 ERR 塌到 0.2%。

### 2.2 批量灌库冲检索命中

发帖按日分布极不均：

```
09-08    67 条
09-10   231 条   ← 单日峰值
09-11     1 条
09-12     1 条
```

271 个文件 + 人物名标签，是为了被 Telegram 搜索和第三方搜索 bot 按书名、作者、人物名命中。**目的是被搜到，不是被读到。**

### 2.3 为什么失败了

| 指标 | 数值 |
|---|---|
| 转发 | **26 次 / 300 条 = 0.09 次/帖** |
| 反应 | **总计 5 个** |
| 中位阅读 | 57（p10 47 / p90 152 / max 248） |
| ERR | **0.2%** |

注意：这批帖子发布仅 1–4 天，但 p90 只有 152、最大 248——**不是"还没涨起来"，是确实没人看**。

互推能把订阅数堆到 2.8 万，但换来的是从色情向频道漂过来的无意向用户，他们既不看也不转。

对比同为文件分发号的 [lps999](lps999.md)（转发 50 次/帖、ERR 4.5%）——**差距不在品类，在流量来源**。

唯一真实的留存回路是「求书」机制，但规模太小，撑不起 2.8 万订阅的体量。

## 五、法律风险

> 本节为外部法律风险识别，不构成法律意见。

**两条独立的刑事线。第二条常被忽略，但性质同样严重。**

### 5.1 传播淫秽物品（文字作品同样入罪）—— 🔴 critical

| 依据 |
|---|
| 《刑法》第三百六十三条 制作、复制、出版、贩卖、传播淫秽物品牟利罪 |
| 《刑法》第三百六十四条 传播淫秽物品罪 |
| 《关于办理利用互联网、移动通讯终端、声音台制作、复制、出版、贩卖、传播淫秽电子信息刑事案件具体应用法律若干问题的解释》 |

**需要特别指出：中国对淫秽物品的认定不限于影像，文字作品同样构成。** 司法解释对淫秽电子信息设有明确的数量与点击量入罪标准，网络小说类判例数量不少。

271 个文件直传、单日 231 条的投放量、84 次成人向标签命中——在数量标准上处境不利。

而且**由于承接付费广告，属"牟利"情形，适用第三百六十三条而非第三百六十四条，量刑更重**。

### 5.2 题材构成情节加重 —— 🔴 critical

`#乱伦` 8 次、`#母子` 4 次、`#虐待` 3 次。涉及血亲与暴力题材的内容在情节认定上属加重项，**不能与一般成人内容同等评价**。

### 5.3 为未经批准的药品销售发布广告 —— 🔴 critical

| 依据 |
|---|
| 《药品管理法》第九十八条、第一百二十四条（未取得批准证明文件进口的药品按假药论处） |
| 《刑法》第一百四十一条 生产、销售、提供假药罪 |
| 《刑法》第二百二十五条 非法经营罪（无药品经营许可） |
| 《广告法》第十五、十六、四十六条（药品广告须经审查批准） |
| 《广告法》第五十六条（广告发布者连带责任） |
| 《刑法》第二百二十二条 虚假广告罪 |

**未取得进口批准证明文件的药品在中国按假药论处。** 作为广告发布者，明知为处方药/违禁品且无广告审查批准文号仍予发布，承担连带责任；若消费者因用药受损，发布者需承担赔偿责任。

"催情"类产品若含违禁成分，还可能牵涉更严重罪名。

### 5.4 侵犯著作权（盗版图书与报刊）—— 严重

《刑法》第二百一十七条、《著作权法》第五十三条。

混入的正规出版物与 7 种外文报刊 PDF 均为未授权分发。这部分占比不高，但**侵权事实清晰、权利人明确、易于取证——实际上比色情内容更容易被主动追诉**。

### 5.5 参与互推网络的连带风险 —— 严重

《刑法》第二百八十七条之二。互推帖为 10 个伙伴频道导流，伙伴列表中包含里番、本子及带地名的疑似性服务招揽频道。为这类频道提供曝光构成帮助行为。

### 5.6 内容分级不构成免责 —— 中等

《网络安全法》第四十七条、《未成年人保护法》第八十条。

自建的 🔞 / 🌱 分级在中国法下**不产生任何免责效果**——中国没有成人内容合法分级制度。**标注 🔞 等于自认内容性质**，而频道对未成年人没有任何准入限制。
