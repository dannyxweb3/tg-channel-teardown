> **频道 · 202,079 订阅（本轮最大） · 中位阅读 9,236 · 历史删除率 99.0%**
> 数据来源：`scripts/tg_recon.py dump shareAliyun --limit 300` → [data/recon/shareAliyun.jsonl](../data/recon/shareAliyun.jsonl)
> 抓取时间 2026-09-13 · 样本 300 条（2024-09-28 → 2026-09-13，跨度 715.1 天）
> **⚠️ 本报告不复现任何网盘分享链接。**

**一句话结论：20.2 万订阅，本轮最大的一个号。它把盗版影视、动画和付费网课挂在阿里云盘上分发，每条帖子都是机器生成的标准模板——名称、剧情简介、链接、大小、标签，末尾还带一行「⚠️ 版权：版权反馈/DMCA」。它的历史 id 从 66,448 排到 97,324，三万条消息里只活下来 300 条，删除率 99.0%。而最值得看的是两张榜单的分裂：阅读前三是《师兄啊师兄》36 万、《漩涡》22.9 万、《喜羊羊》17.4 万；转发前四全是盗版付费课程——某机构的「10000+ 行代码实现 TCP/IP 协议栈」144 次、「趣学设计模式」139 次、英语语法课 116 次、Python 实战课 108 次。剧一个人看完就算了，课要转给别人。**

## 二、核心发现一：一个完全模板化的盗版分发流水线

**每一条帖子的结构完全一致：**

```
名称：<片名> <画质> <更新进度>
描述：<剧情简介，通常直接来自豆瓣>
链接：<阿里云盘分享链接>
📁 大小：<体量>
🏷 标签：#<类型> #<片名> #<画质> #ali
🎉 来自：<投稿者>
⚠️ 版权：版权反馈/DMCA
📢 频道　👥 群组　🤖 投稿
```

**十个字段，字段名带 emoji 前缀，顺序固定。** **这是 bot 拼装的，不是人写的。**

**标签体系（前 12）：**

```
#ali 175 | #剧情 112 | #4K 106 | #动画 63 | #动作 57 | #喜剧 44
#奇幻 42 | #爱情 29 | #KMYP 25 | #悬疑 25 | #犯罪 23 | #学习 23
```

**`#ali` 175 次是网盘标识**（区分阿里云盘与其他盘），**`#4K` 106 次是画质，`#学习` 23 次是课程类。**

**投稿链路可见**：`@aliyun_share_bot` 在 2024 年的帖子里被标为「🤖 投稿」，出现 118 次；投稿者署名写作「🎉 来自：雷锋」。**内容由用户投稿、bot 入库、模板出帖。**

**35 条帖子标注了明确体量，合计 1,198.9 GB** ——**但这些字节全部存在阿里云盘上，频道本身托管 0 字节。**

**这是与本轮其他盗版分发号的关键区别：**

| 频道 | 文件放哪 | 托管量 |
|---|---|--:|
| [gitbig](gitbig.md) | **Telegram** | 29.01 GB |
| [TAndroidAPK](TAndroidAPK.md) | **Telegram** | 20.95 GB |
| [dianying4K](dianying4K.md) | 网盘外链 | 低 |
| **shareAliyun** | **阿里云盘** | **0** |

**把内容放在阿里云盘上，意味着存储、带宽、分发全部由阿里巴巴承担，而侵权内容的删除也由阿里巴巴执行**——**这正是 99.0% 删除率的来源（§四）。**

**转发/阅读比差了 26 倍。**

**行为解释很直接：影视是一次性个人消费——看完就完了，没有转发的动机；网课是资产——转给同学、转进学习群、存进收藏夹，转发就是收藏和分享的复合动作。**

**这条规律对内容选品有直接含义**：**如果目标是订阅增长（靠转发），课程比影视有效得多，尽管它的阅读量只有影视的十五分之一。**

**§一 里 `#学习 23` 只占样本的 7.7%，却贡献了转发榜的全部前六。**

**而这 23 条课程的来源全部是可指名的商业培训机构**（样本内可见至少四家国内知名 IT 培训与考证机构的完整课程包，以及 B 站的付费课程）。**这一点在法律层面比影视盗版更重（见 §八）。**

## 四、核心发现三：99.0% 删除率与一个被跳过的两年

**id 从 66,448 排到 97,324，历史消息 30,877 条，存活 300 条。**

**但存活的这 300 条在时间上不是均匀的：**

```
2026-09  175 条   ← 抓取前两周
2024-10   56 条
2024-09   68 条   ← 两年前的一个残块
2025-06    1 条
```

**2024 年 11 月到 2026 年 8 月，整整 22 个月，只活下来 1 条。**

**这说明删除不是随机的，而是有一条清理线在往前推**：**近两周的帖子还在，两年前有一块残留没清干净，中间被清空。**

**最可能的机制是：阿里云盘的分享链接被平台失效后，频道批量删除对应帖子。** 阿里云盘对盗版分享的处置是持续的，**一条链接的平均寿命远短于一个月**，而 30,877 条历史消息除以 715 天 ≈ **43 条/天的实际发布量**。

**id 差分布 `+1` 出现 268 次、`+2` 18 次** ——**在存活的两个区块内部，消息是连续的。这佐证了"按时间段批量删除"而非"逐条零散删除"。**

**本轮的删除率排名现在是：**

```
googlevoice       99.9%
google_drive      99.4%
shareAliyun       99.0%   ← 本条
bigdongdongGroup  96.1%
blacktechsharing  92.9%
dockertutorial    91.5%
```

**前三名全部是网盘/账号类** ——**它们的共同点是：分发的东西会被第三方平台失效，留着死链只会招来投诉和差评。**

## 五、核心发现四：一行 DMCA 声明

**每条帖子末尾都有：**

```
⚠️ 版权：版权反馈/DMCA
```

**这行字是一个可点击的链接，指向一个版权投诉入口。**

**一个分发盗版的频道，自带一个 DMCA 投诉通道。**

**这是在模仿正规平台的合规界面。** 它的实际作用有两层：

| 层 | 作用 |
|---|---|
| **对外** | 制造"我们有合规流程"的观感，**在被投诉时主张自己是"平台"而非"发布者"** |
| **对内** | **收到投诉就删，用最低成本消化维权压力** |

**第一层在中国法下站不住**：**《信息网络传播权保护条例》的"避风港"规则保护的是提供存储、搜索、链接服务的网络服务提供者，前提是不知道也没有合理理由应当知道侵权。** **一个主动编辑标题、撰写简介、打上 `#4K` 标签、分门别类排版的频道，是内容的编辑者与发布者，不是中立的服务提供者。**

**第二层倒是真实有效的** ——**配合 99.0% 的删除率，它把每一次维权的结果都变成"已删除"。**

## 六、模板的两年演变

**把 2024-09 的帖子和 2026-09 的帖子并排看，有四处变化：**

| 字段 | 2024 年 | 2026 年 |
|---|---|---|
| 频道/群组/投稿 | **`@shareAliyun` / `@aliyundriveShare` / `@aliyun_share_bot`（明文 handle）** | **「📢 频道　👥 群组　🔍 投稿/搜索」（纯文字，handle 藏进链接）** |
| 投稿者署名 | **「🎉 来自：雷锋」** | **已移除** |
| 第三个入口 | 🤖 投稿 | **🔍 投稿/搜索**（加了搜索） |
| 体量 | 明确数字（如 13.25 GB） | **多数为空或残缺** |

**第一处变化是刻意的**：**明文 handle 会被搜索引擎和批量扫描工具直接抓取；改成"频道"两个字加超链接后，纯文本扫描就拿不到账号名了。** **本轮此前在 [merlinclashcat](merlinclashcat.md) 见过同类思路（把"机场"拆成拉丁字母塞进括号），这是另一种实现。**

**第二处（移除投稿者署名）指向责任切割**：**"来自：雷锋"把具体上传者暴露在每条帖子上；去掉它，链路上就只剩频道本身。**

**第三处（投稿 → 投稿/搜索）说明它增加了一个搜索入口** ——**20 万订阅、每天 43 条的体量下，用户找不到东西是必然的，搜索 bot 是必需品。**

## 七、趋势

**月度中位阅读：**

```
2024-09   7,774
2024-10  14,129
2026-09   1,314   ← n=175，全部 <7 天
```

**帖龄分桶**：`0–7d 1,312`（n=174）、`7–14d 5,080`（n=1）、`≥56d 9,298`（n=120）。

**必须说清楚这两个数字不可直接相比**：**2026-09 的 175 条全部不到 7 天，而 2024 年的 120 条已超过两个月。**

**但即便如此，落差仍然异常**：**样本内 2026-09 的单帖实测阅读低到 201、326** ——**在一个 20.2 万订阅的频道上，发出去三到五天只有两三百人看。**

**Telegram 频道的绝大部分阅读发生在前 48 小时。** **一条发了几天还停在 300 阅读的帖子，不会在两个月后长到 9,000。**

**因此结论是：这个频道的实际触达已经崩塌，而 20.2 万的订阅数是历史存量。**

**两个可能的原因，样本无法区分：**

1. **发帖量太大**：43 条/天会让绝大多数订阅者静音频道。**这正是本轮反复验证的"高频铺量压低 ERR"规律**（[AI_News_CN](AI_News_CN.md) 76 条/天 → 1.11%、[inside1024](inside1024.md) 70 条/天 → 1.00%）。
2. **订阅盘本身的质量**：20.2 万订阅、单帖三百阅读，**比例失衡的程度超过了单纯"静音"能解释的范围。**

**月度转发同样低迷**：2024-09 的 9 → 2026-09 的 3。

**节奏**：小时分布集中在晚 19–22 点（28 + 33 + 45 + 33 = 139 条，46%），**分/秒无 cron 聚集**（分钟最高 `:52` 仅 13 次），**间隔中位 401 秒，`<60 秒` 占 21%、`<10 秒` 占 15%** ——**短间隔是批量入库时的连发，整体是 bot 驱动但按队列出帖，不是整点定时。**

## 十一、法律风险

> **level: criminal。**
>
> **1｜大规模分发盗版影视作品（核心）。** 约 43 条/天、715 天、三万条历史消息，内容是院线电影、剧集、动画、综艺的 4K / 1080P / 蓝光原盘 REMUX 资源，通过阿里云盘分享链接分发。样本内 35 条标注体量即达 1,198.9 GB。
>
> 《著作权法》第十条第（十二）项信息网络传播权；**《刑法》第二百一十七条侵犯著作权罪。**
>
> **「以营利为目的」这一要件在本案中不能以"零广告"排除。** 依《关于办理侵犯知识产权刑事案件具体应用法律若干问题的解释（二）》，**以刊登收费广告等方式直接或间接获得利益的，属于"以营利为目的"**；而实践中，**大规模、持续、组织化的传播即使当期无直接收益，也可能被认定具有营利目的**（司法解释同时规定了"传播他人作品数量合计在五百件以上"的入罪标准——本案的历史消息量是这个标准的六十倍）。
>
> **本案的组织化程度是加重因素**：模板引擎、投稿 bot、搜索 bot、标签分类体系、持续两年的死链清理线——**这是一套基础设施，不是个人分享行为。**
>
> **2｜盗版商业培训课程（独立且更重的一项）。** `#学习` 23 条，样本内可见至少四家可指名的国内 IT 培训与考证机构的完整课程包、B 站付费课程、以及带源码课件的完整项目实战课。
>
> **这一项比影视盗版重，原因有三：** (1) **权利人明确、集中、且有维权动机**——培训机构的核心资产就是课程，被盗版直接冲击主营收入；(2) **"带源码课件"意味着分发的是完整交付物，不是片段**；(3) **它在本频道的转发榜上排前六**——传播效果最好的恰恰是侵权最明确的部分。
>
> **3｜「⚠️ 版权：版权反馈/DMCA」的法律效果。** 该声明不产生避风港保护。**《信息网络传播权保护条例》第二十二、二十三条的免责前提是网络服务提供者不知道也没有合理理由应当知道所链接的作品侵权，且未从中直接获得经济利益。** 本频道主动编辑标题、撰写剧情简介、标注画质、分门别类打标签——**是内容的编辑者与发布者，不是中立的链接服务提供者，"应知"要件明显成立。**
>
> **该声明的真实作用是降低处置成本**（收到投诉即删），**而 99.0% 的删除率证明这条流程在运转。** 在量刑上，**积极响应投诉属于酌定从轻情节，但不影响定罪。**
>
> **4｜借用合法平台的存储与带宽（情节评价）。** 全部内容托管在阿里云盘上，频道自身托管 0 字节。**这意味着侵权物的存储与分发成本由一家合规经营的公有云服务商承担，且其服务条款明确禁止此类使用。** 与本轮 [gitbig](gitbig.md)（29.01 GB 托管在 Telegram）相比，**后果的转嫁对象从 Telegram 变成了一家中国境内、受中国法管辖、有明确投诉处置义务的公司——这使权利人的维权路径更短，也使运营者的账号链路更容易被追溯。**
>
> **5｜模板去明文化（不利情节）。** 2026 年起，帖子末尾的 `@shareAliyun` / `@aliyundriveShare` / `@aliyun_share_bot` 从明文 handle 改为纯文字加超链接，投稿者署名「来自：某某」被整体移除。**前者规避文本扫描，后者切断具体上传者的暴露** ——**两者都属于规避行为，在情节评价上不利。**
>
> **6｜零可观测收入（有利情节，但不能单独依赖）。** 715 天内 0 条广告、0 个联盟参数、0 个付费入口。**这是本案在"营利目的"上的唯一抗辩点**，但如第 1 条所述，它在大规模有组织传播的事实面前作用有限；且样本只覆盖频道，**群组与 bot 内部是否存在收费，本次抓取看不到。**
>
> **不适用的三条**：不涉及开设赌场罪（0 条博彩内容）；不涉及传播淫秽物品罪（样本内 0 条成人内容，标签体系里也没有对应分类）；不涉及帮助信息网络犯罪活动罪（0 个代收款账号、0 条诈骗或机场导流）。
