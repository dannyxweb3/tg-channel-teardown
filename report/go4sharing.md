「本次耗时 11 分 13 秒」「从 1470 个节点中筛选出 24 个」——**这是程序输出，不是人写的文案**。全自动，无人工环节。

### 1.2 流水线

```
从公开来源抓节点（其他免费分享频道 / 公开订阅 / Cloudflare Worker 代理）
   → 批量连通性与可用性测试（耗时 9-23 分钟）
   → 按地区去重筛选
   → 产出 sub.yaml / clash.yaml / worker.yaml 三种格式
   → 推到 GitHub 仓库 go4sharing/sub
   → 发频道，附 raw.githubusercontent 订阅地址 + subsub.surge.sh 一键导入
```

## 四、法律风险

> 本节为外部法律风险识别，不构成法律意见。

**「公益」「免费」的定位在法律上不构成任何免责，在伦理上反而加重了误导。**

### 4.1 提供侵入、非法控制计算机信息系统的程序、工具 —— 严重

《刑法》第二百八十五条第三款。批量分发跨境代理配置，是该罪名在同类案件中的典型情形。

**免费不收费会影响非法经营罪的认定**（无经营行为），**但不影响本罪——本罪不以营利为要件**。

### 4.2 节点来源不合法 —— 严重

| 依据 |
|---|
| 《刑法》第二百八十五条（非法获取计算机信息系统数据） |
| 《刑法》第二百八十六条（破坏计算机信息系统） |
| 《反不正当竞争法》第十二条 |

良率 0.77% 说明节点是从公开渠道大规模扒取的。未经授权使用、并向**数万人再分发**他人的付费服务与计算资源，对原权利人构成侵权；规模化之后可能触及刑事。

### 4.3 对下游用户的未告知安全风险 —— 🔴 critical

| 依据 |
|---|
| 《网络安全法》第二十二条、第四十一条 |
| 《消费者权益保护法》第十八条（安全保障义务） |
| 《个人信息保护法》 |

**这是实质危害最大的一项。**

代理节点的运营者**可以看到经过其节点的全部未加密流量，并可实施中间人攻击**。

该频道向 55,425 名订阅者分发**来源不明、运营方完全不可知**的节点，且未作任何风险提示。被扒来的节点里混入蜜罐或恶意节点的概率不低，而这条链路上**没有任何一方对用户负责**。

「公益」「免费」的标签反而降低了用户的警惕——这是它比一个明码标价的商业机场更危险的地方。付费机场至少有商业声誉的约束，这里没有。

### 4.4 第三方平台服务条款违规 —— 中等

用 GitHub、Surge、Firebase 的**免费额度**托管代理订阅分发，违反相应使用政策，面临仓库与站点被封。

这不是法律风险而是业务连续性风险——**整条投递链路都建在别人的免费额度上**，任一环被封就断供。
