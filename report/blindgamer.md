## 二、核心发现：274 次 boost 请求是它唯一的"变现"

**300 条帖子里 274 条带着完全一致的页脚：**

> 📣 频道：@BlindGamer 💬 群聊： 点击加入 🚀 **Telegram 会员点此助力**

对应的链接统计：

```
t.me 域名出现 549 次
其中 t.me/…?boost   274 次   ← 每条帖子一次
@BlindGamer 提及    274 次   ← 同一个页脚
「会员」关键词      275 次   ← 同一个页脚
```

**这三个 274 完全对齐，证明它是一个固定模板，机械附加在每一条内容后面。**

**`?boost` 是 Telegram 的频道加成功能**：Premium 用户可以把自己的加成票投给某个频道，频道攒够票数就能解锁自定义表情、频道故事、更高的文件上传额度等特权。**投票对用户零成本（票是 Premium 附赠的），对频道则是实打实的功能升级。**

**这是本轮见到的最"干净"的一种索取**：

| | 常见做法 | blindgamer |
|---|---|---|
| 索取对象 | 现金 / 点击 / 注册 | **一张不花钱的加成票** |
| 对用户的成本 | 有 | **零** |
| 对频道的收益 | 现金 | **平台功能权限** |

**它需要 boost 的原因也很直接：242 个 mp4 共 9.27 GB。** 更高的加成等级意味着更宽松的上传限制与更好的分发。**这不是在变现，是在换基础设施。**

**3.3 严格的每日定时**

```
小时：15 点 198 条（66%）、14 点 36 条 → 两者合计 234/300（78%）
分钟：:01 42 | :02 49 | :03 45 | :04 46 | :05 41  → 五分钟窗口内 223/300（74%）
秒：  :57 23 | :58 17
间隔中位 86,343 秒 ≈ 24.0 小时
```

**间隔中位数精确落在 24 小时，分钟集中在 `:01–:05`，秒偏向 `:57–:58`。**

**这是一个每天固定时刻触发的定时任务**，把当天准备好的内容发出。**秒落在 `:57–:58`（而不是 `:00–:02`）说明 cron 设在整点前，或者上传大文件耗时把发布时间往后推了一点点。**

**但内容本身是人做的**：视频要剪、标题要写、原作者要查。**这是"人工生产 + 定时投放"的组合，与 awesomeRSSHub（全自动 1 秒连发）和 eco_cn（全手工零定时）都不同。**

## 七、法律风险

> **level: medium。**
>
> **1｜视频内容的著作权（主要项）。** 242 个 mp4 中包含大量游戏实机画面、他人创作的短视频与剪辑素材。中国大陆《著作权法》第十条第（十二）项信息网络传播权——**游戏画面的著作权归游戏开发商，玩家录制的实况与二创的权属在实践中存在争议**；样本内明确标注了部分原作者（`@Winkle雪线` `@星陨烟雨阁` 等），但标注来源不等于获得授权。责任主体为频道运营者。**减轻情节：非营利（零广告、零收款）、标注来源、内容多为评论与盘点性质，接近合理使用的边界。** 这类频道在实践中被追究的极少。
>
> **2｜「单机游戏修改器终极指南（附带黄油修改器）」这条帖子（26 转发，全样本最高）。** 传播游戏修改器涉及《计算机信息网络国际联网安全保护管理办法》与《刑法》第二百八十五条第三款**提供侵入、非法控制计算机信息系统程序、工具罪**的边界——**但单机游戏的本地存档修改器不侵入他人计算机系统，不构成该罪；真正的风险在网络游戏外挂，而本条明确限定为"单机"。** 风险很低。样本内「破解 3」的其余命中为游戏新闻正文用词。
>
> **不适用的三条**：不涉及帮助信息网络犯罪活动罪（0 个收款账号、0 条博彩/诈骗导流、0 个落地页）；不涉及传播淫秽物品罪（频道自标 `#SFW`，本次 300 条样本内 0 条成人内容）；不涉及非法经营罪（零现金收入、无经营行为）。
