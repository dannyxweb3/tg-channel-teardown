# jisou771 · 极搜 资源搜索、超级引索

> **群（megagroup）· 10,515 成员 · 730 在线（6.9%）**
> 数据来源：`scripts/tg_recon.py dump jisou771 --limit 600` → [data/recon/jisou771.jsonl](../data/recon/jisou771.jsonl)
> 抓取时间 2026-09-12 · 样本 600 条，只覆盖 **13.9 小时**

四个样本里**唯一不生产内容**的一个，也是唯一**不用 LLM** 的一个。它卖的是广告位。

## 一、先说群和频道的分析差异

| | 频道 | 群 |
|---|---|---|
| per-message 阅读量 | 有 | **没有** |
| ERR（阅读/订阅） | 核心指标 | **不适用** |
| 判活指标 | ERR、转发/帖 | **online/members、bot 消息占比** |
| 发言人 | 单一（频道身份） | 多个，需区分 bot 与人 |

所以本报告的 `metrics.err_pct` 和 `median_views` 都是 `null`，`views_available: false`。

> ⚙️ **工具缺口**：`scripts/tg_recon.py` 的 `_row()` 是按频道设计的，不抓 `sender_id`。分析群必须知道 bot 与人的比例，本次是另写脚本补的。建议给 `_row()` 补上 `sender_id` 与 `sender_is_bot`。

## 三、技术实现

### 3.1 消息流

```
用户发关键词（301 条短消息，中位 21 字符，p10 仅 2 字符）
   ↓
搜索 bot 回复一个结果块：
   ├─ 顶部：付费广告      中位 1 行 / 均值 2.4 行 / 最多 12 行
   ├─ 中间：搜索结果      18-19 条 t.me 链接
   └─ 底部：「热搜」一行   出现 240 次
```

用户关键词长什么样：

```
'老a8'  'Rwt4184'  '云峰之巅'  '小说'  '欧美'  'Erotica'
'这个词不返回结果.'   ← 这条出现了两次，是 bot 的兜底回复
```

**它自己不存任何资源。** 4,508 个 t.me 链接全是指向别人的频道和群——纯指路。

### 3.2 广告注入：`ad=` slot id（判定它是广告平台的关键证据）

落地链接带追踪参数：

```
http://<一个裸 IP>/?cid=<7 位渠道 id>&ad=link<4 位槽位 id>
https://<博彩落地域名 A>/?channel=<3 位渠道 id>&ad=link<4 位槽位 id>
https://<博彩落地域名 B>/?ad=kw<6 位关键词槽位 id>
https://<一个文档托管域名>/<短 id>?ad=kw<6 位关键词槽位 id>
```
（⚠ 落地域名、裸 IP 与具体 id 按内容纪律脱敏；参数名与位数保留，因为判定靠的是结构不是取值。）

| 参数 | 含义 |
|---|---|
| `ad=link####` | **固定链接广告位** |
| `ad=kw######` | **关键词广告位**——广告主按搜索词竞价，用户搜什么就注入对应广告主 |
| `cid=#######` | 渠道/客户 id |
| `channel=###` | 渠道 id |

六位数的 slot id 说明库存规模很大。一天内出现 **383 条去重广告行**。

### 3.3 运营班底（管理员列表直接暴露）

| 账号 | 角色 |
|---|---|
| 一个具名账号 | 群主 |
| 一个商务账号 | **商务对接（广告位销售）**，自称某某商务，并附一句「注意骗子模仿」的防伪声明 |
| 搜索 bot 主 [BOT] | 纯数字用户名，169 条 |
| 搜索 bot 副 [BOT] | 纯数字用户名，140 条 |
| 一个互推 bot [BOT] | **自建的换量涨粉 bot** |
| 一组同族 bot（编号 17–21）[BOT] | 五个，管入群与隐藏服务消息 |

那个自建互推 bot 值得注意：syrjfx_sl 用的是 soso 的互推产品，极搜**自己做了一个**。互推在这个生态里是标准件。

### 3.4 连群简介都是广告位

群的 `about` 字段挂的是社交账号批发商的广告（精养号、死号封号包赔，附一个联系人账号）——**about 字段本身被租出去了**。

### 3.5 全天候，无排期

```
08:00 ▇▇▇▇▇▇ 80    16:00 ▇▇▇▇ 61    17:00 ▇▇▇ 51
19:00 ▇▇▇ 46       20:00 ▇▇▇▇ 55    21:00 ▇▇▇ 52
```

人流驱动，不是 cron 驱动。这是它和前三个号最根本的区别。

## 四、成本

| 项 | 估算 |
|---|---|
| **搜索索引**（MTProto 爬公开群组/频道，存储+检索） | ¥500–3,000/月 |
| VPS / bot 托管（8+ 个 bot） | ¥200–700/月 |
| 群管理人力 | ¥100–300/月 |
| **LLM** | **¥0**——纯关键词匹配，无生成环节 |
| **内容生产** | **¥0**——不生产内容，不存资源 |

**经常性支出 ¥800–4,000/月**，无一次性投入（不买粉、不买号）。

搜索索引是唯一的真资产，也是唯一的技术门槛。

## 五、收益

| 变现路径 | 证据 | 估算月入 |
|---|---|---|
| 关键词广告位 `ad=kw######` | 落地链接带 kw slot id | ¥1,500–8,000 |
| 固定链接广告位 `ad=link####` | 落地链接带 link slot id | ¥1,000–5,000 |
| 群简介广告位 | about 挂号商广告 | ¥200–1,000 |
| 自家第二个搜索 bot 分销 | `t.me/jisou2?start=<推广载荷·已脱敏>` | ¥300–1,000 |

**合计估 ¥3,000–15,000/月——但这只是本群可归因的部分。**

⚠️ **归因问题必须说清楚**：383 条去重广告行是**整个极搜网络**的库存，不是这一个群的。10,515 人的群只是众多展位之一。极搜网络整体收入远高于此，但从单个群的数据推不出来——要估网络规模，得把它的 bot、其他群、以及收录的频道一起拉。

**为什么它的毛利结构是四个样本里最好的**：不生产内容、不存资源、不用 LLM、不买粉。成本只有索引和托管，收入是广告位。

## 六、风险

> ⚠️ **这个是四个样本里最严重的一个，性质上也不同。**
>
> 前三个号的问题是它们**自己发的内容**违法。这个群自己不发内容，问题在**它承载的广告**：
>
> - **社工库 / 开盒服务**（宣称可查户籍与全家档案）——侵犯公民个人信息罪，且直接危害具体自然人
> - **线下性交易招揽**（外围兼职、选妃入口）——组织卖淫 / 介绍卖淫范畴
> - **境外博彩引流**——与 syrjfx_sl 同类，开设赌场罪 / 帮信罪的引流环节
> - **成人 AI 换脸脱衣**类广告，文案含非自愿情节与未成年暗示
> - **群简介在批发社交账号**——账号盗用黑产的上游
>
> 最后两条比前三个号的任何内容都严重。**本报告正文刻意没有引用这些广告的原文**，分类描述即可说明问题。
