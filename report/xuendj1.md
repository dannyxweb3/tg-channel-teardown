## 一、它是怎么实现的

全自动流水线，做法相当粗放。

| 观察 | 说明 |
|---|---|
| 消息 ID 390,559，最早 id 2000 在 2024-08-15 | 运营 758 天 |
| 连续帖间隔 **45–90 秒**，20 条压在 17 分钟里 | 批量定时喷 |
| ID 每两个跳一个 | 隔号那条是 `@soso` 的「消息已收录，30 秒后自动删除」，发完自删 |
| **0 个 inline 按钮**，正文一律以「👇 评论区获取资源」收尾 | 资源链接不落在频道消息里 |
| 评论区已开（关联讨论组），web widget 读不到 | 真链接在关联群的自动回复里 |
| 每帖一张独立封面图 | 跟着采集源一起抓下来的资源海报 |
| 唯一外链 `t.me/soso?start=<推广载荷·已脱敏>` | `a_` 后面是分销码 |

正文结构高度模板化，是 LLM 生成的：`《标题》` + 一段 60–80 字营销体简介 + `[#标签 ×3–5]` + 固定 CTA。

**模板换过版**：2025-04 的帖子还是「简介：/ 亮点：（4 条 bullet）/ 🏷标签：」的长版，2026 年砍成了短版。改了一次 prompt。

```
采集源（网盘资源站 / 同行频道）→ 抓标题+封面
   → LLM 套模板写简介和标签（输入只有一个标题，没有原文）
   → 定时批量发频道（无按钮）
   → 关联群机器人在评论区补真链接
   → soso 收录 + 分销码
```

### 关键设计点：把下载链接挪进评论区

好处两个：频道正文永远「干净」，被举报时正文没有侵权链接可指；同时强制把人拽进关联群，群里才是能推广告、能私聊的地方。

（另一种常见做法是用深链按钮直接跳进 bot，路径更短、转化更好，但正文的可追责性也更高。）
