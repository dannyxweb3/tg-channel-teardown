## 二、技术实现

### 2.1 inline 按钮矩阵（最值得抄的一条）

300 条样本里 **294 条带按钮，共 1,341 个**。每帖固定四件套：

| 按钮 | 出现次数 | 作用 |
|---|---|---|
| 🔗 夸克网盘 | 312 | 主投递 |
| 🔗 百度网盘 | 154 | 备选投递 |
| 🔗 蓝奏云 | 4 | 备选投递 |
| 🔎 点击搜索更多实用软件 | 286 | 留存 |
| 👥 进群搜索想要内容 | 286 | 导流私域 |
| 📢 防走丢频道 | 286 | 备份频道，预设被封 |

正文里的「💾【下载地址】🔻」**后面是空的**——链接全在按钮上。

好处三条：正文纯文本不含侵权 URL；按钮可随时批量替换或失效；点击可追踪。

> 注意：这些是 URL 按钮，不吃 `callback_data` 的 64 字节上限。

### 2.2 先发后补：全部帖子都有 edit_date

```
126473  发布 13:30:00 → edit 13:30:23
126864  edit 2026-09-12 05:30:44
126889  edit 2026-09-12 10:30:58
```

**每条都在发布后 20–60 秒被编辑过。** 这是「先发消息占位，网盘上传/转存完成后再 edit 补按钮」的流水线。

### 2.4 增长引擎：soso 互推网络

互推帖里每个频道名都是超链接，指向：

```
t.me/SosoCnBot?start=<推广载荷·已脱敏><伙伴频道ID>_<hash>
```

第一个 ID 是它自己，第二个是伙伴频道——**soso 跑了一套自动化互推交换网络，带归因追踪**，尾部还有「加入互推 · 获得曝光，赚邀请奖励」按钮。

与 xuendj1 用到的 soso **收录**功能是同一生态的两个产品：一个负责被搜到，一个负责换量。

伙伴频道里混着转账模拟器、网络钱包修改、超级签/企业签等灰黑产工具号。
